# Schema gaps

The selected W-B0′ wire contracts have no open schema gaps. The machine-readable list is `schema_gaps.json`. Each catalogued adapter operation has a named argument resource, a named reply resource, their digests and a policy row in `adapter_ops.json`.

**Dispatch evidence is separate.** Carbon-verified backend bindings are AUSENTE. All current rows are unsupported. A parked operation can return an empty refusal result with its code in the control envelope. The factory's production capability manifest is AUSENTE. Its adapter describes the common payload in SF3 §2.2 pending manifest reconciliation by M1.

**Runtime decisions remain open.** Production calibration thresholds and a qualification receipt for the index are AUSENTE. Candidate promotion evidence and workflow default status remain operator decisions. Several non-adapter tools retain the W-B0 empty argument placeholders outside this selection. Existing frozen identifiers and migration details are in `SCHEMAS.md`.
