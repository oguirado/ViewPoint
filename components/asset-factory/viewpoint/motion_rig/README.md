# Offline motion and rig mini-tools

Load `viewpoint.motion_rig.profile.configure(work, pins, context)` into HOST-FACES. Create the state directory and the `exchange` and `capsule` directories under the granted root before dispatch. Both slots expose qualify, benchmark, inspect, repair, preview and compare through the router, CLI, MCP and JSON faces.

`ext.motion.*` accepts `source_mode` `video` or `text` for `vp3d-motion-fixture`. The bound BVH, rig sidecar and source drive forward kinematics. Qualify, benchmark, compare and repair also use a pinned reference. The Y4M clock must match the BVH frame rate. The legacy single-frame specimen is exempt from the frame-count check.

For `tools.motion.native`, set `source_mode` to `supplied_bvh_with_video_clock`. Inspect and preview take `rig_glb`, `action_bvh`, `video` and `observation` and return the observed contact frames and sole positions in micrometres. This diagnostic path uses matching GLB and BVH joint names and metre-scale BVH offsets. To check the observed trace against the independent oracle, supply both `reference` and `pose_reference`. Qualify, compare, benchmark and repair require these two pins. The `af.motion-observation/v1` observation binds the input digests and frame identities. Its request digest is the canonical digest of the object containing `rig_sha256`, `video_sha256` and `reference_sha256`, where the reference digest uses canonical JSON. The pose reference pins the raw rig, video and reference digests, the normalized BVH hierarchy and all normalized channel rows.

Native `inspect` also accepts the optional `pose_reference_bvh` role with both reference pins. Its normalized hierarchy, clock and full channel rows must match the applicable pins. The resulting `measurements.temporal_concentration` reports the fixture verdict, contact onset deltas, planted-sole displacement from each stance anchor and per-joint angular speed and velocity-change peaks in the parent basis. Its windows cover adjacent frames and immediate parents and children around peak changes and contact onsets. The verdict covers all frames and joints against the authored reference, plus all observed sole positions against the reference BVH and contact labels against the contact reference. The report lists native policy refusals separately. Use `compare` or `qualify` for a strict refusal.

Native repair takes the signed `advance_foot_frames` offset and an independent `derived_observation`. It retimes the referenced feet's rotation channels in the supplied BVH, preserves the other channels and writes a parent-bound revision only after the video-clock, sole-position and full-pose checks pass. A positive offset advances the channels. At either edge, repeating a boundary sample requires all discarded samples on the repaired channels to match the boundary sample.

`ext.rig.*` uses `rig.fixture` to measure joint hierarchy, inverse bind matrices, weights and weighted vertex poses from GLB bytes. For custom references, add the independent reference file's SHA-256 to `configure(..., rig_reference_sha256=(...))` in the host configuration. The reference object contains `asset_sha256` for its source GLB and `measurements`. Candidate byte equality is independent of reference admission. The bundled legacy expectation remains supported. Rig repair emits a new GLB and records its digest.

With the required input roles, `mocapanything_v2` video refuses with `research_only_unverified_runtime`, its text route refuses with `text_unsupported`, and `unirig` refuses with `approved_build_missing`. An unlisted model ID returns `UNKNOWN_MODEL`. All routes are offline fixture bindings.
