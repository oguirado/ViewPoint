## Schedule, sampling and stopping

1. Before dispatch, record baseline/candidate build and delta digests, checker/toolchain and contract pins, workload and reference manifests, approvals, cache/worker start state, raw-output comparison rules, timing boundaries and admissible resource/placement receipts. An ABSENT required input (AUSENTE) keeps that arm NOT_RUN. For stochastic work preassign the same seeds within pairs. Distinguish distinct real providers and diagnostic fixtures.
2. For each eligible arm schedule exactly 15 blocks with 2 matched pairs each (30 pairs total). Each block contains an AB and a BA pair on the same predeclared input stratum. Randomize their order with a deterministic sequence derived from SHA-256 of the registration digest, arm ID and block index. Use the low bit of the first raw digest byte, even meaning AB then BA. Encode the seed material as factory canonical JSON array of the digest, arm ID and zero-based index. Freeze the workload/stratum order before the first run.
3. Run one leg at a time on the normally working host. Reset declared software caches, worker generation and local destinations between legs. Preserve normal host page-cache state and operator load. No system cache flushing. Use independent wall capture and the same out-of-process PSI/placement sampler even for recorder-off arms. End-to-end time includes queue, startup, execution, verification and teardown. Record raw child evidence before normalization.
4. Complete the fixed schedule without early success, futility looks, extra pairs, or replacement of excluded blocks. Stop immediately on a witnessed rights, custody, resource-safety or semantic regression. Record DISCARD for a candidate regression, including a first occurrence, independently of timing. Missing permission, interrupted study or unresolved equivalence yields INCONCLUSIVE or NOT_RUN; retain all attempts.
5. Exclude a whole block from timing inference when either pair is incomplete or has an instrumentation failure such as a drop, sequence gap, broken join, mismatched pins/workload, invalid placement, clock reset, or missing primary wall/PSI reading. Log the specific failure and variant before analysis. Candidate-induced loss, timeout, crash, corrupt output, refusal on valid work or evidence loss is a failed functional gate, never a favorable timing exclusion. Genuine expected refusals are part of declared refusal workloads. Keep slow observations and high-pressure periods. Require at least 12 complete balanced blocks; report attempted, included and excluded denominators per arm and cause. Differential unexplained losses prevent promotion.

## Estimator, confidence interval and decision

For pair i use y = log(wall_A / wall_B), retaining only strictly positive elapsed times. PSI covariates are differences (B minus A) of the host CPU, memory and I/O **some** stall fractions from the fixed 10 s window immediately before each timed leg, derived from monotonic cumulative totals. Preserve start/end counters, elapsed times, host clock and attribution. Log pressure during the leg as a diagnostic. Adjusting for pressure caused by B would remove part of the treatment effect.

Fit ordinary least squares to y with an intercept, order indicator (+1 for AB, −1 for BA) and the three pre-leg PSI differences. Report the intercept at *equal pre-leg pressure* and balanced order. Omit any covariate identically zero in the confirmation sample. If the remaining design is rank deficient, report INCONCLUSIVE. Use the fitted intercept b to report wall-time reduction G = 100 × (1 − exp(−b)) percent. Also publish the raw paired geometric reduction, median paired reduction, wall distributions, useful verified output bytes/s and CPU-s per useful GiB for each variant. A zero useful-byte denominator yields a null rate with reason. Report copied bytes by boundary, peaks, retries, failures and cleanup separately.

Compute the paired 95% percentile interval by resampling complete two-pair blocks with replacement within the frozen input strata, retaining both orders in each block. Use 9,999 replicates, the same fixed nonzero covariate columns as the original fit, a Python MT19937 generator seeded with the full integer SHA-256 of the canonical JSON pair [registration digest, arm ID], and sorted order of strata and block IDs. Use inverse empirical CDF endpoints at 0.025 and 0.975. Any singular resample or stratum with fewer than 2 retained blocks makes the adjusted CI INCONCLUSIVE; report the unadjusted descriptive results. Publish the ordered pair table, model columns and seeds so the analysis can be replayed. Freeze independent strata in repeated blocks before timing. If block independence is untenable over the recorded host schedule, withhold inferential promotion.

For a speed arm, KEEP when the lower endpoint is ≥ +5%, DISCARD when the upper endpoint is ≤ −5%, and MARGINAL only when both endpoints lie strictly inside (−5%, +5%). All other intervals are INCONCLUSIVE. Decisions use unrounded endpoints and apply arm by arm. No family-wide superiority claim follows from these intervals. Preserve every registered arm in the results, including negative and unauthorized arms.

For TRACE-job and TRACE-gate use their sole wall endpoint to estimate **overhead** = 100 × (wall_on / wall_off − 1) per pair. Report the median paired overhead, its block-bootstrap interval, the PSI-adjusted wall result and event-heavy diagnostics. Enable tracing in timed runs only if both median overheads meet their respective ceilings and capture-integrity checks pass. Overhead admission has its own ceiling. A performance decision alone cannot advance an asset, approve a provider or release a lease.
