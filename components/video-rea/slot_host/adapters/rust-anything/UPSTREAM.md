`fixtures.json` pins both polarities of every shared oracle-bank case and supplies the synthetic raster for the lease probe. The gate validates the bank cases before applying each negative mutation to an in-memory copy. The custody and lifecycle exercises use fixture identities and state. Transport parity normalizes passive inspection across the existing projections and exercises the runtime's process-local claim behavior. The simulated pool exercises the host comparator's grant, timeout and release behavior.
