# Static False Positive Cause Attribution Rules (`bvqa.static-fp-cause/v1`)

## Scope and Population

`tools/static_fp_cause.py --run RUN --out NEW` attributes scene-specific static false positives to root causes using only persisted unit evidence under `RUN` without rendering or modifying any input file.

### Unit Discovery and Persisted Inputs
1. **Scoring rows (`RUN/rows.jsonl`)**:
   - Each unit `(bench, seed)` is discovered from `rows.jsonl` (`schema == "bvqa.calib-row/v1"`), reading `"bench"`, `"seed"`, `"grid"`, `"frames"`, `"tiles"`, `"t0_q4"`, and optional `"clean_resid"` (`blender_visual_qa/truth/score.py:23, 150-157`; `blender_visual_qa/truth/run_bench.py:687-688, 1052`; `tools/noise_rescore.py:315-330`).
2. **Ground-truth tile labels (`labels/tiles_truth.bin` or `labels_t0_<t0>/tiles_truth.bin`)**:
   - Loaded via `score.read_truth_tiles(path, expect_grid)` (`blender_visual_qa/truth/score.py:60-79`), which unpacks the 64-byte `BVQTRUT1` header (`TRUTH_HDR_FMT`, `blender_visual_qa/truth/score.py:48-50`, `blender_visual_qa/truth/labels.py:35-37`) and 8-byte per-tile records (`TRUTH_REC`, `blender_visual_qa/truth/score.py:52-53`, `blender_visual_qa/truth/labels.py:38-39, 306-317`) yielding `tl` (`uint8[F, N]`), `flags` (`uint8[F, N]`), `mv` (`int8[F, N, 2]`), `ob` (`uint16[F, N]`), `occ` (`uint16[F, N]`), and `hdr` (`s, W, H, gw, gh, N, n_frames, f0`).
3. **Engine per-tile classes (`vision/tile_cls.jsonl` else `vision/frames.jsonl` + `vision/regions.jsonl`)**:
   - When `vision/tile_cls.jsonl` is present in the unit directory, per-tile classes `cls[f, i]` (`0..6` in `visioncore.layout.CLS`) are loaded directly from `vision/tile_cls.jsonl` (any tile marked `null`/`-1`/`"ABSENT"` is recorded as `-1` and counted as `ABSENT`).
   - Otherwise, engine classes are reconstructed from `vision/frames.jsonl` (`vqa.core-frame/v1`) and `vision/regions.jsonl` (`vqa.core-region/v1`) via `tools/noise_rescore.py` `decode_regions(frame_rows, region_rows, grid)` (`tools/noise_rescore.py:228-312`; cf. `tools/confusion_from_regions.py:55-138`):
     - Single-class regions (`len(active) == 1` in `region["cls_hist"]`) assign `cls[f, indices] = c` (`tools/noise_rescore.py:289-290`).
     - Multi-class dirty regions (`len(active) > 1` in `region["cls_hist"]`) cannot be spatially disambiguated from region spans alone; `decode_regions` assigns `cls[f, indices] = -1` and increments `mixed_class_tiles` (`tools/noise_rescore.py:291-293`).
     - Uncovered tiles where `0 < expected[1] < uncovered` increment `clean_class_absent_tiles` (`tools/noise_rescore.py:300-311`).
     - All unknown tiles (`cls == -1` and `clean_class_absent_tiles`) are counted as `ABSENT` and never guessed.
4. **Target False Dirty Tile Selection**:
   - A tile `(f, i)` is selected as a false dirty tile iff its ground-truth label is in `score.FP_POP = (0, 7)` (`STATIC = 0`, `SHADE_WEAK = 7`, `blender_visual_qa/truth/score.py:41, 43-44, 187`; `blender_visual_qa/truth/labels.py:22-24`) and its known engine class is predicted dirty (`cls[f, i] >= score.DIRTY_MIN` where `DIRTY_MIN = 2`, `blender_visual_qa/truth/score.py:24-25, 131`).
   - Any tile with `tl[f, i] in score.FP_POP` and unknown engine class (`cls[f, i] == -1`) is counted in `CAUSE_ABSENT` (`fp_absent_tiles`) rather than guessed.

## Ordered Attribution Rules

Every selected false dirty tile (`tl in score.FP_POP` and `cls >= score.DIRTY_MIN`) is attributed to **exactly one** cause by evaluating the rules below in strict priority order (`1 -> 6`):

| Priority | Cause ID | Condition Summary | Primary Persisted Fields & Citations | When Reported `ABSENT` |
|---:|---|---|---|---|
| 1 | `SHADE` | Truth tile label is `SHADE_WEAK` (`tl == 7`). | `tiles_truth.bin` field `tl` (`blender_visual_qa/truth/score.py:41, 43-44, 52, 60-79`; `blender_visual_qa/truth/labels.py:22-24, 222-230`); `rows.jsonl` field `clean_resid` (`blender_visual_qa/truth/run_bench.py:672-675, 687-688`). | When `row["clean_resid"] is False` on `CLEAN_BENCHES` (`B3`, `B5`), where `labels.label_frame` receives `resid=None` and collapses shading to `SHADE_BAND` (`blender_visual_qa/truth/run_bench.py:674`, `blender_visual_qa/truth/labels.py:223-224`). |
| 2 | `EDGE_BLEED` | Within 1 tile in Chebyshev distance (`max(\|tx - tx'\|, \|ty - ty'\|) <= 1`) of a truth-dirty tile (`tl in (3, 4, 5, 6, 9, 10, 11)` where `score.EXPECT[tl][0] == "dirty"`) in the same frame `f`. | `tiles_truth.bin` `tl` and `hdr` (`W, H, gw, gh, s, N`) (`blender_visual_qa/truth/score.py:30-40, 68, 78, 195`; `blender_visual_qa/truth/run_bench.py:68`); Morton grid coordinates `grid.tx`, `grid.ty`, `grid.order` (`tools/noise_rescore.py:209-216`); Chebyshev ring convention (`blender_visual_qa/truth/labels.py:32, 93-103`). | Only if truth tiles or grid dimensions are absent (which aborts unit loading). |
| 3 | `GLOBAL_EXPOSURE` | Frame `f` where the fraction of `STATIC` (`tl == 0`) tiles predicted dirty exceeds `global_exposure_threshold_ppm` (default `200000` ppm = 20%) **and** the engine frame row shows a global luma or drift signal. | `tiles_truth.bin` `tl` (`blender_visual_qa/truth/score.py:41, 78`); `vision/frames.jsonl` (`vqa.core-frame/v1`) histogram field `n[6]` (`score.C_DRIFT = 6`, `blender_visual_qa/truth/score.py:24`, `tools/noise_rescore.py:247-253`, `blender_visual_qa/truth/run_bench.py:434, 480-484`) or explicit frame-row luma/drift fields (`global_luma`, `global_luma_q4`, `luma_delta`, `luma_delta_q4`, `global_drift`, `drift_signal`). | `vqa.core-frame/v1` in `vision/frames.jsonl` persists `schema, frame, grid, n, cov_ppm, global_mv, regions, tiles_sha256` (`tools/noise_rescore.py:248-253`, `blender_visual_qa/truth/run_bench.py:434-438`) and does **not** persist `global_luma`. Reported `ABSENT` when `vision/frames.jsonl` is missing or lacks `global_luma` and `n[6]` is `0`. |
| 4 | `LIGHT_CHANGE` | Scene journal or manifest lists a `light` or `world` change on frame `f`. | `journal.json`, `scene.manifest.json`, or `<bench>.scene.json` field `animated[]` (`{"frame": int, "kind": "light"\|"world", "name": str}`) (`blender_visual_qa/truth/labels.py:33, 252-265, 288-294, 446-457`; `blender_visual_qa/truth/run_bench.py:126-148, 328-329, 361-362`). | Reported `ABSENT` when neither `journal.json` nor `scene.manifest.json` (nor `<bench>.scene.json`) is persisted in the unit directory or when `animated` is absent. Note `labels.ANIM_KINDS = ("material", "light", "visibility")` (`blender_visual_qa/truth/labels.py:33`) persists `"light"` but not `"world"`. |
| 5 | `AA_JITTER` | Static tile (`tl == 0`) whose engine class `cls` flips across consecutive frames (`f - 1` or `f + 1`) while both frames remain truth `STATIC` (`tl == 0`, no truth change). | `tiles_truth.bin` `tl` (`blender_visual_qa/truth/score.py:60-79`); consecutive-frame comparison (`blender_visual_qa/truth/score.py:198-205` `c1b_flips`); engine `cls` from `vision/tile_cls.jsonl` or `decode_regions` (`tools/noise_rescore.py:228-312`). | Reported `ABSENT` when `n_frames < 2` or when mixed-region unknown classes (`cls == -1`, `tools/noise_rescore.py:291-293`) prevent consecutive-frame class comparison. |
| 6 | `UNATTRIBUTED` | Residual static false dirty tiles not matching Rules 1–5. | `blender_visual_qa/truth/score.py:25, 41, 131`; still-noise context (`tools/still_noise_bound.py:80-122`). | Never `ABSENT` once `tl` and `cls` are known. |
