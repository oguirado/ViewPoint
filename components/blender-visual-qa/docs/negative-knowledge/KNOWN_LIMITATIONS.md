# Known Limitations and Deferred Audit Debt

## Deferred Limitations

During the audit and calibration phases of campaign `visual-qa-0`, several technical items were formally triaged and deferred to future releases. These represent accepted boundary debt that must not be claimed as resolved in version 1.0:

| ID | Scope | Current Documented Limitation | Consequence and Prohibited Claim | Mitigation and Closure Trigger | Evidence Status |
|---|---|---|---|---|---|
| **A-P1-5** | `reproducibility` | Run identity does not hash all stage code and prompt templates. | Prohibited: Claiming run ID cryptographically authenticates all pipeline algorithm bytes. | Mitigation: Record git commit hash alongside run receipt. Closure: Cryptographic binding of stage script and template hashes. | Open |
| **A-P2-6** | `platform` | Engine and renderer stack authentication beyond binary SHA-256 is deferred. | Prohibited: Asserting binary hash proves complete rendering driver/stack attestation. | Mitigation: Record host platform, renderer name, and driver version. Closure: Add GPU driver and Vulkan/GLES library integrity checks. | Open |
| **A-P2-8** | `capture` | Settling frames do not implement a true simulation physics freeze. | Prohibited: Claiming game simulation is completely paused during settling frames. | Mitigation: Narrow point selectors to avoid transitional settling intervals. Closure: Add engine physics-freeze hooks during settling. | Open |
| **A-P2-17** | `adapters` | Hook and probe headers are not proven equivalent to full HyperBook P-gate qualification. | Prohibited: Claiming header syntax lint qualifies runtime execution. | Mitigation: Inspect explicit execution logs and receipts. ## Release Boundary

These deferred limitations establish the strict boundary of the v1 release:
1. **Immutable Defect Debt**: No documentation writer or agent may claim these limitations are resolved without sealed implementation code and passing verification gates.
2. **Auditable Backlog**: Each limitation is tracked in `docs/negative-knowledge/limitations.json` and mapped to universal catalogue policy nodes.
3. **Safety Policy**: In the event of ambiguous visual evidence related to these scopes, the harness must fail closed or report `INCOMPLETE` rather than synthesizing an artificial verdict.
