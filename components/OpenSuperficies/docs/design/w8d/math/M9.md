### PM-122.1 · stmt-thm-main

> **Theorem 1** (Uniform trace reconstruction). *There exist absolute constants $C,c\ge1$ and one randomized multitape Turing machine $\mathcal A$ with the following property. For every $n\ge2$, every rational $p\in(0,1]$, and every $x\in\{0,1\}^n$, given $n,p$ in binary and access to independent ordinary deletion traces of $x$, the machine requests at most $$M_C(n,p)=\left\lceil\exp\bigl(CB(n,p)\bigr)\right\rceil$$ traces, outputs an element of $\{0,1\}^n$, and returns $x$ with probability at least $2/3$.*
> 
> *For every internal random-bit sequence and every well-formed trace stream of strings of length at most $n$, it halts within $$\bigl(n+L+M_C(n,p)\bigr)^c$$ bit operations. This bound includes preprocessing, all parameter and finite-precision calculations, every received trace bit and delimiter, and the output. The only oracle operation is the external generation of the independent deletion traces.*

### PM-122.2 · stmt-auto-thm-1

Source: [papers/EN-114-000-0007-2-2026-PR-T4-UK-EX-M1-B-AL-M-0259_PM-122.2_A_latest_anchor_induction_with_spectrally_compact_masks_for_worst_case_trace_reconstruction.md:2057](/home/user/Documentos/math-router/papers/EN-114-000-0007-2-2026-PR-T4-UK-EX-M1-B-AL-M-0259_PM-122.2_A_latest_anchor_induction_with_spectrally_compact_masks_for_worst_case_trace_reconstruction.md:2057); anchor `stmt-auto-thm-1`.

> **Theorem 1**. *For integer $n\ge 2$ and $0<p\le1$, worst-case trace reconstruction of binary strings is possible in this channel with at most $$\exp\!\left(O\!\left(p^{-1}(\log n)^3(1+\log\log(2n))^6\right)\right)$$ traces, with an absolute constant. Write $q=1-p$. More finely, when $q>0$, setting $\mathcal X=1+\log n/(1+\log(1/q))$, the logarithm of the required sample budget is at most $$O\big(p^{-1}(\log n)\mathcal X^2 (1+\log\mathcal X)^6\big)$$ with an absolute constant. In particular for fixed $\varepsilon>0$ and $0\le q\le n^{-\varepsilon}$ the number of traces can be polynomial in $n$ (with parameters of the polynomial allowed to depend on $\varepsilon$). The same asymptotic bounds also suffice for strings with general symbols (assuming exact observation of retained symbols). This concerns sample complexity, not computational efficiency.*

## Plain terms

The uniform theorem claims randomized reconstruction of a fixed binary string from many independent deletion traces with known retention probability and length. The companion statement explicitly concerns sample complexity rather than computational efficiency [CITED]. Neither reconstructs an arbitrarily overwritten log ring deterministically.

## Application to the W8 decision

Informs deterministic reconstruction of execution histories and root-cause failure signatures from truncated or noisy capsule log rings (hits PM-122.1, PM-122.2).

Dedup/history proposal [TARGET]: encode each lifecycle event with attempt identity, monotone integer sequence number, event type and canonical payload identity. Validate consecutive sequence numbers; merge retained segments by sequence number only when overlaps agree exactly. Record missing intervals and conflicting payload identities explicitly. Root-cause classification may use verified surviving events but must return indeterminate when a required predecessor is missing. To evaluate the cited deletion model offline, keep a complete fixed reference stream and independently generate deletion traces with a recorded random tape, comparing reconstructed output to the reference; this is a model experiment, not a recovery guarantee for live rings.

## Limits: when this does not apply

Ring overwrites are contiguous, history-dependent losses, not independent deletions of the same fixed string. Rerunning nondeterministic attempts generally generates different source histories. Unknown length or retention, substitutions, inserted events and adversarial truncation are outside the quoted channel. Fixing randomness for replay does not convert a probability-of-success theorem into guaranteed deterministic recovery. Never synthesize missing authoritative events.
