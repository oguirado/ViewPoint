### PM-124.1 · stmt-thm-main

Source: [papers/EN-114-000-0022-2-2026-PR-T4-UK-EX-M1-B-ML-H-0261_PM-124.1_A_Polynomial_Time_Algorithm_for_Three_Machine_Unit_Job_Scheduling.md:3465](/home/user/Documentos/math-router/papers/EN-114-000-0022-2-2026-PR-T4-UK-EX-M1-B-ML-H-0261_PM-124.1_A_Polynomial_Time_Algorithm_for_Three_Machine_Unit_Job_Scheduling.md:3465); anchor `stmt-thm-main`.

> **Theorem 1**. *Let an explicitly listed finite directed acyclic graph specify the precedence constraints on $n\ge1$ nonpreemptive unit-length jobs on three identical machines. There is a uniform deterministic algorithm that constructs a feasible schedule of minimum makespan. Given also an integer deadline $1\le T\le n$, it decides feasibility exactly and returns a schedule whenever the answer is affirmative. Both tasks can be performed in $O((L+2)^{150020})$ steps on a deterministic multitape Turing machine, where $L$ is the total binary input length.*

## Plain terms

The manuscript claims an exact deterministic polynomial algorithm for precedence-constrained, nonpreemptive unit jobs on three identical machines [CITED]. Its displayed exponent is 150020 [CITED]; polynomial existence is not a usable latency promise.

## Application to the W8 decision

Informs deterministic polynomial-time wave scheduling and task-to-seat assignment across heterogeneous worker lanes (hits PM-124.1).

Scheduler proposal [TARGET]: represent precedence by integer indegrees; sort ready task IDs canonically; scan seats by stable seat ID and dispatch only tasks whose dependencies have verified completion receipts and whose integer resource vector fits. Update indegrees only after a receipt passes. Reserve before dispatch and release only after verified teardown. For a small homogeneous unit-job fixture, enumerate ready subsets and memoize completed-task bitsets to obtain an exact minimum-slot oracle; compare the operational scheduler to that oracle. This finite exponential oracle is a validation instrument, not the cited polynomial algorithm.

## Limits: when this does not apply

Heterogeneous seats, unequal runtimes, preemption, setup costs, resource vectors, dynamic arrivals and quarantine are outside the theorem. No optimal makespan claim transfers to W8. The unusually large exponent also precludes adopting the existence theorem as a practical scheduler.
