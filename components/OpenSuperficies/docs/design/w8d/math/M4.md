### PM-111.1 · stmt-thm-main

Source: [papers/EN-114-000-0022-2-2026-PR-T4-UK-EX-M1-B-ML-H-0240_PM-111.1_One_Sample_Suffices_for_Matroid_Prophet_Inequalities_against_an_Almighty_Adversary.md:3450](/home/user/Documentos/math-router/papers/EN-114-000-0022-2-2026-PR-T4-UK-EX-M1-B-ML-H-0240_PM-111.1_One_Sample_Suffices_for_Matroid_Prophet_Inequalities_against_an_Almighty_Adversary.md:3450); anchor `stmt-thm-main`.

> **Theorem 1**. *There is a measurable online selection rule, independent of the value distributions, with the following property. Let $M=(E,\mathcal I)$ be any finite known labeled matroid, and let $(S_e,V_e:e\in E)$ be mutually independent nonnegative real random variables, with $S_e$ and $V_e$ having the same arbitrary law $D_e$. Assume $\mathbb E[\mathop{\mathrm{OPT}}_M(V)]<\infty$. The rule receives exactly the sample vector $S$ before arrivals and uses a seed $R$ independent of $S,V$.*
> 
> *For every measurable permutation rule $\pi$ depending on $M$, the laws $(D_e)$, $S$, $V$, and $R$, the rule accepts an independent set $A$, irrevocably deciding at each arrival using only the available history, and <a id="eq:main"></a>$$\label{eq:main}
>  \mathbb E\left[\sum_{e\in A}V_e\right]
>        \ge 2^{-310}\mathbb E[\mathop{\mathrm{OPT}}_M(V)].$$*

## Plain terms

The claimed online rule uses an independent training sample and fresh independent values for each element of a known matroid, plus independent algorithmic randomness. Its expected fraction is 2^{-310} [CITED], a mathematical existence claim rather than a useful engineering target.

## Limits: when this does not apply

Knapsack or intersected multi-resource budgets need not satisfy matroid exchange. Correlated task values, reused or biased samples, changing ground sets and unbounded unknown costs violate the quoted model. This theorem selects tasks; it does not establish a statistically valid early-stopping test or guarantee value for the proposed deterministic threshold.
