## Ordered evidence contract

`NewAggregatorEvidence(manifest, snapshots)` freezes two independently supplied records and implements **exactly** the `certificate.AggregatorPort` methods `Manifest() (certificate.Manifest, error)` then `Snapshots() ([]certificate.Snapshot, error)` (`src/w8wave/certificate/certificate.go:1454-1459`). `NewHarvestEvidence(account)` freezes independent harvest accounting and implements **exactly** `Account() (certificate.HarvestAccount, error)` (`certificate.go:1461-1475`). `proto1cert.Evaluate(agg, harv)` accepts these or any other conforming read-only ports, reads each once, makes private copies and passes the copies to **`certificate.EvaluateFromPorts`** (`certificate.go:1477-1505`). It does not compute success or cleanup separately. A `nil` error is not a success attestation: callers must examine `report.Outcome`, the gate bits and reasons.

The full `Manifest` field order and types are `ManifestSHA256 string`, `Epoch uint64`, `Units []Unit`, `CarriedWeight uint64`, `CarriedUnitIDs []string`, `TrustRoot string`, `PreviousEpoch uint64`, `RevokedEpoch uint64` (`certificate.go:225-234`). `Snapshot` retains `Seq uint64`, `Units []Unit`, `States map[string]UnitState`, `ReportedR *int64` in this order; either unit representation can be supplied when valid (`certificate.go:236-244`). The `HarvestAccount` field order is `Stages []StageFlow`, `Origin OriginEvidence`, `Coverage CoverageEvidence`, `Stall StallInput`, `UnresolvedRevocations uint64`, `UnresolvedViolations uint64`, `DeadlineViolations uint64` (`certificate.go:1461-1470`). No counter is intentionally truncated or forced to zero. Copies include carried IDs, unit slices, state maps, residual pointers, stage slices, coverage source slices and nested tick slices. No frame bytes, encoding, transport or journal are persisted by Area A.

Presence validation is **additional source hygiene, not an alternate gate**: missing aggregator/harvest ports (including typed nil), empty manifest hash/obligation inventory, blank obligation IDs, absent snapshots or states, missing stage names, missing independent harvest origin trust root, missing monitor source/sequence/boot ID or zero stall threshold return `*certificate.Error` (code 2, `REQUIRED_MISSING`). The manifest digest must have the 64-byte lowercase hex textual shape (code 2 `TYPE_ERROR`), and a zero obligation weight is refused (code 2 `ZERO_WEIGHT`). There is no implicit empty-passing record. Duplicate IDs, invalid origins, coverage gaps and other semantic gate failures still go through the real evaluator with its original selected reason. The source's richer coverage contract includes source ID, tick sequence, clock, boot, counter, billed and covered ticks plus duplicate, clock regression, uncovered ticks, counter reset, open lease and unfenced-member counters (`certificate.go:527-559,788-857`). Each stage is conserved independently (`certificate.go:517-525,878-908`). Accepted `P` requires all four evidence bits and independent origin evidence (`certificate.go:203-221,911-945`).

## Refusal taxonomy and accounting distinction

| Condition | Normalized code or gate reason | Result semantics |
| --- | --- | --- |
| Missing required typed port/field | `rc=2`, `REQUIRED_MISSING` | error, no report minted |
| External unavailable authority | preserves typed `rc=4` | error, no report minted |
| Producer verification failure or unknown untyped error | preserves typed `rc=5`, or normalizes to `rc=5 VERIFIER_REJECTION` | error, no report minted |
| Timed-out/cancelled or typed uncertain cleanup | `rc=6 BLOCKED_EVIDENCE` | error, no report minted |
| Duplicate obligation | `SCHEMA=0 DUPLICATE_KEY` | `INDETERMINATE` |
| Skipped monitor interval | `COVERAGE=0 SEQ_GAP` | `INDETERMINATE` |
| Local stage deficit | `CONTINUITY=0 STAGE_CONSERVATION_VIOLATION` | `INDETERMINATE` |
| Forged pass bit | `ORIGIN=0 MISSING_EVIDENCE_BIT` | `INDETERMINATE` |
| Open lease / unfenced or unclean member | `COVERAGE=0 OPEN_LEASES` / `UNFENCED_OR_UNCLEAN_MEMBERS` | `INDETERMINATE` |
| Unresolved revocation, violation, deadline | `SUCCESS=0 UNRESOLVED_REVOCATIONS` / `UNRESOLVED_VIOLATIONS` / `DEADLINE_VIOLATIONS` | `INDETERMINATE` |
| Unclear residual activity | `WARNINGS=0 STALL_ACTIVITY_UNKNOWN` | `INDETERMINATE` |
| Valid fully accounted terminal failure | `SUCCESS=0 ACCOUNTED_FAILURES_PRESENT`, `rc=5` | `DONE_ACCOUNTED_FAILURE`, **not** success |
| All required gates, verified passes and no unresolved counter | `SUCCESS=1 OK`, `rc=0` | `DONE_SUCCESS` |

These are not interchangeable: `certificate.ResultExitCode` is `0/5/4/6` for success/accounted failure/blocked/indeterminate respectively (`certificate.go:187-200`); typed `certificate.Error`/`ExitCode` are defined at `certificate.go:150-185`. The evaluator orders schema, identity+coverage, integer ranges, stage continuity, origin, monotone lineage, warnings, lease closure and success (`certificate.go:1088-1197`). The outcome rule distinguishes **R=0 and no failure** from **A=0 and terminal failures exactly explain R>0** (`certificate.go:1258-1331`). No cleanup or publication API is exported by `proto1cert`.

## Frozen finite budget and independent acceptance evidence

The unit ledger is frozen before evaluation. For exactly **N** supplied obligation IDs, the Area A TARGET lineage budget is at most **1+2N** snapshots (one baseline and at most queued→running→terminal transitions), with zero retries or sleeps; a longer lineage refuses `rc=2 RANGE_ERROR`. The policy may reject noisy producer heartbeats; evidence must be pre-compacted by its independently trusted producer. It is **not** a measured throughput or VM time. The data and deterministic gate evaluation are finite. No wall-clock value in a test is a measurement.

## Producer limits, absence and outside-grant defects

The bound aggregator file provides its own digest, canonical repro and deduplication structures (`src/w8wave/aggregator/aggregator.go:1-48,68-145`) but **no proven `certificate.AggregatorPort` adapter** in that bound file: adapter capabilities **AUSENTE**. The bound harvest file supplies typed wave, attempt, stage and freeze machinery (`src/w8wave/harvest/types.go:20-37,54-105,113-149`) but **no proven `certificate.HarvestAccountPort` adapter** in that file: adapter capabilities **AUSENTE**. No future PROTO1 adapter, producer-run receipt, real monitor authority, host cleanup proof, measured budget or transport was invented. These synthetic tests are projections and cannot certify host-side receipt authenticity.

**PRODUCTION_DEFECT (outside write grant):** `src/w8wave/certificate/certificate.go:1494-1505` constructs `EvaluationInput` from ports without transporting `SchemaStats`; absent parser evidence therefore becomes zero-valued stats at `certificate.go:655-669`, indistinguishable from a fully validated source. Also, `certificate.go:878-894` checks each stage's own conservation but not cross-stage linkage. Area A requires nonempty stages and structurally present evidence but cannot repair these evaluator/producer protocol gaps without a new contract. Numerically optional/non-pointer zero-valued counters in `HarvestAccount` cannot prove whether a producer *explicitly supplied* zero or omitted the field; producer presence attestation remains **AUSENTE**. Preserve this uncertainty rather than invent a zero-backed authority. Host VM acceptance must be rerun after a source-bound producer verification receipt; no merge or acceptance is implied by a PR.
