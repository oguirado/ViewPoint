# Oracle label pipeline specification

## 1. Sampler and actuator timebase

**S01 — START contract.** `read_start(run_dir)` opens `START` using `O_RDONLY | O_NOFOLLOW | O_NONBLOCK`, requires a regular file with one link and size at most 4096 bytes, parses an object, and requires schema `os.cu.wlcap-start/v1`, clock `CLOCK_MONOTONIC`, and a strictly positive `t0_ns` whose Python type is exactly `int`. (`bench/oracle/sampler.py:28-47`)

**S02 — Optional run nonce.** A present `run_nonce` must be a string of exactly 32 lowercase hexadecimal characters; omission is accepted. (`bench/oracle/sampler.py:17`, `bench/oracle/sampler.py:48-50`)

**S03 — Timestamp placement.** The sample timestamp is `(now_ns - t0_ns) // 1000`, using the supplied clock callable and epoch, and `sample(seq)` obtains it before its snapshot and accessibility requests. (`bench/oracle/sampler.py:53-54`, `bench/oracle/sampler.py:160-162`, `bench/oracle/sampler.py:235-243`)

**S04 — Collection and transport.** Setup requests flattened automatic attachment without pausing, accepts a page attachment with the requested scene URL and a session ID, and enables Accessibility, DOMSnapshot, Page, and layout-shift PerformanceTimeline events. (`bench/oracle/sampler.py:185-190`, `bench/oracle/sampler.py:222-233`)
The sample requests a DOM snapshot with `visibility`, `opacity`, and `display`, requests the full AX tree, drains pending events, and emits one row. (`bench/oracle/sampler.py:14`, `bench/oracle/sampler.py:235-243`)
The FIFO adapter rejects symlinks and non-FIFOs; outbound messages are compact sorted-key JSON followed by NUL, and the reader retains partial input, parses complete frames, and rejects an oversized undelimited frame. (`bench/oracle/sampler.py:57-77`, `bench/oracle/sampler.py:80-105`)

**S05 — Tracked geometry.** Row construction uses the first snapshot document and its layout nodes, filters by decoded DOM `id` when a tracking set is supplied, and represents retained nodes as `[backendNodeId, x, y, width, height, visible, content_hash]`. (`bench/oracle/sampler.py:117-137`)
`Sampler` defaults to the IDs `box`, `cv`, `caret`, and `f1`, whereas the direct `row_from_snapshot(..., track_ids=None)` helper does not apply this filter. (`bench/oracle/sampler.py:15-16`, `bench/oracle/sampler.py:117-130`, `bench/oracle/sampler.py:160-164`)
The visibility entry is zero for the returned style strings `hidden`, `0`, or `none` in their respective visibility/opacity/display positions, and one otherwise. (`bench/oracle/sampler.py:133-137`)

**S06 — Numeric normalization.** `_int` preserves exact Python integers, converts integral floats without setting the fractional flag, and otherwise sets that flag and returns `int(round(value))`; node bounds, shift rectangles, and scroll offsets use this conversion. (`bench/oracle/sampler.py:108-114`, `bench/oracle/sampler.py:135`, `bench/oracle/sampler.py:147-153`)
Thus `frac == 0` is the implemented cleanliness signal, not proof that every original numeric payload value had Python type `int`. (`bench/oracle/sampler.py:108-114`, `bench/oracle/labels_oracle.py:173`)

**S07 — Fingerprints and row fields.** The node hash is FNV-64 over decoded node type/name/value/attribute data, and the snapshot fingerprint hashes retained-node records containing backend IDs, original bounds representations, visibility, and those node hashes. (`bench/oracle/sampler.py:18-25`, `bench/oracle/sampler.py:127-141`)
The row contains `seq`, `t_us`, `snap`, `nodes`, `sx`, `sy`, `focus`, `shifts`, `frac`, and `canv`; an equal previous fingerprint sets only `nodes` to null, and the sampler updates its previous fingerprint after constructing the row and before returning it. (`bench/oracle/sampler.py:151-153`, `bench/oracle/sampler.py:240-243`)

**S08 — Focus, canvas, and shifts.** `focus` is null or the string ID of the first AX node with a `focused` property whose nested value is the boolean `True`, and `canv` contains backend IDs of retained nodes named `CANVAS`. (`bench/oracle/sampler.py:139-146`)
Each collected layout-shift source supplies previous/current rectangles, an integer node ID or fallback zero, and integer `ri` derived from `hadRecentInput`; a sample consumes the accumulated shifts and clears the list. (`bench/oracle/sampler.py:147-157`, `bench/oracle/sampler.py:191-197`, `bench/oracle/sampler.py:235-241`)

## 3. Grid and rectangle geometry

**G01 — Grid selection.** Start with tile size `s = 16`, compute `gw = ceil(W/s)` and `gh = ceil(H/s)` using integer ceiling division, and double `s` until `gw * gh <= 4096` and both axes are at most `255`; failure to find a candidate through `s = 2**16` raises `ValueError("grid")`. (`bench/oracle/labels_oracle.py:24`, `bench/oracle/labels_oracle.py:31-39`)

**G02 — Dense Morton rank.** `morton(tx,ty)` interleaves the low eight coordinate bits with x in even positions and y in odd positions, then `_order` sorts only the cells in the selected viewport grid and enumerates them to obtain dense ranks `0..gw*gh-1`. (`bench/oracle/labels_oracle.py:42-58`)
`order_table` returns a copy of that rank mapping; tile IDs are the dense ranks, rather than the possibly sparse raw interleaved codes. (`bench/oracle/labels_oracle.py:54-63`)

**G03 — EXT intersection.** A tile is included for strict positive-area overlap with `[x,y,w,h]`, using covered-pixel endpoints `x+w-1` and `y+h-1` and grid-clamped tile bounds; nonpositive width or height returns no tiles. (`bench/oracle/labels_oracle.py:66-75`)

**G04 — Clip and STRADDLE.** Before constructing a label, the emitter clips all rectangles to `[0,0,W,H]`, discards empty intersections, and omits the entire label when none survive. (`bench/oracle/labels_oracle.py:88-91`, `bench/oracle/labels_oracle.py:145-148`)
It adds `STRADDLE` if any surviving rectangle has an edge strictly inside the frame that is not divisible by `s`; an edge on a frame border is excluded from that predicate. (`bench/oracle/labels_oracle.py:78-85`, `bench/oracle/labels_oracle.py:149-152`)

## 4. Sample pairs, intervals, and confidence

**T01 — Pair state.** `derive` validates strict-integer `seq`, `t_us`, `sx`, `sy`, and `frac`, supplies missing `shifts`, `canv`, and `focus` defaults, sorts operations by `t_us`, and traverses consecutive samples in their supplied order. (`bench/oracle/labels_oracle.py:130-139`, `bench/oracle/labels_oracle.py:160-169`)
The initial node state is the first row's nodes or an empty list, and a later null `nodes` value carries forward the previous node state. (`bench/oracle/labels_oracle.py:168-170`)

**T02 — Operation bracket and frame interval.** For a pair `(a,b)`, the bracket includes operations with `a.t_us < op.t_us <= b.t_us`, excluding operations whose type is `move`. (`bench/oracle/labels_oracle.py:165-171`)
Writing `F(t)` for the invoked `L2.frame_of(t)`, a nonempty bracket produces `[F(first_op.t_us), F(first_op.t_us)+1)`; an empty bracket produces `[F(a.t_us), F(b.t_us)+1)`. (`bench/oracle/labels_oracle.py:172-179`)

**T03 — Imported definitions: AUSENTE.** The general implementation of `L2.frame_of`, the defining value of `L2.ALIAS_FRAMES`, and the general implementation of vertical `L2.exposed_strip` are AUSENTE from the bound implementation files because the producer imports these helpers. (`bench/oracle/labels_oracle.py:16`, `bench/oracle/labels_oracle.py:172-174`, `bench/oracle/labels_oracle.py:192-193`)
The bound scroll test asserts the particular frame calculation `1010000 * 60 // 1000000` and vertical-strip examples, and the bound cross-check test exercises a one-frame tolerance; these are test expectations rather than a reproduced implementation of the imported helpers. (`bench/oracle/tests/test_labels_oracle.py:58-79`, `bench/oracle/tests/test_crosscheck.py:43-56`)

**C01 — Cleanliness and adjacency.** `clean` means both sample `frac` values are zero, while `adjacent` means `b.seq == a.seq + 1` and `F(b.t_us) - F(a.t_us) <= L2.ALIAS_FRAMES`. (`bench/oracle/labels_oracle.py:173-174`)

| Rule | Label category | Exact condition; otherwise derived |
|---|---|---|
| C02 | Ordinary scroll | `clean` and exactly one bracketed non-`move` operation; this branch does not additionally require `adjacent`. (`bench/oracle/labels_oracle.py:180`, `bench/oracle/labels_oracle.py:182-188`) |
| C03 | Node changes and layout shifts | `clean` and either exactly one bracketed operation or an empty bracket with `adjacent`; the one-operation alternative likewise does not require adjacency. (`bench/oracle/labels_oracle.py:181`, `bench/oracle/labels_oracle.py:201-233`) |
| C04 | Smooth scroll | `clean`, at most one bracketed operation, `adjacent`, and either a nonempty bracket or any non-`move` operation at or before `b.t_us`; this historical-cause check does not restrict the operation to a scroll type or current gesture. (`bench/oracle/labels_oracle.py:184-188`) |
| C05 | Forced derived cases | An unchanged-bounds hash mutation for a current canvas ID, configured caret/focus labels, and configured cursor labels are always derived. (`bench/oracle/labels_oracle.py:203-206`, `bench/oracle/labels_oracle.py:234-252`) |

The canvas override applies specifically to its unchanged-bounds hash-change branch; canvas movement or resize takes the general node confidence, and `UNOBSERVABLE` is assigned independently of confidence. (`bench/oracle/labels_oracle.py:201-222`)
The operator-page description of integer payloads and bracketed operations does not implement additional checks; the conditions above are the actual producer branches. (`docs/CU_W6A.md:17-18`, `bench/oracle/sampler.py:108-114`, `bench/oracle/labels_oracle.py:173-188`)

## 5. Emitted classes, flags, and motion

Every emission below passes through the clipping-and-drop behavior G04, including configured caret and cursor geometry. (`bench/oracle/labels_oracle.py:145-157`, `bench/oracle/labels_oracle.py:242-252`)

**E01 — Class boundary.** The producer admits only class `2` CHANGED, class `3` MOVED, and class `4` FLICKER; UNCHANGED, JITTER, FROZEN, and DRIFT are named as never emitted, and the validator rejects the other class IDs `0`, `1`, `5`, and `6` exercised by the bound test. (`bench/oracle/label_schema.json:14`, `bench/oracle/labels_oracle.py:20`, `bench/oracle/labels_oracle.py:112-113`, `bench/oracle/tests/test_labels_oracle.py:287-292`)

**E02 — Scroll geometry.** For scroll-offset differences `dx = b.sx-a.sx`, `dy = b.sy-a.sy`, a nonzero change emits MOVED only when `abs(dx) < W` and `abs(dy) < H`, over `[max(0,-dx), max(0,-dy), W-abs(dx), H-abs(dy)]` with `mv = [-dx,-dy]`. (`bench/oracle/labels_oracle.py:182-190`)
The same change emits CHANGED with null `mv`, including a vertical strip from `L2.exposed_strip` only when `dy != 0` and a horizontal strip only when `dx != 0`; that horizontal strip has width `min(W,abs(dx))` at the right edge when `dx > 0` or left edge otherwise, and both label kinds use source `scroll` and reference `document`. (`bench/oracle/labels_oracle.py:190-197`)
Scroll CHANGED starts with an empty explicit flag list, so it does not add `UNCOVERED`; the common emitter can still add `STRADDLE`. (`bench/oracle/labels_oracle.py:149-151`, `bench/oracle/labels_oracle.py:197`)

**E03 — Same-bounds node mutation.** Node comparison considers IDs present in both previous and current node maps, and identical bounds with a changed content hash produce CHANGED over current bounds, source `mutation`, and the node ID as a string reference. (`bench/oracle/labels_oracle.py:198-207`)

**E04 — Node translation and uncovered regions.** Changed position with unchanged dimensions produces MOVED over current bounds, source `window`, node ID string reference, and current-minus-previous displacement. (`bench/oracle/labels_oracle.py:198-210`)
It also submits CHANGED rectangles with null `mv` and `UNCOVERED`, using widths/heights capped by the node dimensions and the strip-position formulas below; horizontal and vertical rectangles are accumulated separately when both coordinates change. (`bench/oracle/labels_oracle.py:211-218`)
For positive horizontal displacement the strip starts at the previous left edge, and for negative horizontal displacement it starts at the current right edge; positive vertical displacement uses the previous top edge and negative vertical displacement uses the current bottom edge. (`bench/oracle/labels_oracle.py:212-217`)

**E05 — Node resize.** Different dimensions produce CHANGED over the bounding rectangle enclosing previous and current bounds, with source `mutation`, null `mv`, and the node ID string reference. (`bench/oracle/labels_oracle.py:219-222`)

**E06 — Layout-shift labels.** A shift in the current row with truthy `ri` is skipped; otherwise unchanged dimensions with nonzero position displacement produce MOVED over current bounds, while any other differing old/new rectangle produces CHANGED over their enclosing bounding rectangle. (`bench/oracle/labels_oracle.py:223-233`)
These labels use source `layoutshift`, the shift node ID string as reference, current-minus-previous translation for MOVED, and null `mv` for CHANGED. (`bench/oracle/labels_oracle.py:226-233`)

**E07 — Caret and focus intervals.** A truthy configured `caret_rect` enables one derived FLICKER label for each contiguous interval of the same non-null focus value, closing it on focus change or the final sentinel. (`bench/oracle/labels_oracle.py:234-245`)
The interval starts at the first focused sample's frame and ends at the greater of one frame after that start or one frame after the last sample with that focus; the label uses source `focus`, that focus value as reference, the configured rectangle, null `mv`, and the supplied optional `period_ms`. (`bench/oracle/labels_oracle.py:239-245`)
A persistent autofocus value can therefore produce one label without a focus transition, while an omitted caret rectangle produces no caret label. (`bench/oracle/labels_oracle.py:234-245`, `bench/oracle/tests/test_labels_oracle.py:241-247`)

**E08 — Pointer labels.** A `move` operation and truthy configured `cursor_px` produce one derived CHANGED label over `[x,y,cursor_px,cursor_px]` for `[F(op.t_us),F(op.t_us)+1)`, with null `mv`, `POINTER`, source `pointer`, and null reference; missing or noninteger x/y raises `ValueError`. (`bench/oracle/labels_oracle.py:246-252`)

| Rule | Flag | Emission boundary |
|---|---|---|
| E09 | `STRADDLE` | Added by the common emitter for the clipped interior-edge rule G04. (`bench/oracle/labels_oracle.py:145-151`) |
| E10 | `UNCOVERED` | Added to the CHANGED rectangles computed for same-size node movement. (`bench/oracle/labels_oracle.py:208-218`) |
| E11 | `UNOBSERVABLE` | Added to node-comparison labels when the current node visibility entry is false, without changing the separately selected confidence. (`bench/oracle/labels_oracle.py:201-222`) |
| E12 | `POINTER` | Added to the configured cursor label. (`bench/oracle/labels_oracle.py:246-252`) |

**E13 — Nonemission and unknown behavior.** Flags outside the four-name set are rejected, and although `animation` is an accepted source, an `animation` emission branch is AUSENTE in `derive`. (`bench/oracle/labels_oracle.py:21-22`, `bench/oracle/labels_oracle.py:121-125`, `bench/oracle/labels_oracle.py:182-252`)
Direct appearance/removal labels are AUSENTE from the node loop because it iterates the ID intersection; with identical bounds and hash, a visibility change alone does not enter an emission branch. (`bench/oracle/labels_oracle.py:198-207`)
An independent observation of canvas pixels or caret blink phase is AUSENTE from the sampler and these label branches: the former records DOM metadata, while the latter uses supplied caret geometry and focus. (`bench/oracle/sampler.py:127-153`, `bench/oracle/labels_oracle.py:203-206`, `bench/oracle/labels_oracle.py:234-245`)

**M01 — One motion convention.** `mv = [dx,dy]` always means the pixel translation of previous content: scroll negates scroll-offset differences, whereas node translation and layout shifts subtract previous position from current position. (`bench/oracle/labels_oracle.py:4`, `bench/oracle/labels_oracle.py:182-190`, `bench/oracle/labels_oracle.py:208-210`, `bench/oracle/labels_oracle.py:226-229`)

**M02 — Gesture-distance helper.** `smooth_gesture_sums` considers MOVED scroll labels only, accumulates `-mv[1]`, and starts another group when the next relevant `f0` exceeds the previous relevant `f1 + 2`. (`bench/oracle/labels_oracle.py:256-266`)

## 6. Cross-check against prereg labels

**X01 — Prereg selection and pins.** The cross-check selects v2 for `WL-7` and `WL-2b`, obtains v3 item membership from `L3.ORDER`, and rejects an item outside both sets. (`bench/oracle/crosscheck.py:23-24`, `bench/oracle/crosscheck.py:98-100`)
It selects the v2 manifest with expected `L3.PARENT_SHA256` or the v3 manifest with expected `L3.PINNED_PREREG_V3_SHA256`, compares `L2.prereg_sha256(manifest)` to that pin, and raises an error with rc `5` on mismatch. (`bench/oracle/crosscheck.py:86-95`)
Generation uses the selected module's `labels_for` without actuator rows or `labels_from_act` with supplied actuator rows; errors preserve an available exception rc and otherwise use `5`. (`bench/oracle/crosscheck.py:98-106`)
The complete v3 item list, manifest contents, literal pin values, and implementations of prereg hashing and generation are AUSENTE from the bound implementations because they are imported or read from other files. (`bench/oracle/crosscheck.py:14-24`, `bench/oracle/crosscheck.py:86-106`)

**X02 — Cross-check input validation.** The checker requires `f0`, `f1`, `rects`, `ideal`, `mv`, `flags`, and `confidence`, but accepts additional keys; frame fields and `ideal` must be strict integers, with `ideal` in `0..6`. (`bench/oracle/crosscheck.py:22-25`, `bench/oracle/crosscheck.py:34-42`)
`rects` must be a nonempty list of four-integer lists, `mv` null or a two-integer list, `flags` a list, `confidence` exact or derived, and a present non-null `period_ms` a strict integer. (`bench/oracle/crosscheck.py:43-52`)
Producer-level closure, nonnegative/ordered frames, rectangle extent constraints, flag membership, and the MOVED/non-null relationship are AUSENTE from this checker, which performs its own partial validation rather than calling `validate_label`. (`bench/oracle/crosscheck.py:25-52`, `bench/oracle/labels_oracle.py:98-127`)
`load_oracle` parses nonblank JSONL lines and converts I/O/JSON errors to `XCError`; empty input is rejected unless `allow_empty` is true. (`bench/oracle/crosscheck.py:55-73`)

**X03 — Class mapping and candidate geometry.** Prereg `NOT_CHANGED` maps to `0`, `CHANGED` and `CHANGED_REGION` to `2`, `MOVED` to `3`, and `FLICKER` to `4`. (`bench/oracle/crosscheck.py:21`)
For nonzero prereg classes, only exact oracle rows are candidates, and a compatible row must have the same class, satisfy `abs(oracle.f0 - prereg.frame) <= ALIAS_FRAMES`, and contain at least one individual rectangle whose positive integer intersection area equals its union area with the prereg rectangle, giving IoU exactly one. (`bench/oracle/crosscheck.py:118-124`, `bench/oracle/crosscheck.py:131-136`, `bench/oracle/crosscheck.py:151`, `bench/oracle/crosscheck.py:166-168`)
The matcher does not use `f1` or combine oracle rectangles into a union for this predicate; the alias value is imported from `L2`. (`bench/oracle/crosscheck.py:20`, `bench/oracle/crosscheck.py:131-144`)

**X04 — Motion and period checks.** A non-pointer MOVED match requires `mv = [k*(dx or 0), k*(dy or 0)]`, where `k = -1` for prereg target `content` and `k = 1` otherwise; pointer MOVED skips this equality check. (`bench/oracle/crosscheck.py:137-139`)
Class `2` requires oracle `mv` to be null, and class `4` requires equal `period_ms` only when the prereg period is non-null; flags are not matching requirements. (`bench/oracle/crosscheck.py:140-144`)

**X05 — One-to-one matching.** Prereg rows are processed in order, choosing the unused compatible exact row with the smallest absolute start-frame difference and retaining the first candidate on a tie. (`bench/oracle/crosscheck.py:157-177`)
A match consumes the whole oracle row once, an unmatched prereg row increments `prereg_only`, and `oracle_only` counts unused exact rows; derived rows are counted separately and never consumed as pair matches. (`bench/oracle/crosscheck.py:151-178`, `bench/oracle/crosscheck.py:202-204`)

**X06 — NOT_CHANGED surround exception.** A class-0 prereg rectangle agrees if no exact nonzero oracle row has positive-area overlap with it, using all exact rows without a frame-tolerance check or oracle-row consumption. (`bench/oracle/crosscheck.py:127-128`, `bench/oracle/crosscheck.py:151-165`)
Derived rows therefore cannot block this absence-of-overlap agreement, and a derived-only input can still receive class-0 agreement even though no derived row becomes a paired match. (`bench/oracle/crosscheck.py:151-165`, `bench/oracle/tests/test_crosscheck.py:128-138`)
An explicit exact class-0 oracle row is not consumed by this path and remains in `oracle_only`. (`bench/oracle/crosscheck.py:160-178`)

**X07 — Per-class support.** Ordinary `compare` reports classes `0,1,2,3,4,5,6`, each with `oracle_exact`, `oracle_derived`, `prereg`, `agree`, and `status`, where status is `untested` exactly when `oracle_exact + oracle_derived + prereg == 0` and `tested` otherwise. (`bench/oracle/crosscheck.py:22`, `bench/oracle/crosscheck.py:179-184`)
`tested` therefore reports support presence and does not establish exact evidence or agreement, as the derived FLICKER case explicitly demonstrates. (`bench/oracle/crosscheck.py:179-184`, `bench/oracle/tests/test_crosscheck.py:128-138`)
The producer's nonemitted classes must not be assigned successful oracle support merely from their names; their report values follow this per-class counting rule, including any prereg rows. (`bench/oracle/label_schema.json:14`, `bench/oracle/crosscheck.py:179-184`)

**X08 — Diagnostics.** Matched prereg `uncovered` targets produce an `uncovered_changed_flag` entry counting paired oracle rows with `UNCOVERED`; the flag is diagnostic rather than required for matching. (`bench/oracle/crosscheck.py:131-144`, `bench/oracle/crosscheck.py:187-190`)
The diagnostic grid starts at `16` and doubles until its ceiling-divided dimensions meet the `4096`-cell and `255`-axis limits; nondivisible pane edges produce `straddle_edge`, including a count of all oracle `STRADDLE` rows, and pointer rectangles with a smaller dimension below the tile size produce `subtile_pointer`. (`bench/oracle/crosscheck.py:109-115`, `bench/oracle/crosscheck.py:185-201`)
Diagnostic entries do not themselves change the CLI return code, which uses the two unmatched counts. (`bench/oracle/crosscheck.py:202-204`, `bench/oracle/crosscheck.py:223-224`)

**X09 — Empty-input distinction.** Direct `compare` rejects empty oracle rows and empty prereg rows, while the CLI explicitly loads with `allow_empty=True` and resolves prereg rows before selecting its empty-oracle result. (`bench/oracle/crosscheck.py:55-59`, `bench/oracle/crosscheck.py:147-150`, `bench/oracle/crosscheck.py:216-219`)
That result is explicitly `untested`, has zero agreement and zero unmatched counts, and sets every class to `untested` even when its prereg count is positive; its rc is `0`, while an unknown item or unreadable oracle file still fails. (`bench/oracle/crosscheck.py:76-83`, `bench/oracle/crosscheck.py:216-224`, `bench/oracle/tests/test_crosscheck.py:99-126`)

**X10 — Output and return codes.** The CLI writes compact sorted-key JSON with a final newline and returns `0` when both unmatched counts are zero or `5` otherwise; caught errors write `crosscheck: ...` to stderr and use the exception rc or default `2`, remapping an exception rc of `1` to `5`. (`bench/oracle/crosscheck.py:220-224`)

## 7. Serialization and bounded absences

**O01 — Serialization.** Sampler row serialization writes compact sorted-key JSONL after checking its byte cap, while label serialization validates every row, checks the cap before touching the destination, writes a temporary file, and replaces the destination atomically. (`bench/oracle/sampler.py:246-252`, `bench/oracle/labels_oracle.py:269-281`)
The label CLI maps caught usage/schema/I/O failures to rc `2`, cap errors to rc `5`, and success to rc `0`. (`bench/oracle/labels_oracle.py:284-317`)

**A01 — Unimplemented guarantees: AUSENTE.** Validation that the injected clock is monotonic, clamping of negative sample timestamps, chronological validation or sorting of samples, interpolation between samples, and positive viewport-dimension validation are AUSENTE in the inspected sampler and producer paths.
