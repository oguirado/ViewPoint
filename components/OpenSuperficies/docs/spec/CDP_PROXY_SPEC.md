## 1. Architecture, FIFO Bridge, and Launcher (`cdp_proxy.py` and `launch-oracle-cu.sh`)

- `docker/cu/oracle/cdp_proxy.py` implements the W6a lane P default-deny CDP allow-list proxy between the oracle sampler and Chromium using only the Python 3 standard library (`docker/cu/oracle/cdp_proxy.py:1-9`, `docs/CU_W6A.md:11`).
- In `serve`, the proxy sets `os.umask(0o077)` and validates that `--fifo-dir` (default `"/run/newton-tenant"`) is an existing directory, returning exit code `2` if it is missing (`docker/cu/oracle/cdp_proxy.py:386-392`, `docker/cu/oracle/cdp_proxy.py:466`).
- The proxy creates two `0o600` named pipes via `_mkfifo`: `<fifo-dir>/oracle.in` (written by the sampler, read by the proxy) and `<fifo-dir>/oracle.out` (written by the proxy, read by the sampler), creating no TCP or Unix domain socket listener (`docker/cu/oracle/cdp_proxy.py:4`, `docker/cu/oracle/cdp_proxy.py:252-261`, `docker/cu/oracle/cdp_proxy.py:393-395`).
- `_mkfifo(path)` calls `os.lstat(path)` if the path exists, raises `OSError("not our FIFO: " + path)` if the existing file is not a FIFO (`stat.S_ISFIFO`) or is not owned by `os.getuid()`, unlinks the prior FIFO, and creates a fresh FIFO with `os.mkfifo(path, 0o600)` and `os.chmod(path, 0o600)` (`docker/cu/oracle/cdp_proxy.py:252-261`, `docker/cu/tests/test_cdp_proxy.py:298-302`).
- The proxy opens `oracle.out` with `os.O_RDWR` so the open call never blocks while waiting for the sampler to open the read end (`docker/cu/oracle/cdp_proxy.py:396`).
- Two anonymous OS pipe pairs `(cr, cw)` and `(br, bw)` are created and duplicated to file descriptors `>= 10` with `fcntl.F_DUPFD_CLOEXEC` via `_hi`, followed by a best-effort `fcntl.fcntl(fd, 1031, 1 << 20)` (`F_SETPIPE_SZ` to 1 MiB) on `cw` and `br` (`docker/cu/oracle/cdp_proxy.py:244-249`, `docker/cu/oracle/cdp_proxy.py:397-403`).
- `serve` spawns the target command after `--` via `os.posix_spawnp` in its own process group (`setpgroup=0`) with `POSIX_SPAWN_DUP2` mapping `cr` to `fd 3` (Chromium reads) and `bw` to `fd 4` (Chromium writes), and `POSIX_SPAWN_OPEN` redirecting `fd 1` to `os.devnull` (`docker/cu/oracle/cdp_proxy.py:5`, `docker/cu/oracle/cdp_proxy.py:408-415`).
- Two daemon threads relay frames: `tc` runs `Serve.c2b` reading client requests from `oracle.in` (`1 << 20` byte reads) and writing allowed frames to `cw`, and `tb` runs `Serve.b2c` reading Chromium messages from `br` (`1 << 20` byte reads) and writing forwarded frames to `out_fd` (`docker/cu/oracle/cdp_proxy.py:302-356`, `docker/cu/oracle/cdp_proxy.py:416-419`).
- When `Serve.c2b` exits, its `finally` block closes `self.cw` so Chromium observes EOF on `fd 3` (`docker/cu/oracle/cdp_proxy.py:326-330`).
- When `serve` exits, its `finally` block unlinks both `oracle.in` and `oracle.out` (`docker/cu/oracle/cdp_proxy.py:447-452`, `docker/cu/tests/test_cdp_proxy.py:360`).
- `docker/cu/oracle/launch-oracle-cu.sh` requires at least one argument (`[--sandbox-mode M] URL`, exiting `2` on empty argv), extracts the final argument `${*: -1}` as `URL`, prepends `$HERE/bin` to `PATH` so the oracle shim `bin/chromium` intercepts Chromium execution, and runs `cdp_proxy.py serve` around the unchanged `launch-chromium-cu.sh` (`docker/cu/oracle/launch-oracle-cu.sh:2-15`, `docs/CU_W6A.md:11`).

## 2. Framing, the `lim` Rule, and `max_frame_bytes`

- CDP wire messages on both the pipe (`fd 3`/`fd 4`) and the FIFOs (`oracle.in`/`oracle.out`) are NUL-terminated (`b"\0"`) UTF-8 JSON byte sequences (`docker/cu/oracle/cdp_proxy.py:5-6`, `docker/cu/oracle/cdp_proxy.py:284`, `docker/cu/oracle/cdp_proxy.py:321`).
- The default maximum frame payload size is `DEFAULT_MAX = 100 * 1024 * 1024` (`104857600` bytes, 100 MiB) (`docker/cu/oracle/cdp_proxy.py:11`, `docker/cu/tests/test_cdp_proxy.py:50-51`).
- `docker/cu/oracle/allowlist.json` seals `"max_frame_bytes": 104857600`, and `load_allowlist` validates that `max_frame_bytes` is an `int` with value `>= 1` (`docker/cu/oracle/allowlist.json:3`, `docker/cu/oracle/cdp_proxy.py:65-66`, `docker/cu/tests/test_cdp_proxy.py:226`).
- In `serve`, the active maximum payload size `mx` is `a.max_frame or al["max_frame_bytes"]`, where `--max-frame` defaults to `0` (`docker/cu/oracle/cdp_proxy.py:389`, `docker/cu/oracle/cdp_proxy.py:467`).
- Both `frame_status(buf, max_payload=DEFAULT_MAX)` and `Framer.feed(data)` enforce the `lim` rule `lim = min(L, M + 1)` where `L = len(buf)` and `M = max_payload` (`docker/cu/oracle/cdp_proxy.py:27-33`, `docker/cu/oracle/cdp_proxy.py:46-57`, `docs/CU_W6A.md:11`):
  ```python
  lim = min(len(buf), max_payload + 1)
  i = buf.find(b"\0", 0, lim)
  ```
- Searching `buf[0:lim]` inspects indices `0` through `min(L, M + 1) - 1`, so a NUL byte at index `i` is found if and only if the payload length `i` satisfies `0 <= i <= M` (`docker/cu/oracle/cdp_proxy.py:29-32`, `docker/cu/tests/test_cdp_proxy.py:43-46`).
- In `frame_status` (`docker/cu/oracle/cdp_proxy.py:27-33`):
  - If `i >= 0`, it returns `(1, i)`, accepting a complete frame of `i` payload bytes (`0 <= i <= M`) (`docker/cu/oracle/cdp_proxy.py:31-32`, `docker/cu/tests/test_cdp_proxy.py:43`, `docker/cu/tests/test_cdp_proxy.py:46`).
  - If `i < 0` and `len(buf) <= max_payload`, it returns `(0, 0)` (need more bytes), even when `len(buf) == max_payload` (`docker/cu/oracle/cdp_proxy.py:33`, `docker/cu/tests/test_cdp_proxy.py:44-45`).
  - If `i < 0` and `len(buf) > max_payload`, it returns `(-1, 0)` (oversize), rejecting both an unterminated buffer of `M + 1` bytes and a frame whose NUL terminator is at index `M + 1` (payload of `M + 1` bytes) (`docker/cu/oracle/cdp_proxy.py:33`, `docker/cu/tests/test_cdp_proxy.py:47-48`).
- In `Framer` (`docker/cu/oracle/cdp_proxy.py:36-57`):
  - `Framer.__init__(self, max_payload=DEFAULT_MAX)` initialises `self.max = max_payload`, `self.buf = bytearray()`, and `self.scanned = 0` (`docker/cu/oracle/cdp_proxy.py:38-41`).
  - `Framer.feed(data)` appends `data` to `self.buf` and loops with `lim = min(len(self.buf), self.max + 1)` and `i = self.buf.find(b"\0", self.scanned, lim)` (`docker/cu/oracle/cdp_proxy.py:43-48`).
  - When `i >= 0`, `bytes(self.buf[:i])` is appended to `out`, `del self.buf[:i + 1]` removes the payload and NUL byte, and `self.scanned` is reset to `0` (`docker/cu/oracle/cdp_proxy.py:49-53`).
  - When `i < 0` and `len(self.buf) > self.max`, `Framer.feed` raises `Oversize("oversize: more than %d payload bytes without NUL" % self.max)` (`docker/cu/oracle/cdp_proxy.py:54-55`, `docker/cu/tests/test_cdp_proxy.py:67-69`).
  - When `i < 0` and `len(self.buf) <= self.max`, `self.scanned` is updated to `len(self.buf)` so prior bytes are not rescanned on the next chunk, and `out` is returned (`docker/cu/oracle/cdp_proxy.py:56-57`).
  - Because `lim = min(len(self.buf), self.max + 1)` bounds every scan before consuming bytes, `Framer.feed` is chunk-cut invariant across arbitrary stream splits (`docker/cu/oracle/cdp_proxy.py:37`, `docker/cu/tests/test_cdp_proxy.py:53-65`).

## 3. Default-Deny Request Validation and Method Matching (Browser and Session Methods)

- `load_allowlist(path)` parses the allowlist as UTF-8 JSON and requires a `dict` whose keys equal `_AL_KEYS = {"schema", "max_frame_bytes", "frame_keys", "browser_methods", "session_methods", "event_domains", "event_methods", "refused_explicit"}` and whose `"schema"` equals `"os.cu.oracle-allowlist/v1"` (`docker/cu/oracle/cdp_proxy.py:13-14`, `docker/cu/oracle/cdp_proxy.py:60-64`, `docker/cu/oracle/allowlist.json:1-23`).
- Every client-to-browser (`c2b`) frame is validated by `Policy.check_request(frame)` in the following strict order (`docker/cu/oracle/cdp_proxy.py:108-144`):
  1. **Strict JSON parse (`_parse`)**: Decodes UTF-8 and runs `json.loads` with `object_pairs_hook=_no_dups` (rejecting duplicate keys with `ValueError("duplicate key")`) and `parse_constant=_bad_const` (rejecting `NaN`, `Infinity`, and `-Infinity` with `ValueError("non-finite constant")`); any failure raises `Violation("bad json frame: %s" % type(e).__name__)` and `check_request` returns `(False, str(e))` (`docker/cu/oracle/cdp_proxy.py:70-87`, `docker/cu/oracle/cdp_proxy.py:110-113`).
  2. **JSON object check**: If `not isinstance(o, dict)`, returns `(False, "frame is not an object")` (`docker/cu/oracle/cdp_proxy.py:114-115`).
  3. **Closed envelope keys**: Requires `set(o) <= set(self.al["frame_keys"])` where `frame_keys` is `["id", "method", "params", "sessionId"]`; any extra top-level key returns `(False, "unknown frame key")` (`docker/cu/oracle/cdp_proxy.py:116-117`, `docker/cu/oracle/allowlist.json:4`).
  4. **Request `id` type and range**: Requires `type(i) is int and i >= 0` (using exact `type(i) is not int` so `bool` values `True`/`False` are rejected); otherwise returns `(False, "id must be a non-negative integer")` (`docker/cu/oracle/cdp_proxy.py:118-120`).
  5. **Method type**: Requires `isinstance(m, str)` where `m = o.get("method")`; otherwise returns `(False, "method must be a string")` (`docker/cu/oracle/cdp_proxy.py:121-123`).
  6. **Unique `id`**: Requires `i not in self.seen_ids`; a repeated request ID returns `(False, "duplicate id")` (`docker/cu/oracle/cdp_proxy.py:124-125`, `docker/cu/tests/test_cdp_proxy.py:142-145`).
  7. **`params` type**: If `"params" in o`, requires `isinstance(params, dict)`; otherwise returns `(False, "params must be an object")` (`docker/cu/oracle/cdp_proxy.py:126-128`).
  8. **Browser vs. session scope and exact-key method lookup** (`docker/cu/oracle/cdp_proxy.py:129-135`):
     - If `"sessionId" in o`: `sid = o["sessionId"]` must satisfy `isinstance(sid, str) and sid in self.sessions` (otherwise returning `(False, "sessionId not bound to the scene page")`), and `spec` is looked up via `self.al["session_methods"].get(m)` (`docker/cu/oracle/cdp_proxy.py:129-133`).
     - If `"sessionId" not in o`: `spec` is looked up via `self.al["browser_methods"].get(m)` (`docker/cu/oracle/cdp_proxy.py:134-135`).
     - Note that passing `"sessionId": ""` includes `"sessionId"` in `o` and fails the session binding check unless omitted from the frame (`docker/cu/oracle/cdp_proxy.py:129-132`, `docker/cu/tests/test_cdp_proxy.py:27-28`, `docker/cu/tests/test_cdp_proxy.py:126`).
  9. **Default-deny exact match**: Because lookup uses Python dictionary key equality (`.get(m)`), matching is exact-length and exact-byte with no prefix matching, no case folding, no whitespace trimming, and no NUL truncation; if `spec is None`, `check_request` returns `(False, "method not on the allow-list")` (`docker/cu/oracle/cdp_proxy.py:109`, `docker/cu/oracle/cdp_proxy.py:133-137`, `docker/cu/tests/test_cdp_proxy.py:105-108`, `docker/cu/tests/test_cdp_proxy.py:127-128`).
  10. **Params check and state update**: Calls `why = self._params_ok(spec["params"], params)`; if `why` is non-empty, returns `(False, why)` (`docker/cu/oracle/cdp_proxy.py:138-140`). Otherwise adds `i` to `self.seen_ids`, records `self.pending[i] = m`, increments `self.stats["requests_passed"]`, and returns `(True, "")` (`docker/cu/oracle/cdp_proxy.py:141-144`).

## 5. Session Binding on `Target.attachedToTarget` and `Target.targetInfoChanged` and Inbound Filtering

`Policy.inbound(frame)` classifies every browser-to-client (`b2c`) frame into `("forward", "")`, `("drop", reason)`, or `("violation", reason)` (`docker/cu/oracle/cdp_proxy.py:171-235`):

- **Inbound JSON and object validation** (`docker/cu/oracle/cdp_proxy.py:173-178`):
  - `_parse(frame)` runs first; if it raises `Violation`, `inbound` returns `("violation", str(e))` (`docker/cu/oracle/cdp_proxy.py:173-176`, `docker/cu/tests/test_cdp_proxy.py:161`).
  - If `not isinstance(o, dict)`, `inbound` returns `("violation", "frame is not an object")` (`docker/cu/oracle/cdp_proxy.py:177-178`).
- **Response correlation (`"method" not in o`)** (`docker/cu/oracle/cdp_proxy.py:179-186`):
  - If `type(o.get("id")) is int and ("result" in o or "error" in o)`: when `o["id"] in self.pending`, `inbound` deletes `self.pending[o["id"]]`, increments `self.stats["responses"]`, and returns `("forward", "")`; otherwise it drops the frame with `"response to an id the proxy never forwarded"` (`docker/cu/oracle/cdp_proxy.py:180-185`, `docker/cu/tests/test_cdp_proxy.py:217-221`).
  - If `"method" not in o` and the frame is not an integer-ID result/error response, `inbound` returns `("violation", "neither response nor event")` (`docker/cu/oracle/cdp_proxy.py:186`).
- **Event method syntax** (`docker/cu/oracle/cdp_proxy.py:16`, `docker/cu/oracle/cdp_proxy.py:187-189`):
  - For frames with `"method" in o`, `m = o["method"]` must be a `str` matching `_EVENT_RE = re.compile(r"^[A-Za-z]+\.[A-Za-z0-9]+$")`; otherwise `inbound` drops the frame with `"event method syntax"` (`docker/cu/oracle/cdp_proxy.py:16`, `docker/cu/oracle/cdp_proxy.py:187-189`, `docker/cu/tests/test_cdp_proxy.py:158-159`).
- **Target events (`m in self.al["event_methods"]`, which is `["Target.attachedToTarget", "Target.targetInfoChanged"]`)** (`docker/cu/oracle/allowlist.json:21`, `docker/cu/oracle/cdp_proxy.py:190-220`):
  - Requires `p = o.get("params")` to be a `dict` and `ti = p.get("targetInfo")` to be a `dict`; otherwise drops with `"target event without targetInfo"` (`docker/cu/oracle/allowlist.json:21`, `docker/cu/oracle/cdp_proxy.py:190-194`, `docker/cu/tests/test_cdp_proxy.py:202`).
  - **Case A — Direct scene-page attach on `Target.attachedToTarget`** (`docker/cu/oracle/cdp_proxy.py:195-200`):
    - When `isinstance(sid, str) and ti.get("type") == "page" and ti.get("url") == self.url` (where `sid = p.get("sessionId")`), `inbound` calls `self._bind(sid, ti)`, increments `self.stats["events_forwarded"]`, and returns `("forward", "")` (`docker/cu/oracle/cdp_proxy.py:195-200`, `docker/cu/tests/test_cdp_proxy.py:168`).
    - `_bind(sid, ti)` adds `sid` to `self.sessions`, sets `self.bound[ti.get("targetId")] = sid`, removes `ti.get("targetId")` from `self.candidates`, and sets `self.last_session = (sid, ti.get("targetId"))` (`docker/cu/oracle/cdp_proxy.py:226-230`).
  - **Case B — Candidate page attach on `Target.attachedToTarget` at a non-scene URL (such as `about:blank`)** (`docker/cu/oracle/cdp_proxy.py:201-203`):
    - When `ti.get("url") != self.url`, if `isinstance(sid, str) and ti.get("type") == "page" and isinstance(ti.get("targetId"), str)` and `(len(self.candidates) < MAX_CANDIDATES or ti["targetId"] in self.candidates)` with `MAX_CANDIDATES = 16`, the proxy stores `self.candidates[ti["targetId"]] = (sid, {"targetId": ti["targetId"], "type": "page", "url": ti.get("url") if isinstance(ti.get("url"), str) else ""})` (`docker/cu/oracle/cdp_proxy.py:15`, `docker/cu/oracle/cdp_proxy.py:201-202`, `docker/cu/tests/test_cdp_proxy.py:211-215`).
    - Both candidate page attaches at non-scene URLs and non-page attaches (such as `"iframe"`) return `self._drop("attach not a page on the scene url")`, so the raw attach event is not forwarded to the client and `sid` is not added to `self.sessions` (`docker/cu/oracle/cdp_proxy.py:201-203`, `docker/cu/tests/test_cdp_proxy.py:166-170`, `docker/cu/tests/test_cdp_proxy.py:334-338`).
  - **Case C — `Target.targetInfoChanged` for an already-bound target (`tid in self.bound`)** (`docker/cu/oracle/cdp_proxy.py:204-212`):
    - Computes `tid = ti.get("targetId")` and `at_scene = ti.get("type") == "page" and ti.get("url") == self.url` (`docker/cu/oracle/cdp_proxy.py:204-206`).
    - If `tid in self.bound` and `not at_scene` (the bound page navigated away from `self.url` or changed target type), the proxy revokes the session via `self.sessions.discard(self.bound.pop(tid))` and drops the event with `"bound page left the scene url"` (`docker/cu/oracle/cdp_proxy.py:207-210`, `docker/cu/tests/test_cdp_proxy.py:204-209`).
    - If `tid in self.bound` and `at_scene`, the proxy increments `self.stats["events_forwarded"]` and returns `("forward", "")` (`docker/cu/oracle/cdp_proxy.py:211-212`, `docker/cu/tests/test_cdp_proxy.py:207`).
  - **Case D — `Target.targetInfoChanged` promoting a tracked candidate (`at_scene and tid in self.candidates`)** (`docker/cu/oracle/cdp_proxy.py:213-219`):
    - When `at_scene` is true and `tid in self.candidates`, the proxy pops `(sid, _)` from `self.candidates`, calls `self._bind(sid, dict(ti))`, synthesises a `Target.attachedToTarget` frame in `self.pre = [json.dumps({"method": "Target.attachedToTarget", "params": {"sessionId": sid, "waitingForDebugger": False, "targetInfo": ti}}, sort_keys=True).encode()]`, increments `self.stats["events_forwarded"]`, and returns `("forward", "")` (`docker/cu/oracle/cdp_proxy.py:213-218`, `docker/cu/tests/test_cdp_proxy.py:173-187`).
    - In `Serve.b2c`, whenever `act == "forward"` and `self.pol.last_session` is set, the proxy emits a `"session"` stdout row and clears `self.pol.last_session`; if `self.pol.pre` is non-empty, `Serve.b2c` writes each frame in `pre` to the client and suppresses forwarding the raw `Target.targetInfoChanged` frame (`if not pre: self.to_client(f)`) (`docker/cu/oracle/cdp_proxy.py:344-352`, `docker/cu/tests/test_cdp_proxy.py:319-332`).
    - If `tid` is neither in `self.bound` nor a candidate reaching `at_scene`, `Target.targetInfoChanged` is dropped with `"target info change not for a tracked scene page"` (`docker/cu/oracle/cdp_proxy.py:219`, `docker/cu/tests/test_cdp_proxy.py:189-201`).
- **Domain events (`m not in self.al["event_methods"]`)** (`docker/cu/oracle/allowlist.json:20`, `docker/cu/oracle/cdp_proxy.py:221-224`):
  - Forwarded if and only if `m.split(".", 1)[0] in self.al["event_domains"]` (where `event_domains` is `["Accessibility", "DOMSnapshot", "PerformanceTimeline", "Page"]`) and `isinstance(o.get("sessionId"), str)` and `o["sessionId"] in self.sessions` (`docker/cu/oracle/allowlist.json:20`, `docker/cu/oracle/cdp_proxy.py:221-223`, `docker/cu/tests/test_cdp_proxy.py:156-157`).
  - All other events are dropped with `"event outside the allowed domains or session"` and increment `self.stats["events_dropped"]` (`docker/cu/oracle/cdp_proxy.py:224`, `docker/cu/oracle/cdp_proxy.py:232-234`, `docker/cu/tests/test_cdp_proxy.py:158-160`).

## 8. The `argv` Refusal Policy of the Shim (`argv_policy.py` and `argv_refusal.json`)

- `docker/cu/oracle/argv_policy.py` and `docker/cu/oracle/argv_refusal.json` (`"schema": "os.cu.oracle-argv-refusal/v1"`) define the argv refusal policy shared with the oracle shim `docker/cu/oracle/bin/chromium` (`docker/cu/oracle/argv_policy.py:1-19`, `docker/cu/oracle/argv_refusal.json:1-21`, `docs/CU_W6A.md:28`):
  ```python
  NEEDLE = "remote-debugging"
  PIPE = "--remote-debugging-pipe"
  ```
- **Normalisation (`_hit`)**: `_hit(a)` normalises each argument `a` via `a.lower().replace("_", "-")` and tests whether `"remote-debugging"` is a substring (`NEEDLE in a.lower().replace("_", "-")`) (`docker/cu/oracle/argv_policy.py:8-9`, `docker/cu/oracle/argv_refusal.json:3-4`).
- **Pre-shim input refusal (`refuse_input(args)`)**: returns `any(_hit(a) for a in args)`; if `True`, the shim refuses the invocation with exit code `2` before executing Chromium (`docker/cu/oracle/argv_policy.py:12-14`, `docker/cu/tests/test_cdp_proxy.py:448-452`).
  - Sealed refused inputs (`input_refuse` in `docker/cu/oracle/argv_refusal.json:6-13`, 18 vectors):
    - Port switches: `["--remote-debugging-port=9222"]`, `["--remote-debugging-port", "9222"]`, `["-remote-debugging-port=9222"]`, `["-remote-debugging-port"]`, `["--REMOTE-DEBUGGING-PORT=9222"]`, `["--Remote-Debugging-Port=9222"]`, `["--remote_debugging_port=9222"]`, `["--kiosk", "--remote-debugging-port=0"]` (`docker/cu/oracle/argv_refusal.json:7-8`, `docker/cu/oracle/argv_refusal.json:12`).
    - Address switches: `["--remote-debugging-address=0.0.0.0"]`, `["-remote-debugging-address=*"]`, `["--Remote-Debugging-Address=::"]` (`docker/cu/oracle/argv_refusal.json:9`).
    - Pre-supplied pipe switches: `["--remote-debugging-pipe"]`, `["--remote-debugging-pipe=json"]`, `["--remote-debugging-pipe=cbor"]`, `["-remote-debugging-pipe"]`, `["--REMOTE-DEBUGGING-PIPE"]`, `["--remote-debugging-pipe", "--remote-debugging-pipe"]` (`docker/cu/oracle/argv_refusal.json:10-11`).
    - Substring embedded in another flag: `["--kiosk", "--user-data-dir=/tmp/x-remote-debugging-y"]` (`docker/cu/oracle/argv_refusal.json:12`).
  - Sealed accepted inputs (`input_accept` in `argv_refusal.json`, 3 vectors), to which the shim appends `"--remote-debugging-pipe"` (`docker/cu/oracle/argv_refusal.json:14`, `docker/cu/tests/test_cdp_proxy.py:454-458`):
    - `[]`, `["--kiosk"]`, `["--user-data-dir=/tmp/chromium-1.x", "file:///opt/cu/scenes/v3/wl1s_small.html"]` (`docker/cu/oracle/argv_refusal.json:14`).
- **Post-shim observed argv verification (`observed_ok(argv)`)**: returns `argv.count(PIPE) == 1 and sum(_hit(a) for a in argv) == 1`, requiring the final Chromium argv to contain `"--remote-debugging-pipe"` exactly once and zero other arguments matching `_hit` (`docker/cu/oracle/argv_policy.py:17-19`, `docker/cu/oracle/argv_refusal.json:15-20`, `docker/cu/tests/test_cdp_proxy.py:465-468`).
- **Shim file-descriptor hygiene**: before `execv`, the shim closes inherited descriptors `>= 5` and verifies that the open descriptor set is `{0, 1, 2, 3, 4}` with FIFO `fd 3` (`O_RDONLY`) and `fd 4` (`O_WRONLY`), exiting `5` otherwise (`docs/CU_W6A.md:11`, `docker/cu/tests/test_cdp_proxy.py:420-440`, `docker/cu/tests/test_cdp_proxy.py:471-477`).

## 9. The No-Listener Check (`no_listener.py`) and Its Baseline

- `docker/cu/oracle/no_listener.py` inspects `<proc-root>/net/{tcp,tcp6,unix}` and `<tmp-root>/chromium-*/DevToolsActivePort` and outputs a sorted-key JSON report (`docker/cu/oracle/no_listener.py:1-6`, `docker/cu/oracle/no_listener.py:23-83`):
  ```python
  BASELINE = (re.compile(r"^/run/newton-tenant/bus$"), re.compile(r"^/tmp/chromium-[^/]+/SingletonSocket$"))
  ACCEPTCON = 0x00010000
  ```
- **TCP and TCP6 listener scan** (`docker/cu/oracle/no_listener.py:26-34`):
  - Reads `<proc-root>/net/tcp` (`required=True`) and `<proc-root>/net/tcp6` (`required=False`; if absent, sets `r["tcp6"] = "absent"`) (`docker/cu/oracle/no_listener.py:13-20`, `docker/cu/oracle/no_listener.py:26-30`).
  - For every line after the header where `len(c) > 3 and c[3] == "0A"`, appends `"%s %s" % (name, c[1])` to `r["tcp_listen"]`; non-empty `r["tcp_listen"]` appends `"tcp listener"` to `r["violations"]` (`docker/cu/oracle/no_listener.py:31-34`, `docker/cu/oracle/no_listener.py:61-62`, `docker/cu/tests/test_cdp_proxy.py:494-500`).
- **Unix domain listener scan and `BASELINE` rules** (`docker/cu/oracle/no_listener.py:9-10`, `docker/cu/oracle/no_listener.py:35-52`):
  - Reads `<proc-root>/net/unix` (`required=True`), splits each row with `l.split(None, 7)`, parses hex flags `fl = int(c[3], 16)`, and skips non-listening entries where `not fl & ACCEPTCON` (`0x00010000`) (`docker/cu/oracle/no_listener.py:35-44`).
  - For listening sockets (`fl & ACCEPTCON`), extracts `path = c[7] if len(c) > 7 else ""` and `low = path.lower()` (`docker/cu/oracle/no_listener.py:45-46`):
    1. **Unconditional refusal (never baseline)**: if `path.startswith("@")` (abstract socket), `not path` (unnamed socket, recorded as `"<unnamed>"`), `"devtools" in low`, or `"debug" in low`, `path` is appended to `r["unix_listen"]` even when `--allow-capsule-baseline` is passed (`docker/cu/oracle/no_listener.py:47-48`, `docker/cu/tests/test_cdp_proxy.py:514-516`, `docker/cu/tests/test_cdp_proxy.py:523-528`).
    2. **Declared capsule baseline (`--allow-capsule-baseline`)**: else if `allow_baseline` is true and `path` matches `^/run/newton-tenant/bus$` or `^/tmp/chromium-[^/]+/SingletonSocket$`, `path` is appended to `r["baseline_unix"]` without adding a violation (`docker/cu/oracle/no_listener.py:9`, `docker/cu/oracle/no_listener.py:49-50`, `docker/cu/tests/test_cdp_proxy.py:508-512`).
    3. **All other unix listeners**: appended to `r["unix_listen"]` (including `/tmp/.org.chromium.Chromium.AbC123/SingletonSocket`, which is not in `BASELINE` pending operator decision OD-2); non-empty `r["unix_listen"]` appends `"unix listener"` to `r["violations"]` (`docker/cu/oracle/no_listener.py:51-52`, `docker/cu/oracle/no_listener.py:63-64`, `docker/cu/tests/test_cdp_proxy.py:502-506`, `docker/cu/tests/test_cdp_proxy.py:530-536`, `docs/CU_W6A.md:25`, `docs/CU_W6A.md:28`).
- **`DevToolsActivePort` file scan** (`docker/cu/oracle/no_listener.py:53-60`):
  - Lists `<tmp-root>`, and for each entry `d` starting with `"chromium-"`, checks `os.path.lexists(os.path.join(tmp_root, d, "DevToolsActivePort"))`; any hit is appended to `r["devtools_port_files"]` and adds `"DevToolsActivePort file"` to `r["violations"]` (`docker/cu/oracle/no_listener.py:53-60`, `docker/cu/oracle/no_listener.py:65-66`, `docker/cu/tests/test_cdp_proxy.py:518-521`).
- **Fail-closed `/proc` handling** (`docker/cu/oracle/no_listener.py:76-80`):
  - If reading a required `/proc` file (`tcp` or `unix`) raises `OSError`, `main` prints `{"error": "E_PROC <ErrorType>", "violations": ["proc unreadable"]}` and returns exit code `5` (`docker/cu/oracle/no_listener.py:17-19`, `docker/cu/oracle/no_listener.py:76-80`, `docker/cu/tests/test_cdp_proxy.py:538-539`).
