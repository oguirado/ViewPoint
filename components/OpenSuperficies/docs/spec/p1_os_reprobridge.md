# P1 OS reprobridge — Area A design and evidence

**Source:** `oguirado/OpenSuperficies`, explicitly read at `bridge/integration`, observed HEAD `1372a80c59c8d3384c64adac49a735f6eb4bffc4` (2026-10-21). The task card records `dc77910fea53617c2b49f704cb1d11fcb642a053` instead; this implementation binds to the **observed ref**, not the stale recorded commit. This note is design/test evidence, **not** a host authorization or acceptance certificate.

## Port, ownership and ordering

- `harvest.ReproInput` is `(Binding, Record)`; `harvest.ReproBinding` is `(Repo, Commit, InputSHA256, GateArgv, FrameOrder)`; `harvest.CanonicalRepro` is `(Normalizer, Key, Canonical)`. `Adapter` implements `harvest.Identity.Canonical(context.Context, harvest.ReproInput)` exactly (`src/w8wave/harvest/types.go:182-193`). `New` is stateless.
- Identity must be generated **only** by `aggregator.ParseAndComputeIdentity(record, nil)`, which delegates to the real `ComputeIdentity`, uses default SHA-256, and preserves exact `CanonicalRecord` and `FramedBytes` (`src/w8wave/aggregator/aggregator.go:321-346,350-419`). C3 framing is the JSON bytes **without** an added prefix (`:320-323`). The adapter returns a fresh byte copy and does not reserialize or rehash JSON.
- The closed C3 schema retains these identity members (logical protocol order): `normalizer`, `repo`, `commit`, `base_image_digest`, `base_recipe_sha256`, `cache_manifest_sha256`, `guest_kernel_sha256`, `guest_rootfs_sha256`, `extract_policy_sha256`, `gate_argv`, `gate_cwd`, `failure_kind`, `normalized_exit`, `affected`, `assertion`, `frames`, `repro_steps` (`src/w8wave/aggregator/aggregator.go:82-104,147-151,269-317`). JSON itself is sorted-key compact UTF-8 (`src/workerbridge/json.go:196-223,267-291`). Frame members are `path`, `symbol`, `line`, optional `address` (`src/w8wave/aggregator/aggregator.go:74-80`); frame and argv list order is preserved. Both guest pins and normalized exit are nullable on the wire, but a null/absent normalized exit has **no keyed identity** (`:194-209,394-418`). Never infer zero.
- `InputSHA256` and opaque `FrameOrder` belong to the frozen binding, **not** the C3 JSON. Repo, commit and ordered argv in the C3 record must agree with their frozen binding. Frame labels cannot be interpreted as symbols or paths without a defined host contract: harvest separately checks the entire binding against frozen wave and attempt (`src/w8wave/harvest/pipeline.go:451-466`) and includes ordered `FrameOrder` in the consumer finding address (`src/w8wave/harvest/sink.go:84-95`). The adapter validates labels and their finite count but does not invent a transformation of label strings into frame data.
- Attempt, worker, timestamps, pulse and cost are separate provenance or attempt-receipt data (`src/w8wave/aggregator/aggregator.go:126-136,153-167,479-530`). Volatile `workspace_prefix`, `pid`, `time_ms` and frame addresses do not enter C3 canonical bytes (`:101-123,269-317`). Cost is nullable with `AUSENTE`, never a synthetic zero (`src/w8wave/harvest/types.go:298-299`, `src/w8wave/harvest/sink.go:131-155`).

## A-result and A-completion contract

1. The adapter checks cancellation and validates finite binding data before parsing; the real aggregator strict parser validates record types and exact names, builds the canonical bytes and hashes in `w8-repro/1`. Post-parse binding mismatch is code **5** and never yields a keyed result. Source parser rejections are returned unchanged (no recoding). Canonical byte copies are independent of caller mutations.
2. A resulting identity can be merged only after host-side receipt validation and trusted frozen binding checks. The existing harvest `MemorySink` unions **actual** distinct witnesses, keeps receipt/cost per attempt and stores each canonical byte copy; two attempts witnessing the same reproduction do not become two reproduction IDs (`src/w8wave/harvest/sink.go:103-155,228-255`). No file I/O is performed by reprobridge or its tests.
3. A-completion is the existing `Reserve -> Publish/Reconcile -> Confirm` state machine, not a new publisher (`src/w8wave/harvest/pipeline.go:503-525`; `src/w8wave/harvest/sink.go:180-225`). `Fresh` is true once per immutable reservation. A hash collision at the consumer boundary is not equality: keep canonical bytes and frozen binding, with distinct finding IDs. Aggregator itself additionally refuses byte-mismatched merges (`src/w8wave/aggregator/aggregator.go:832-853`), while `MemorySink` uses an exact-byte storage address (`src/w8wave/harvest/sink.go:84-95`).
4. A raw native gate exit is **not** a C3 object member. The pure `NormalizeNativeGateExit` helper follows the host gate failure categories: native 0 maps to normalized 0, native nonzero and known terminal outcomes to 5, unknown outcome refuses with uncertainty 6, missing raw evidence refuses with unavailable 4, unrecognized category is malformed input 2. It cannot authenticate host-provided raw evidence; the existing private `normalizedReceiptGate` function and actual receipt validator remain host authority (`src/w8wave/harvest/receipt.go:69-76,129-135,349-356`). No new ImagePins or AuthenticatedGateEvidence API is assumed.

## Refusals and finite work

| Condition | Code and class | Effect |
|---|---|---|
| Missing/invalid binding, too-long record, unknown key, bool/float exit, duplicate JSON key, wrong normalizer, null exit | **2**, precise source class where parsed | No identity, sink or send |
| Record repo/commit/argv differs from binding; provenance injected in identity | **5** `BINDING_MISMATCH` or source `PROVENANCE_IN_IDENTITY` | No identity, sink or send |
| Missing trusted raw native gate exit | **4** `unavailable` | No inferred normalized exit |
| Unknown native gate termination | **6** `UNCERTAIN_GATE` | Quarantine; no success |
| Cancelled context | `context.Canceled` (harvest maps to 7) | No identity, sink or send |

The adapter's local defensive raw-input bound is **1,048,576 bytes** per record and 64 argv/frame-binding labels (not a throughput claim). The source aggregator limits `gate_argv`, `affected`, `frames` and `repro_steps` to 64 members and frame lines/volatile numbers to JSON-safe integer bounds (`src/w8wave/aggregator/aggregator.go:226-265`); the shared strict JSON decoder limits nesting to 128 (`src/workerbridge/json.go:123-151`). No VM throughput or disk budget is asserted: **TARGET/AUSENTE** pending an authorized host benchmark.

## Undefined capabilities, external defects and limitations

- **AUSENTE:** an importable producer for authenticated raw native gate evidence, image pins, host A4 evidence, diskless guest frame extraction or an actual consumer writer grant. The existing host `validateExtraction`/`validateCandidate` are private and must not be replaced by test doubles (`src/w8wave/harvest/receipt.go:16-69`). Neither `Adapter` nor a test string such as `trusted-test-only` grants authority.
- **PRODUCTION_DEFECT / outside grant:** `src/w8wave/harvest/sink.go:53-81` checks canonical JSON and a 64-hex `Key`, but does not independently recompute SHA-256 over canonical bytes. It therefore accepts a caller-supplied forged key if an untrusted identity port bypasses this adapter. The Area A adapter always delegates to the real aggregator; this concern must be handled at the sink's trust boundary by its owner, **not** by editing the held producer.
- **AUSENTE:** revision-bound green receipts for an authorized Go 1.26 host gate, real VM timing, actual cost, production publishing authority and operator acceptance. These are not replaced by test expectations, GitHub publication or this note.
