## 2. Running the daemon

Command: `bin/srfd [--socket PATH]`. The only flag is `--socket` (`src/surfacebook/manager/uds.go:245`); an unknown flag exits 2 [MEASURED 2026-09-20, `evidencia/v2/u22/comandos-runbook.txt:14`].

Socket path, in order (`src/surfacebook/manager/uds.go:113`): the explicit value, then `$SRF_SOCKET` (`src/surfacebook/manager/uds.go:117`), then `$XDG_RUNTIME_DIR/opensuperficies/srfd.sock` (`src/surfacebook/manager/uds.go:124`); when `XDG_RUNTIME_DIR` is unset the temporary directory is used (`src/surfacebook/manager/uds.go:112`). On this host the default resolves to `/run/user/1000/opensuperficies/srfd.sock` [MEASURED 2026-09-20, `evidencia/v2/u22/comandos-runbook.txt:30`].

Security properties, all read from source:

- The socket is created 0600 at creation, with the umask narrowed around `bind` (`src/surfacebook/manager/uds.go:145`), and creation fails when the result is not a 0600 socket (`src/surfacebook/manager/uds.go:157`). Its directory is created 0700 (`src/surfacebook/manager/uds.go:137`).
- A socket directory owned by another uid is refused (`src/surfacebook/manager/uds.go:339`). A stale socket is replaced; a socket a live process serves is never replaced (`src/surfacebook/manager/uds.go:179`).
- Admission is by kernel identity: the caller's `SO_PEERCRED` uid must equal the daemon's uid, with no root exemption and no group rule (`src/surfacebook/manager/uds.go:68`). A refused peer gets rc 9 and nothing is executed (`src/surfacebook/manager/uds.go:541`).
- One request line per connection, at most 4096 bytes [TARGET] (`src/surfacebook/manager/uds.go:235`); the peer has 5 s [TARGET] to deliver it (`src/surfacebook/manager/uds.go:237`).

Single instance and journal. The journal `srfd.wal` sits next to the socket (`src/surfacebook/manager/uds.go:361`). Its exclusive flock is the single-instance guard, taken before the socket is touched (`src/surfacebook/manager/uds.go:372`); a second daemon fails with `another srfd holds <wal>` (`src/surfacebook/manager/uds.go:375`) and exits with the lock-collision code 69 (`src/surfacebook/manager/uds.go:257`). The journal and its flock file are durable state and are never unlinked by a run that served.

Signals and teardown. `SIGINT`, `SIGTERM` and `SIGHUP` start shutdown (`src/surfacebook/manager/uds.go:250`). Teardown is synchronous: `main` calls `os.Exit` only after `EjecutarDaemon` returned (`cmd/srfd/main.go:13`). In-flight requests get 20 s [TARGET] (`src/surfacebook/manager/uds.go:297`); stopping the live capsules is bounded by 90 s [TARGET] (`src/surfacebook/manager/uds.go:300`); capsules that cannot be stopped keep the journal alive and are reported (`src/surfacebook/manager/uds.go:488`).

## 3. Wire protocol

One JSON object per line, one request and one response per connection. Verbs: `estado`, `iniciar`, `detener`, `mediacion`, `listar` (`src/surfacebook/manager/uds.go:98`); any other verb answers rc 2 `unknown command` (`src/surfacebook/manager/uds.go:600`). The answer is `{ok, rc, error, datos}` (`src/surfacebook/manager/uds.go:104`). `estado` returns the six fixed fields `estado`, `parada`, `vivas`, `reservado_mib`, `disponible_mib`, `soberana_mib` (`src/surfacebook/manager/manager.go:68`); its `estado` value is the constant `ok` and is only produced when the governor telemetry was read (`src/surfacebook/manager/manager.go:412`).

## 5. Slots, ports and the start and stop paths

Capsules are named `srf-ng-<slot>` (`src/surfacebook/manager/manager.go:139`). The port plan is Xpra `10020 + slot` and CDP `9220 + slot` for 80 slots [TARGET] (`src/displaybook/puertos/puertos.go:13`, `src/displaybook/puertos/puertos.go:14`, `src/displaybook/puertos/puertos.go:15`); `bin/srf-puertos par --slot 0` gave 10020/9220 (`evidencia/v2/u22/comandos-runbook.txt:75`), slot 79 gave 10099/9299 (`evidencia/v2/u22/comandos-runbook.txt:91`) and slot 80 was refused (`evidencia/v2/u22/comandos-runbook.txt:95`) [MEASURED 2026-09-20].

A start runs these steps in order, and undoes every step it took when one fails (`src/surfacebook/manager/manager.go:182`): (1) the stop signal is read (`src/surfacebook/manager/manager.go:188`); (2) the class is checked; (3) the slot is reserved so two starts cannot both pass (`src/surfacebook/manager/manager.go:197`); (4) governor admission with the class reservation for 6 pages and 1.5 CPUs [TARGET] (`src/surfacebook/manager/manager.go:242`, `src/surfacebook/manager/manager.go:243`); (5) a one-hour lease [TARGET] from the lessor (`src/surfacebook/manager/manager.go:252`); (6) the stop signal is read AGAIN immediately before the dispatch (`src/surfacebook/manager/manager.go:260`); (7) dispatch through `bin/srf-capsula`, 120 s per dispatcher call [TARGET] (`src/surfacebook/manager/manager.go:121`). Non-browser classes are routed to `bin/srf-capsula-<class>` or to the executable named by `SRF_CAPSULA_<CLASS>` (`cmd/srf-capsula/main.go:70`, `cmd/srf-capsula/main.go:73`), and the dispatcher exits with the class binary's own code (`cmd/srf-capsula/main.go:94`).

Slot states: `iniciando`, `listo`, `deteniendo`, `huerfana` (`src/surfacebook/manager/manager.go:44`, `src/surfacebook/manager/manager.go:49`). `huerfana` marks a slot whose capsule could not be confirmed stopped after a failed start; it keeps its reservation and lease until a later stop releases them (`src/surfacebook/manager/manager.go:47`).

## 6. The stop signal (PARADA)

The effective signal is the pair (repository `PARADA.txt`, Plaza `PARADA.txt`): it is `LIBRE` only when BOTH files read `LIBRE` (`src/surfacebook/manager/parada.go:115`). Reading is fail-closed: a missing file is `AUSENTE`, and an empty file, a blank first line, `libre` or `LIBREX` are all `PARADA` (`src/surfacebook/manager/parada.go:88`). Paths: `$SRF_PARADA_REPO` or `<repository>/PARADA.txt` (`src/surfacebook/manager/parada.go:55`); `$SRF_PARADA_PLAZA`, else `$SRF_SALA/PARADA.txt`, else the campaign room (`src/surfacebook/manager/parada.go:67`, `src/surfacebook/manager/parada.go:26`). Both files are read again on every call. Only the human operator writes `PARADA.txt` (`PLAN-CAMPANA-OPENSUPERFICIES-V2-NEXTGEN.md:1078`). Instrument: `scripts/ng/campana.sh parada` returns rc 0 for LIBRE and rc 3 for PARADA (`scripts/ng/campana.sh:10`); today it printed `LIBRE` for both files [MEASURED 2026-09-20, `evidencia/v2/u22/comandos-runbook.txt:2`].
