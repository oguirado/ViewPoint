- Pack: `pack(batch, cap_bytes=None, shuffle_window=None, batch_no=0) -> PackResult`. `batch` needs `W, H, params_sha256, gops`; optional `regions` (dict or list), `tiles` and `frames` (callables frame -> array), `acc`, `n_check_png`, `text_b`. Output `vqa.pack/v2` plus `files`: `z1.txt`, heatmaps (V1), crop pairs (V2), `mp4_frames.json`, `pack.json` (V3 inside as `v3`); `PackResult.acc` is the next starvation accumulator.
- `PackResult.write(out_dir)` stages to `<out_dir>.tmp` and replaces; an existing `out_dir` is `E_USAGE`, an I/O failure `E_IO`, the filesystem unchanged.
- Request layer: `build_request(pr, static_extra=b"")` (prefix = Z1 text + caller bytes, suffix = canonical `pack.json` + media rows), `ResponseCache(root)` keyed by the request sha256, `judge_batch(pr, call, cache, static_extra, budget, retry)` (one call per miss, `RunTokenBudget` charged before dispatch).
- Verifier: `verify_citations(vision, judge_output, pack) -> dict` (`vqa.cite-verdict/v1`), `verify_dir(vision_dir, pack, judge_output)`, `build_vision`, `load_vision`, `render_quote`. Only `status == "FAIL"` results are verified; `PASS` and `CANNOT_SEE` pass through untouched.
- Pure and deterministic: no clock, no RNG; V3 carries host facts only (no oracle verdicts, no RAG edges).

| error code (`visioncore/errors.py` CODES) | rc | raised by |
|---|---|---|
| `E_USAGE` | 2 | bad `cap_bytes`, existing out dir, placebo without width, non-bytes `static_extra`/call result, missing shared budget, malformed judge output or pack |
| `E_IO` | 2 | write failure, missing `tiles.bin` |
| `E_SCHEMA` | 2 | tile `cls` above 6, `r_rep` missing from regions |
| `E_VC_ID_RANGE` | 3 | crop bbox empty after clamping |
| `E_CITE` | 3 | at least one FAIL result rejected |
| `E_STALE` | 4 | pack grid, `params_sha256` or `api_version` differs from the vision |
| `E_BUDGET` | 6 | Z1, V3 (per GOP or batch), mandatory frames, request tokens or run tokens over the cap |
| `OK` | 0 | every FAIL result accepted |

Exit-code classes are `RC_CLASSES = (0, 2, 3, 4, 5, 6)` (`errors.py`); rc 1 is never used. The per-pointer rejection tags (`E_CITE_SYNTAX` SY, `E_CITE_UNKNOWN` UK, `E_CITE_WINDOW` WI, `E_CITE_QUOTE` QU, `E_CITE_CLASS` CL, `E_CITE_IRRELEVANT` RE, `E_CITE_NONE` NO) are result tags inside the verdict, not process exit codes. Toolchain: numpy, zlib, hashlib; the suite is `python3 -m unittest tests.test_pack tests.test_cite` (47 tests, rc 0, `R-s6-pack-cite-unittest`).

**A. Pack.**
1. Z1 static legend (`z1_text`, `E_BUDGET` part `z1` when over `Z1_MAX_B`). Region ids named by tracks must exist (`E_SCHEMA` otherwise).
2. Items per GOP: track items (`_track_items`) and frame-all items (`_frameall_items`) with weights from class and flag tables.
3. `fit`: sort items by the strict key `(-(w+acc), first, morton, id)`; start everything at level 2; any GOP block over `PACK_GOP_B` or the batch over the cap at all-L2 is `E_BUDGET`; then two passes (target level 1, then 0): a promotion that overflows its GOP block is undone and skipped, one that overflows the batch cap is undone and ends that pass ([CITED, EX-SW-0234-FIT]). Each promotion re-serialises V3, so the cost is quadratic in the item count; a faster fit must be bit-exact and needs a differential test against this one.
4. Starvation accumulator: items kept above level 0 add their weight to `acc`, items at level 0 reset to 0.
5. V2 crops (`crop_png`): tile bbox grown by one tile, clamped, box-downscaled when the side exceeds `CROP_SIDE`; before = frame `rf-1`, after = `rf`.
6. V1 heatmap (`heatmap_png`): one cell per tile, class of highest weight, intensity = active frames over n, deterministic PNG (`png_encode`, zlib level 6, filter 0).
7. `select_frames`: 12-slot clip; priority tiers cut/flash, APPEAR/VANISH, cycle first frame, FROZEN onset, DRIFT onset, window I-frame; remainder by `dirty_ppm`. More mandatory frames than slots is `E_BUDGET` part `mandatory_frames`.
8. Media ladder: while the token estimate exceeds `PACK_CALL_TOK`, drop crops, then heatmaps down to 1, then MP4 slots down to `max(8, must_n)`, then downscale check PNGs; still above is `E_BUDGET` part `tokens`.
9. `shuffle_window` (placebo, EVAL X7): V3 built from a cyclically shifted GOP list; `pack.json` gets `placebo: true`.

**B. Request and dispatch.** `build_request` -> `judge_batch`: request tokens above `PACK_CALL_TOK` is `E_BUDGET` part `request_tokens`; a cache hit returns the stored bytes without a call; a miss needs a shared `RunTokenBudget` (else `E_USAGE`), charges before dispatch (over `PACK_RUN_TOK`, or `PACK_RETRY_TOK` after a retry: `E_BUDGET` part `run_tokens`), calls once, requires bytes, stores under the request sha256.

**C. Verifier (rule order of `_check_pointer`, first failure wins).** Staleness first (`_stale`: grid, `params_sha256` with a 32-hex vs 64-hex prefix match, `api_version`; rc 4 before any result is read). Per FAIL result: reason class known, then per pointer (first 8): 1 syntax (string, at most 24 chars, `ids.parse_any` kind field/region/global/track/gop), 2 existence, 3 window (frame actually sent), 4 quote equals `render_quote`, 5 class evidence (`_evidence`), 6 relevance (pointer tiles within the Moore ring of a compatible flagged region). Accepted iff at least one pointer passes; zero accepted gives `E_CITE_NONE` and `CANNOT_SEE`.

Commands: `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest tests.test_pack tests.test_cite -v`; receipts via `python3 hyperbooks/_tools/reseal.py R-s6-pack-cite-unittest R-s6-z1-size R-s6-anchors`.

A batch of two GOPs with tracks and regions enters `pack`. `z1_text` is checked against its cap, `fit` starts both GOPs at level 2 and promotes items in key order until the GOP block or the batch cap stops it, `select_frames` picks the clip frames, the heatmap and crop PNGs are rendered, and the media ladder trims until the token estimate is within `PACK_CALL_TOK`. `judge_batch` builds the request (Z1 prefix first, so the prefix hash is stable across batches), looks the request sha256 up in the `ResponseCache`, and on a miss charges the shared `RunTokenBudget` and calls the judge once. The judge answers FAIL with pointers and a digest quote; `verify_citations` first compares grid, `params_sha256` and `api_version` (rc 4 on drift), then runs the six rules per pointer. A pointer to a frame outside the pack window fails rule 3 and the claim becomes `CANNOT_SEE` with rc 3, while a sibling pointer that passes all six rules keeps the claim accepted. Decision (ADR): promotion order is the greedy L2 -> L1 -> L0 of `fit` rather than demotion from a full pack ([CITED, EX-SW-0234-FIT]); a refused batch emits nothing ([CITED, EX-SW-0233-EMIT]).
