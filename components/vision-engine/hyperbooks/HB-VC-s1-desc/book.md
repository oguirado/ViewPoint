- Input: `frame` uint8 `[H,W,3]` RGB24 matching `Grid(W,H)`; optional `words_prev` (previous *padded* frame), `prev_xh64`, `prev_tiles`, `y_plane`, `lazy_xh`.
- Output: `(tiles, words_eq)`; `tiles` is `TILE_DTYPE[N]` in ascending Morton rank; `words_eq` bool[N] (all False without `words_prev`).
- S1 fills `morton, flags (EDGE, TEXTURE, SAT, PAD), y_q4, co_h, cg_h, sig_q4, grad_q6, edge, sig64, xh64`; it leaves `cls, resid, mv_dx, mv_dy` and the flags `SHADE_ONLY, UI_OCC, ACTOR_OCC, GLOBAL_MV` at 0 for S2/S4.
- Pure and deterministic: no clock, no RNG, no global except `PARAMS["TAU_EDGE"]` (a parameter, range 1..255, default 48).

| error code (`visioncore/errors.py` CODES) | rc | raised by |
|---|---|---|
| `E_VC_FRAME_SHAPE` | 2 | `describe` (wrong shape or dtype), `describe_padded` (padded shape differs from `(gh*s, gw*s, 3)`) |
| `OK` | 0 | no other code is raised by S1 |

Exit-code classes are `RC_CLASSES = (0, 2, 3, 4, 5, 6)` (`errors.py`); rc 1 is never used. `isqrt`, `ycocg`, `xh64_of` raise nothing. Toolchain: numpy and hashlib only, determinism by construction; the suite is `python3 -m unittest tests.test_desc` (13 tests, rc 0, `R-s1-desc-unittest`).

1. `Grid.pad` (edge replication by index clamp, [CITED, EX-OC04]) then reshape `(gh,s,gw,s,3)`.
2. `luma_of_padded`: Co=R-B; t=B+(Co>>1); Cg=G-t; Y=t+(Cg>>1) in int16 (edge pad commutes with the lift).
3. `words_eq` = per-tile byte equality with `words_prev`; with `prev_tiles`, equal tiles copy their descriptor (flags & `_DESC_FLAGS`) and only `idx = ~words_eq` is computed.
4. `_compute` on `idx`: sums of Y, Y^2, Co, Cg in i32 widened to i64; gradients inside the tile; edge and saturation counts; sub-block sums; then isqrt and one commit per field.
5. Flags: EDGE iff `2e >= s and e < 4s`; TEXTURE iff `e >= 4s`; SAT iff `4*sat >= n`; PAD from `Grid.pad_flags()`.
6. xh64: eager in `describe_padded` (carry-forward where `words_eq`), or lazy (`lazy_xh=True`, then `fill_xh64` after S2).

Commands: `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest tests.test_desc -v`; receipts via `python3 hyperbooks/_tools/reseal.py R-s1-desc-unittest R-s1-desc-bench`.
