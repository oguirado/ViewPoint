- Write path `Store.commit(files, blobs=(), extra=None, strict=True)`: exclusive non-blocking `flock` on `LOCK` (held: `E_STALE` reason `lock_held`, rc 4) -> `put_blob` each blob -> `gen.publish_gen` (stage, fsync, rename) -> `gen.flip` (CURRENT tmp symlink, `os.replace`, directory fsync) -> journal `flip` record. A failure before the flip leaves CURRENT and the previous generation untouched. The kill seam is `Store.hook` over `gen.POINTS` and `BLOB_POINTS`.
- Read path: `router.route` (V1 shortlist), `get`, `evidence`, `last_good`, `diff_region`, `seen_defect`, `check_answer`, `answer` (V0 digest -> V1 -> V3 -> V4 at most 2 crops). Readers are lock-free `Snapshot`s pinned to one generation and validated at the end (`E_STALE` rc 4 when CURRENT moved).
- Abstention `NOT_IN_VISUAL_MEMORY` (rc 3), first match wins, letters `a scope_unknown, c build_out_of_range, d tk_unknown, e sig_no_hit, f no_lexical_hit, g check_failed`; a grid mismatch is rc 4 before any abstention.
- Gates `gates.verify(root, quick, gen)` run the 13 names in `GATES` (`g_schema g_nofloat g_ids g_layer_pin g_fg_monotone g_catalogue g_blob_integrity g_provenance g_cite g_grid g_caps g_window g_privacy`), each rc 0 or 5; `ABSENT = (g_determinism, g_cache_stable)` are reported, never run. A failing gate is `E_GATE` rc 5.
- Compaction: `compact.compact(units, blob_sizes, k_clean, table, gen)` returns a plan dict (`active, archive, retired, summaries, live_blobs, dropped_blobs, fg_ids_sha256`) without I/O; `gc_plan` returns blobs unreferenced by every generation in the rollback window.
- Rollback: `Store.rollback(to)` accepts only generations in `[CURRENT-VM_GEN_KEEP+1, CURRENT]`, else `E_ID` rc 3.

| error code (`visioncore/errors.py` CODES) | rc | raised by |
|---|---|---|
| `E_USAGE` | 2 | missing lock for a write verb, bad relpath or gen number, window too large, bad journal type |
| `E_SCHEMA` | 2 | an invalid vmem.unit/v1 |
| `E_IO` | 2 | spool unreadable, journal short write |
| `E_ID` | 3 | rollback outside the window, a file missing from the pinned generation |
| `E_STALE` | 4 | lock held, empty store, CURRENT moved, manifest or flip target missing |
| `E_GATE` | 5 | failing gate, FG edit refused, `fg_cap`, `gen_exhausted`, blob integrity |
| `E_BUDGET` | 6 | journal record above the record cap, answer or shortlist over its cap |
| `NOT_IN_VISUAL_MEMORY` | 3 | a lettered abstention |
| `OK` | 0 | success |

Exit-code classes are `RC_CLASSES = (0, 2, 3, 4, 5, 6)`; rc 1 is never used. The suite is `python3 -m unittest tests.test_vmem_units tests.test_vmem_store tests.test_vmem_router tests.test_vmem_compact tests.test_vmem_fixes` (101 tests, rc 0, `R-s7-vmem-unittest`).

Dependencies: `visioncore.{canon,errors,ids,layout}` plus the standard library (`fcntl, os, bisect, struct, re, hashlib, argparse`). `vmem` never imports `visioncore.params` (the layer gate `g_layer` plants the mutant `m_g_layer__vmem_import`). Internal order: `blobs, gen, receipts` -> `store` -> `units` -> `tiers` -> `compact`, `gates` -> `router` -> `ingest`, `cli`.

Write DAG: lock -> `put_blob` -> `publish_gen` -> `flip` -> journal append; the order is not to be changed, and every new durable step needs a `point(name)` crash hook and a crash test ([CITED, EX-SW-0171-BARRIER]). Read DAG: `View` pinned to one generation -> verb -> `snap.validate()`.

Commands: `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest tests.test_vmem_units tests.test_vmem_store tests.test_vmem_router tests.test_vmem_compact tests.test_vmem_fixes`; gates `python3 tools/gates.py --all`; CLI `python3 -m vmem.cli <verb> --store S` (verbs route, answer, get, evidence, last-good, diff-region, seen-defect, check-answer, verify, rollback, ingest, compact, gc, pin), each printing one canonical JSON object; receipts via `python3 hyperbooks/_tools/reseal.py R-s7-vmem-unittest R-s7-vmem-inventory`.

## <a id="hb-s7"></a><a id="pm-s7"></a>7. Narrative

<!-- HB:BEGIN hb.section.v2 -->
```json
{"anchor":"hb-s7","claims":[],"code_anchors":["vmem/router.py::route","vmem/store.py::Store.commit"],"diataxis":"reference","hb_id":"HB-VCS7-001","kind":"narrative","n":7,"purpose":"One end-to-end trace: lock, commit, flip, read, abstain.","route":{"emit":true,"tags":["software/router"]},"schema":"hb.section.v2","title":"Narrative"}
```
<!-- HB:END -->
A writer takes `Store.lock()`: recovery drops a torn journal tail, removes unacked generation directories and temporary files, and reconciles a CURRENT that lacks its flip record. `commit` writes the blobs, stages `gen/gen-000005` with `units/active.jsonl`, the indexes and the catalogue, fsyncs, renames, replaces CURRENT, fsyncs the directory and appends the journal `flip` record. A reader's `Snapshot` pins generation 5; if a flip to 6 happens mid-read, `validate()` raises rc 4 instead of returning mixed data. `route(q="flicker hud")` filters scope, build and tk, scores with the integer BM25F, fits the shortlist into `SHORTLIST_B` or abstains with a lettered reason.

Decisions (ADR): generation directories plus a pointer flip instead of in-place edits, so a crash gives the old or the new generation ([CITED, EX-SW-0171-BARRIER]); a four-band index for exact distance up to 3 with stdlib `bisect`; the R5 thresholds mirrored in `tiers.py` instead of importing `params`; FG derived from pins and never deleted, with the cap blocking compaction but not ingestion; typed links kept out of scores. The BM25F is an integer variant (permille K1 and B, log2-ppm IDF) and is not the float BM25 of the cited literature.
