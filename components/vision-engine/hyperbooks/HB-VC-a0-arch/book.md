CARD_D01F parallel design (source anchors [CITED, `visioncore/parallel.py`]): `describe_many` assigns contiguous ranges `[w * count // workers, (w + 1) * count // workers)` (`visioncore/parallel.py:104`). Each worker writes disjoint frame indices into shared outputs. Within a range, `_worker` passes the previous padded frame and raw `prev_tiles` into `describe_padded` (`visioncore/parallel.py:159`), enabling exact tile reuse. Whole-frame repeats reuse descriptors and alias immutable S0 planes (`visioncore/parallel.py:144`, `visioncore/parallel.py:165`). Classified or hinted tiles never feed this reuse. At the boundary frame, the worker pads the actual predecessor input pixels, but starts with `prev_tiles=None` (`visioncore/parallel.py:142`). It computes a full boundary descriptor while preserving exact equality words for sequential S2; it never reads another range's output. `_with_s0` returns views of shared planes through their alias indices (`visioncore/parallel.py:48`). `analyze` copies only the raw tile row and consumes those S0 views (`visioncore/pipeline.py:215`); no main-thread S0 redo occurs. Lazy hashes are filled after sequential classification (`visioncore/pipeline.py:223`). Acceptance is bound to `eval/results/rt0/EQUIV_RECEIPT.json` and its proof table, rather than a blanket exemption from the sealed-tree law. Regression oracles: `tests.test_rt0_d01` (range boundaries, serial byte equality, bounded cold descriptor calls) and `tests.test_parallel`; the production sealed gate also rejects unlisted paths and mismatching hashes.

`analyze` on a 1280 x 720 source: `Grid(1280, 720)` gives `s = 16` and 80 x 45 tiles [MEASURED, tests.test_registry.test_grid_table]; each frame is padded, described, classified, hashed, grouped into regions and linked to the previous frame; GOPs are encoded at the end; the vision directory is published in one rename. If a frame has the wrong shape the run stops with `E_VC_FRAME_SIZE` (rc 3) and the output directory is untouched.

Decisions (ADR): L0 is deliberately tiny so every stage can import it; the error registry fixes the rc class of each failure once (SPEC_INT R4) and `VqaError` carries it; ids live in one module so the grammar can be gated; the decoder has a strict reference path and a fast path that must agree; frame parallelism lives only in S1 because S2 onward is sequential by definition (state machines over time). Deviation: the directory name `HB-VC-a0-arch` does not match the paper grammar `HB-X-000`; the compliant `book_id` is `HB-VCA0-001`.
