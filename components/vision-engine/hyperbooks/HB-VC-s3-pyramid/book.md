Input: `tiles` (structured array with `morton` u16, `cls` u8, `resid` u8; existing cells only) and a `Grid`. Output: a `Pyramid` with per-level arrays `mx` (max resid, u8), `cnt` (dirty tiles, `cls >= layout.CLS_DIRTY_MIN`, u16) and `real` (existing tiles, u16) for levels `0..L`, where `L = levels_for(gw, gh)` is computed with `bit_length`. Cells of the `4^L` Morton square outside the grid have resid 0 and real 0.

- `node(level, i)` returns `(level, m0, max, cnt)`; `node_id(frame, level, i)` returns `p<F>:L<k>:<m0:04x>` through `ids.node_id`; `children(level, i)` returns the child indices that hold real tiles; `bound(level, i)` is the exact subtree maximum.
- `query_aabb(x, y, w, h)` returns at most four nodes at the smallest level whose aligned blocks cover the tile box, sorted by `m0`; `max_aabb` is the maximum over those nodes, an upper bound for the rectangle.
- `select(B, rsel=None)` returns at most `B` nodes whose disjoint spans cover every tile with `resid > rsel`.

| error code (`visioncore/errors.py` CODES) | rc | raised by |
|---|---|---|
| `E_USAGE` | 2 | `select` when `B` is not an `int` or `B < 1` |
| `OK` | 0 | no other code is raised by S3 |

Exit-code classes are `RC_CLASSES = (0, 2, 3, 4, 5, 6)` (`errors.py`); rc 1 is never used. The module is a pure function of its inputs: no clock, no RNG, no float. Toolchain: numpy and stdlib `heapq`; the suite is `python3 -m unittest tests.test_pyramid` (15 tests, rc 0, `R-s3-pyramid-unittest`).

Deps in the module header: `vc.errors`, `vc.ids`, `vc.layout`, `vc.p`; third party `numpy`; stdlib `heapq`. Layer 2, imports from L0 only. Consumers: `regions`, `pipeline` and `pack` (budgeted node selection in S6).

1. Scatter `resid`, the dirty flag and presence into zero arrays of size `4^L` at the Morton index of each tile.
2. Reduce `L` times with `reshape(-1, 4)`: `max` for `mx`, `uint16` sum for `cnt` and `real` ([CITED, EX-VG-0015-2]).
3. `query_aabb`: clip the rectangle to the image, convert to a tile box, take `m = (max(w_t, h_t) - 1).bit_length()`, visit at most 2 x 2 aligned blocks at level `m` and keep those with real tiles.
4. `select`: push the root when its max exceeds `rsel`; pop the best node by `(-max, -level, m0)`; emit it at level 0, when `cnt == real`, or when `len(out)+len(heap)+4 > B`; otherwise push the children whose max exceeds `rsel`.

Commands: `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest tests.test_pyramid -v`; gates `python3 tools/gates.py --all`; receipts via `python3 hyperbooks/_tools/reseal.py R-s3-pyramid-unittest R-s3-pyramid-select`.

## <a id="hb-s7"></a><a id="pm-s7"></a>7. Narrative

<!-- HB:BEGIN hb.section.v2 -->
```json
{"anchor":"hb-s7","claims":[],"code_anchors":["visioncore/pyramid.py::Pyramid.select"],"diataxis":"reference","hb_id":"HB-VCS3-001","kind":"narrative","n":7,"purpose":"One end-to-end trace of select and the design decisions.","route":{"emit":true,"tags":["software/router"]},"schema":"hb.section.v2","title":"Narrative"}
```
<!-- HB:END -->
Trace for a 1280x720 frame (80 x 45 tiles, L = 7): tiles at Morton codes 90 and 120 carry resid 100 and 80, both above R_SEL (7). `select(8)` pushes the root (max 100, cnt 2), pops it, and since it is not full and `0 + 0 + 4 <= 8` it pushes the children whose max exceeds 7; the descent follows the two paths to level 0 and emits `(0, 90, 100, 1)` and `(0, 120, 80, 1)`. With `B = 1` the root is emitted at once (`0 + 0 + 4 > 1`): bounded, covering, coarse.

Decisions (ADR): D1 best-first by max, then by coarser level, so the largest residual is refined first; D2 emit-when-tight (`len(out)+len(heap)+4 > B`) guarantees the bound because at most four children are pending; D3 a total-order heap key instead of a random selector, so the output is deterministic; D4 Morton-indexed flat arrays, because aligned blocks are contiguous ranges ([CITED, EX-VG-0034-2], a 3-D result specialised to 2-D).
