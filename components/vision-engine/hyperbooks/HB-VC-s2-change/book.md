`classify_tiles(state, tiles, words_eq, y_cur=None, grid=None, params=None) -> (tiles_out, state, summary)` (`vc.s2.classify`); `classify_first(state, tiles, y_cur=None)` for frame 0 (`vc.s2.classify_first`); `ClassState.init(tiles)`.

- **Pre:** `len(tiles) == len(words_eq) == state.n`, else `VqaError("E_VC_GRID_MISMATCH")`. `tiles` carry the descriptors of frame t (fields `layout.TILE_FIELDS`; `cls` ignored). `words_eq[i]` is exact pixel equality of tile i with t-1 (from S1). `grid=(s, gw, gh)` and `y_cur` (from `luma_padded`) enable MOVED, the aperture rule, SHADE_ONLY and the sig64 confidence masks; without `y_cur` every sig64 bit counts.
- **Post:** `tiles_out` is a copy: `cls` in 0..6 (`UNCHANGED JITTER CHANGED MOVED FLICKER FROZEN DRIFT`), `resid = min(255, r>>2)` (display units r/4, not q4; 0 for UNCHANGED), `mv_dx` and `mv_dy` set only for MOVED, flag `GLOBAL_MV` (b6) only on MOVED tiles explained by the published global vector, flag `SHADE_ONLY` (b2) only on CHANGED tiles; both bits are cleared from the input flags first, other bits are copied. The input arrays are not mutated; `state` is mutated in place and returned.
- **summary:** `{"first", "n" (7 class counts), "cov_ppm", "global_mv"}`; `cov_ppm = n_dirty*10^6 // N` with dirty = `cls >= 2` (SPEC_INT I6; JITTER and UNCHANGED excluded); `global_mv = [dx, dy]` only when published.
- **Invariants:** integer only, floor semantics (I4), pure step with no clock or RNG (I2); a `words_eq` tile is never active (INV-S2-EXACT).

**Residual** `r(a,b)` in q4 (1/16 grey), `vc.s2.residual`: `|dy_q4| + W_CHROMA*(|dco_h|+|dcg_h|) + |dsig_q4| + W_HAM*max(0, popcount((sig64_a^sig64_b) & mask) - H_DEAD)`; `mask = conf_a | conf_b` (hb-s2.sig_conf), `None` = all 64 bits; int64, vectorised.

**Thresholds** `vc.s2.drift` (`thresholds`): `T_enter = T0*(1000+BAND)//1000`, `T_exit = T0*(1000-BAND)//1000`, `drift_u = max(T_enter, DRIFT_U_Q4)` (DRIFT never fires inside the hysteresis band; raising `T0_Q4` raises the DRIFT threshold). Defaults 35 / 28 / 35 q4 [MEASURED, tests.test_change.test_default].

**ClassState**, arrays of length N: `hot u8`; `hist16 u16` (bit0 = active at t); `still_run u8` (saturates at 255); `pre_act u8` (activity count over the 16-frame history at the stop); `mvh16 u16` and `pre_mov u8` (motion history and its count at the stop); `ref_max u16`, `stall u8` (DRIFT latch); `ref`, `prev1`, `prev2` (`TILE_DT` records of 32 B [MEASURED, tests.test_change.test_record_layout]); `cf_ref`, `cf1`, `cf2 u64` (confidence masks, all ones until a luma plane is seen); `y_prev` (padded luma of t-1 or None). `digest_bytes()` concatenates the arrays in a fixed order for determinism checks.

### <a id="hb-s2.sig_conf"></a>2b. sig64 confidence masks (`vc.s2.sig_conf`)

The sig64 confidence masks are generated by `sig_conf(y_plane, s, gw, gh, mortons, sig_dead_q4)` (`vc.s2.sig_conf`) from the padded luma plane: bit k of the u64 mask is set iff the mean of sub-block k (same 8x8 layout and bit order as the descriptor sig64) is more than `SIG_DEAD_Q4`/16 grey from the tile mean (integer test `16*|sub*n - sum*b*b| > SIG_DEAD_Q4*n*b*b`, n = s*s, b = s//8). `SIG_DEAD_Q4 = 0` gives all-ones masks. `classify_tiles` computes the mask of frame t once per call (`_conf_of`), keeps the masks of prev1, prev2 and ref in `cf1`, `cf2`, `cf_ref`, and passes `cf | cf_prev` to every `residual` call, so a sig64 bit that flips inside the dead band in both frames is not counted (AMEND_NR). `classify_first` seeds all three masks from frame 0's plane. On the calibration seeds, 1020 X4 runs show zero false positives [MEASURED, tests.test_e12_sig_dead.Registry.test_fit_table_applies_declared_rule].

`vc.s2` is layer 2 (`# @module` header, deps `vc.layout`, `vc.p`, `vc.errors`). Imports in code: `numpy`, `layout`, `params as P`, `errors.VqaError`. Consumed by `pipeline.py` (L4) and read by `regions.py` and `pyramid.py` (`cls`, `resid`, `mv_*`). It must not import `vmem` or `vadapt`, and uses no float.

```
layout, params, errors (L0) -> change (L2) -> pyramid, regions (L2) -> pipeline (L4)
```

`change.py` defines its own `TILE_DT` from `layout.TILE_FIELDS` (asserted `itemsize == layout.TILE_SIZE`), wire-compatible with `desc.TILE_DTYPE` without importing `desc` (L1). Stage order inside a run: S0 pad, S1 describe (lazy xh64), S2 classify, then `desc.fill_xh64`, S4 regions.

Per frame t >= 1 (frame 0: `classify_first`, all UNCHANGED, `ref = prev1 = prev2 = desc_0`):
1. `cf = sig_conf(t)`; `r1 = residual(t, prev1, H_DEAD, cf | cf1)`, forced to 0 where `words_eq`.
2. `active = hot ? r1 > T_exit : r1 > T_enter`, and never where `words_eq` (hysteresis).
3. Stillness: on an active-to-inactive transition `pre_act = popcount(hist16_before)` and `pre_mov = popcount(mvh16)`, `still_run = 1`; otherwise `still_run` counts up (saturating); active resets it. `hist16 = (hist16<<1)|active`.
4. Provisional class: JITTER = `~words_eq & ~active`; else UNCHANGED.
5. FLICKER (A-B-A only, no transition counter): `active & r(t, prev2) <= T_exit & r1 > T_enter`.
6. MOVED (needs `y_cur`, `y_prev`, `grid` and some active tile): candidates in order [global, island, pool] (`vc.s2.motion`, `vc.s2.island_vector`). `global_vector` picks per axis the shift minimising `SAD*n//(n-|d|)` over projections with ties `(cost, |d|, d)`, accepted iff `3*cost(best) < cost(0)`. A vector explains a tile iff the source window is inside the padded image, `MV_SAD_RATIO_DEN*SAD(v) < SAD(0)`, `16*SAD(v) <= s*s*T_exit`, and its SAD is strictly below the tile's best so far. The global vector is published (`summary.global_mv`, flag GLOBAL_MV) iff the tiles it explains reach `GLOBAL_SHARE_PPM` of the active tiles; then it also turns A-B-A tiles it explains, and edge tiles explained on the clipped window, from FLICKER to MOVED; otherwise it is withdrawn. Islands are the 8-connected components of active non-FLICKER tiles, largest first, at most `ISLAND_MAX`; each island vector other than (0,0) and the published one is offered to its own island, then every island vector is offered to every active tile (pool).
7. Precedence: CHANGED (active) < MOVED < FLICKER.
8. FROZEN (non-active tiles): the frame is alive iff the global vector is published or `n_active*10^6//N >= FROZEN_COV_PPM`; then FROZEN iff `still_run >= FROZEN_M` and `pre_act >= FROZEN_PRE_ACT`. Aperture rule: with a published vector, a non-active tile the vector explains at least as well as zero motion is FROZEN only if `pre_act - pre_mov >= FROZEN_PRE_ACT`.
9. DRIFT (non-active, not FROZEN): `rr = residual(t, ref, H_DEAD, cf | cf_ref)`; the latch `ref_max` grows with new maxima (`stall` resets), else `stall` counts up; DRIFT iff `rr > drift_u`, `stall < DRIFT_STALL` and the tile is not aperture-ambiguous. `stall >= DRIFT_STALL` settles the tile (ref advances). SHADE_ONLY on CHANGED tiles with luma: `min(n_pos, n_neg) <= s*s//SHADE_DEN` and `|d_edge| <= SHADE_EDGE_MAX`.
10. `resid = min(255, r>>2)` (`rr` for DRIFT tiles, `r1` otherwise; 0 for UNCHANGED). State update: `ref := desc_t` and `cf_ref := cf` for CHANGED, MOVED, FLICKER and settled tiles (not on DRIFT); `mvh16` shifts in MOVED; `prev2 <- prev1 <- desc_t`; `y_prev <- y_cur`.
