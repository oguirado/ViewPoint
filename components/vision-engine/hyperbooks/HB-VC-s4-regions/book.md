- `regions_of(tiles, W, H, frame)`: `tiles` is a structured array with the fields of `layout.TILE_FIELDS` (it reads `morton, cls, flags, resid, edge, mv_dx, mv_dy`); returns a list of `vqa.core-region/v1` dicts sorted by minimum Morton.

1. Range check: every `morton` is decoded with `_compact_v`; a cell outside `gw x gh` raises `E_VC_ID_RANGE` before any region is built. Only classes CHANGED, MOVED, FLICKER, FROZEN, DRIFT enter a group; UNCHANGED and JITTER tiles join no region.
2. `_islands(cells)`: parent map keyed by `(tx, ty)`; tiles are scanned in raster order against the 8 neighbours; `union` sets `parent[b] = a` iff `cells[a] <= cells[b]`, so the root of an island is its minimum Morton code (I5).
3. Per island: `cls_hist`, majority `kind`, `r_max`, `r_sum`, `edge_ppm`, `shade_only`, `occ` from flag bits 4 and 5, `bbox_t`, clipped `bbox_px`, `block` and run-length `spans`.
4. `adjacency`: owner map from tile to region id; the half neighbourhood `(1,-1), (1,0), (1,1), (0,1)` counts each unordered contact once.
5. `match_regions`: prev tiles shift by `(mv + s//2)//s` per axis, using the region's own `mv` for group MOV and `global_mv` for every other group; edges below `MATCH_OVERLAP_PPM` of the smaller region are dropped; the rest are accepted greedily in the order `(overlap desc, a, b)`.

Callers: `visioncore/pipeline.py` calls `regions_of` and then `match_regions(prev_regs, regs, gmv, grid.s)` per frame. Commands: `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest tests.test_regions -v`; receipt via `python3 hyperbooks/_tools/reseal.py R-s4-regions-unittest`.
