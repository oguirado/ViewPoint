- `encode_run(tiles_seq, grid, frame_nums=None, global_motion=None, regions=None, links=None, params=None)`: per-frame tile tables (N records, ascending Morton), `grid` with `.N .gw .gh .s`; `global_motion[i]` is `(dx, dy)` px or None; `regions[i]` core-region rows; `links[i]` the core-link object for frame i-1 to i. `frame_nums` must be strictly increasing and an empty run is rejected, both with `E_VC_FORMAT`.
- Output: `[Gop]` with `blob` (header, zlib I-frame, P-frames), `blob_sha256` (stored bytes), `canon_sha256` (uncompressed canonical identity, I10), `key_sha256`, `delta_bytes`, `tracks`, `cycles`, `glob`, `events`, `dirty_ppm`.
- `decode_gop(blob)` returns `(header, [(frame, committed table of N*TILE_SIZE bytes)])`; `write_gops(out_dir, gops, grid_ident, params_sha256)` writes `gops.bin` and `gops.jsonl` with `canon.write_atomic`.
- Pure and deterministic: no clock, no RNG, no float; the same tiles and params give a byte-identical blob (`test_determinism`).

| error code (`visioncore/errors.py` CODES) | rc | raised by |
|---|---|---|
| `E_VC_FORMAT` | 2 | `encode_run` (empty run, non increasing `frame_nums`, wrong table shape) |
| `E_GATE` | 5 | `decode_gop` (zlib error or sha8 mismatch, reason `g_blob_integrity`) |
| `E_IO` | 2 | `write_gops` through `canon.write_atomic` |

The delta and header codes `E_DELTA_TOKEN`, `E_DELTA_LEN`, `E_DELTA_BOUND`, `E_GOP_MAGIC`, `E_GOP_VERSION`, `E_GOP_GRID`, `E_GOP_PAD`, `E_GOP_MASK` are not registered in `errors.CODES`; `_gerr` builds them as `VqaError` with an explicit rc 2 (raised by `rle_decode`, `parse_header`, `decode_gop`). Exit-code classes are `RC_CLASSES = (0, 2, 3, 4, 5, 6)`; rc 1 is never used. Toolchain: numpy, zlib, hashlib, struct; the suite is `python3 -m unittest tests.test_gop` (36 tests, rc 0, `R-s5-gop-unittest`).

1. `dirty_mask`: `cls >= layout.CLS_DIRTY_MIN` (2). `dirty_ppm_of(n_dirty, n) = n_dirty*1000000 // n` (INT I6).
2. `cut_flags`: a cut at t>0 iff `ppm[t] >= CUT_PPM_1F`, or `ppm[t] >= CUT_PPM_2F` and `ppm[t+1] >= CUT_PPM_2F`; the last frame has no look-ahead.
3. `plan_gops`: I-frame at frame 0, at every cut, and when t minus the last start reaches `GOP_K`; FLASH iff the GOP starts at a cut and t+1 is also a cut.
4. `encode_run`: per GOP the I-frame is the raw table compressed with zlib level 6 (storage only); `ref` starts as a copy of the I-frame; every later frame is `_encode_pframe`: XOR the dirty records against `ref` (not t-1), token RLE, then `ref[dirty] = rec`. The global triplet `(gdx, gdy, share_ppm)` is the clipped CORE `global_mv` plus the share of non-UNCHANGED tiles with flag bit 6.
5. Identity: `canon_sha256 = sha256(header with izlen=0 and body_sha8=0, raw I-frame, body)`, so the zlib version cannot change it (I10); `blob_sha256 = sha256(stored bytes)`.
6. `decode_gop`: verify header, zlib, sha8 of I-frame and body (rc 5 on mismatch), zero pads, mask popcount equals `n_dirty`, decode the delta, XOR into `ref`, emit the committed table per frame; no trailing bytes.
7. `build_tracks`: consumes `vqa.core-link/v1` and never re-matches. Track key `k<f_first>:<min morton>`. An unlinked region (frame > 0, links present) is APPEAR; a previous region without outgoing link is VANISH; `split` and `merge` ids give SPLIT and MERGE. Per frame over the track's tiles: FROZEN iff at least 500000 ppm are cls 5 (I3), DRIFT iff any cls 6, FLICKER iff any cls 4, GLOBAL iff at least 500000 ppm have flag bit 6.
8. `find_cycles`: xh64 matrix over frames; for p = 2..8, `c = (H[i]==H[i-p]) & (H[i]!=H[i-1]) & exact`; a maximal run of at least p gives `{t, p, n, end}`; a tile assigned to p is skipped for larger p; only tiles with at least one non-UNCHANGED frame count.
9. `gop_record` builds the `vqa.gop/v1` line; `write_gops` writes the two files.

Commands: `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest tests.test_gop -v`; receipts via `python3 hyperbooks/_tools/reseal.py R-s5-gop-unittest R-s5-gop-rle-bound`.

A run of 25 frames on a 16x10 grid (160 tiles, 4 macroblocks) arrives with per-frame `cls` from S2. S5 computes the dirty ppm, plans GOPs of at most `GOP_K` frames with extra I-frames at cuts, and for each GOP writes the raw I-frame table (zlib level 6) followed by one P-frame per later frame: a 24-byte header, one mask word per occupied macroblock and the token RLE of the XOR of the dirty records against the reference. `decode_gop` replays the deltas and returns the committed table of every frame, byte-equal to the encoder's model. [MEASURED, tests.test_hb_s4_s5_hybrid.NarrativeTrace.test_trace_is_true]

Decisions (ADR): XOR against `ref`, not t-1, so a JITTER tile after its commit costs zero bytes (consequence: sequential decoding of at most K-1 deltas); `canon_sha256` over uncompressed bytes so zlib is storage only (I10); pads are zero and checked at decode so hashes are a function of values. Events also include CUT besides FLASH; track flags include SPLIT, MERGE and GLOBAL.
