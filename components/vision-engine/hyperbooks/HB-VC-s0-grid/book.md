- Input: `W, H` Python `int`, `1 <= W,H <= 8192` (`layout.DIM_MAX`).
- Output: `Grid` with `.W .H .s .gw .gh .N .ident .morton[gh,gw] u16 .flat .mortons[N] .tx[N] .ty[N] .order[gh,gw] i16`, plus `.pad(rgb)` and `.pad_flags()`. `flat` maps Morton rank to the row-major cell; `order[ty,tx]` maps a cell to its Morton rank.
- `field_ids_of_rect(frame, rect_px, grid)` returns the sorted list of `f<F>:t<m:04x>` of a closed box clipped to the image; an empty rect gives `[]`, a rect fully outside gives `E_VC_ID_RANGE`.
- `aligned_block((tx0,ty0,tx1,ty1))` returns `(k, m0, m1)`, the smallest aligned 2^k block, with `m1 = m0 + 4^k - 1`.
- Pure and deterministic: no clock, no RNG, no float (C-INT-DET).

| error code (`visioncore/errors.py` CODES) | rc | raised by |
|---|---|---|
| `E_GRID` | 2 | `Grid(W,H)` (via `layout.grid_params`): non-int or outside `1..8192` |
| `E_VC_ID_RANGE` | 3 | `field_ids_of_rect` for a rect fully outside; `aligned_block` / `layout.morton` for a tile coordinate above 255 |
| `OK` | 0 | no other code is raised by S0 |

Exit-code classes are `RC_CLASSES = (0, 2, 3, 4, 5, 6)` (`errors.py`); rc 1 is never used. `E_GRID` (rc 2) is the grid-rule failure; `E_VC_FRAME_SHAPE` (rc 2) belongs to S1 and is a different code of the same class. Toolchain: numpy only. The suite is `python3 -m unittest tests.test_grid` (7 tests, rc 0 [MEASURED, R-s0-grid-unittest]).

1. `layout.grid_params(W,H)` tries `s = 16, 32, ...` until `gw*gh <= CELL_MAX` and `max(gw,gh) <= AXIS_MAX` (ceiling division `-(-W // s)`).
2. `Grid.__init__` fills `morton[gh,gw]` with `layout.morton(tx,ty)`, takes `perm = argsort(morton.reshape(-1), kind="stable")` (so `flat = perm`: rank to row-major cell), `mortons = morton[perm]`, `tx = perm % gw`, `ty = perm // gw`, and the inverse `order[perm] = arange(N)`.
3. `Grid.pad(rgb)` returns `rgb` itself when `gh*s == H` and `gw*s == W`, else `np.pad(..., mode="edge")` ([CITED, EX-OC04] edge replication by clamping).
4. `Grid.pad_flags()` is `((tx+1)*s > W) | ((ty+1)*s > H)`.
5. `field_ids_of_rect` clips the rect to the image and formats ids through `ids.field_ids_of_rect`; `aligned_block` raises `k` until both corners share the block.

Layer L1; module header deps `vc.ids`, `vc.layout`. Command: `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest tests.test_grid -v`; receipts via `python3 hyperbooks/_tools/reseal.py R-s0-grid-unittest R-s0-grid-table`. Consumers: S1 `desc.py` (pad, tile order), S2-S5, `vadapt.synth` (rect truth), VMEM (`aligned_block` to the track key).

A 1280 x 720 frame: `grid_params` tries `s = 16`, gets `gw = 80`, `gh = 45`, `N = 3600` and both caps hold, so it is accepted [MEASURED, tests.test_grid.TestGrid.test_table]. `Grid` fills the Morton table: tile `(tx=1, ty=0)` has code 1 and `(0, 1)` has code 2. 720 = 45 * 16, so `pad` returns the frame itself; a 1000 x 700 frame would be edge-replicated to the next multiple. Decisions (ADR): D1 minimum tile 16, not 8, because sig64 needs 8x8 sub-blocks. D2 axis cap 255 because the Morton code has 8 bits per axis. D3 edge replication, not zeros, so every tile has `s*s` real samples and unchanged borders stay byte-equal. D4 `E_GRID` rc 2 is used (SPEC_INT R4) where SPEC_CORE says `E_VC_FRAME_SHAPE`; both are rc 2 and the tests only check the class.
