## Public API and trust boundary

Export frozen value records, with exact positional field order: `Handle(kind, canonical_id, generation)`, `StreamSpec(width, height, slots, quota_bytes)`, `StreamToken(handle, epoch)`, `FrameRef(handle, epoch, frame_seq, width, height, rgb, digest)`, `Drop(handle, epoch, frame_seq, reason)`. `StreamError`, `QuotaError`, `StaleStreamError` are `ValueError` subclasses.

`WindowStreamBank(*, quota_bytes, ring_factory=None, step_hook=None)` exposes `open(handle,spec)`, `publish(token,rgb,*,frame_seq)`, `read(token,*,step_hook=None)`, `resize(token,spec)`, `close(token)`, plus atomic `open_many`/`resize_many`, `check_lock_order(handles)`, `reserved_bytes` and `retry_cleanup()`. `read()` reports an owned `FrameRef` or bounded explicit `Drop`. Hook receives one of `"before_copy"` or `"after_copy"` with no metadata mutex held; hook exceptions propagate.

Accepted identity kinds: `cdp_tab`, `x11_window`, `xvfb_screen`, `capsule`, `godot_window`. Canonical actuation domains for a capsule and its child screen must be normalized to the same destination by the upstream actor registry; **this bank never takes actor/focus locks or dispatches actions**. External `Handle`, `StreamSpec` and token values are accepted structurally after normalization, without imports from another repository. Geometry epochs are separate from unbounded nonnegative generation integers. Only exact `uint8[height,width,3]` RGB24 frames are supported; no encoded/alternate capture modes, no crop requests or disk-frame fixtures. A future crop API must check trusted source dimensions before reading memory; crop integration is **AUSENTE** here.

The default `ring_factory` creates a bank-owned `bytearray` of exact `rtring.ring_bytes` size; tests may inject bytearray-backed rings. An external factory receives `(handle,spec)` and must return a *new* writable full-layout buffer directly or via an owner `.buffer`/`._mm`. Factories that manage native mappings must make `close() -> True` only after proven unmapping, or expose compatible `_released is True`. Missing proof, `False`, `BufferError` or still-live views retain the full reservation; call `retry_cleanup()` once the owner can really unmap. An unreturned allocation after a factory exception cannot be inspected by this bank: the factory remains responsible for such resources.

## Invariant reasoning

- **INV-M4-1, identity and sequencing.** One full ring allocation per active `(kind, canonical_id, generation, epoch)`; live buffer identity reuse is rejected. A generation can be opened once, even after close. Resize creates a *new* ring and increments only the geometry epoch; old tokens fail with `StaleStreamError`. `frame_seq` increases monotonically across resize and is represented as `render_index` in the legacy unsigned-64 ring format (maximum `2^64 - 2`). Writer admission serializes the per-stream publication protocol; callers must not externally write concurrently except adversarial tests.
- **INV-M4-2, reservations.** Charge exactly `rtring.ring_bytes(slots,width,height)` for every staged ring, not only RGB payload. Per-stream quota must cover that exact layout. Multi-target admission reserves all requests atomically before invoking any factory and validates canonical `(kind, canonical_id, generation)` order without acquiring a mutex. No partial group is exposed. On failure, refund only allocations that provably do not exist or have been fully released; existing rings and any unknown live mappings remain charged. Resize must have transient quota for both old and new allocations. `reserved_bytes` is logical retained-ring accounting, not RSS or workspace disk-block accounting.
- **INV-M4-3, guarded read.** Recheck stable even slot `seq`, local `render_index`, slot CRC and a later repeated sequence/index/CRC observation around a copy. Head is checked for absence and regression. The read pins its ring against close/resize unmapping, executes optional hooks outside the registry lock and performs at most eight attempts. A persistent mismatch returns `Drop(reason="torn"/"lapped"/"absent")`; epoch invalidation during read returns `Drop(reason="stale_epoch")`. CRC is integrity evidence only, not a substitute for atomic CPU ordering or proof against CRC collisions.
- **INV-M4-4 / G M4 5, owned lifetime.** Successful reads use an immutable *bytes*-backed contiguous `uint8` NumPy array; its writeable flag cannot be re-enabled. `FrameRef.digest` is SHA-256 of canonical row-major RGB bytes. Later publication, slot wrap or resize never mutates an already returned frame. Borrowed/strict zero-copy delivery and a native hardware fence guarantee are **AUSENTE**.
