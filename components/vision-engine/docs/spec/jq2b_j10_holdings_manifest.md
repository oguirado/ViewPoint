# J10 — sealed, source-neutral Holdings corpus manifest

## API and scope

`eval.v2eval.holdings_manifest.build_manifest(cases, *, environment, lanes, generator_source, generator_sha256, algorithm_id, master_seed)` returns an immutable `Manifest(canonical_json, sha256)`; `metadata()` produces a detached copy. `pixel_declaration_sha256(width, height)`, `derive_case_seed(...)`, `parse_metadata(text)` and `verify_manifest(text, seal)` are public validation helpers. None performs I/O or imports CDP, Godot, or external broker adapters. The only generator dependency is read-only `SplitMix64` from `eval/gui_synth/rng.py` (lines 5–28); source bytes are supplied by a trusted caller, not inspected from the filesystem or inferred from time.

`environment` **must** be a closed record with `python`, `numpy`, `platform` and lowercase hex `dependency_digest`. The caller must supply verified environment values and a trusted digest for all relevant dependencies. `generator_source` must be nonempty bytes whose SHA-256 matches `generator_sha256`. `master_seed` and `seed_tag` are integer-only uint64. Derived independent case seeds mix the master seed with the canonical lane handle, case id, seed tag, generator digest and environment identity using SHA-256 and `SplitMix64`.

Each lane contains an exact `handle = {kind,canonical_id,generation}`, `case_ids`, and `epoch_plan` entries `{case_id,epoch,frame_seqs}`. Each case contains exactly `case_id`, `seed_tag`, `geometry={width,height}`, `faults`, `expected`, `expected_frame_count`, `expected_frame_seqs`, `frames`. Expected intent is an independent authored record `{label,dx,dy,gm_ops,fl_ops}`; unsupported label strings fail. Absent operation counters are `null`, not zero. Each frame supplies `{frame_seq,rgb,pixel_decl_sha256,raw_sha256}` and may supply **both** `normalized_rgb` and `normalized_sha256`. Only volatile HxWx3 `numpy.uint8` arrays are accepted; arrays are copied before hashing and discarded. The pixel declaration is SHA-256 over canonical `{channels:3,dtype:'uint8',height,order:'C',width}` and protects layout. Only scalar fields and digest strings enter the sealed output: no frame data, crops, pixel masks, arbitrary unbounded labels, wall clock, measured speed or estimated capacity.

## Invariants and regression controls

* **INV-J10-1**: A unique typed lane handle owns each case, and the epoch plan binds every case and its exact declared sequences. Canonical ordering is independent of lane, case and frame input order; a lane's derived case seed never depends on another lane's generation order. Source boundary: `eval/v2x/per_window_detector.py` lines 92–183 handles reset/continuity and 183–296 local GM/FL execution. This manifest does **not** mutate that detector.
* **INV-J10-2**: SHA-256 of supplied generator bytes must equal declared source identity; dependency identity, seed, algorithm, environment and raw pixel digests all enter the deterministic seal. `verify_manifest` rejects noncanonical JSON, duplicate keys, floats, invalid expected top-level records and seal mismatch. A seal identifies pinned inputs; it does not independently prove an untrusted generator *executed* the claimed source or that a dependency digest was honestly measured.
* **INV-J10-3**: Existing `eval/v2x/gm_bands_hv.py` uses context-local operation accounting (`ContextVar`, lines 9–49); FL owner `eval/v2x/fl_v3.py` delegates tracker accounting and the detector (`per_window_detector.py`, lines 183–296) isolates calls. J10 stores supplied missing counters as null, never resets or aggregates GM/FL contexts. Caller/plugin exception isolation remains an upstream owner gate, not a claim made by corpus hashing.
* **INV-J10-4**: Expected labels are supplied as generation intent; manifest never calls a predictor to derive expected labels. Fault vocabulary covers static, localized changes, integer translation, periodic flicker with a real-motion veto, sparse support, mixed history, skipped sequences, resize/epoch, caller mutation, plugin exception and eviction. Fault labels describe authored fixture intents; they are **not** proof that a particular test drove the actual detector along each path.

Healthy vs negative regression contrasts in `tests/test_jq2b_j10_holdings_manifest_implementation.py` exercise shuffled equivalent seals versus changed source or dependency identities, valid frame/counts versus missing or duplicated frame identities, valid layout versus tampered declaration/content, correctly typed integers versus booleans, closed records versus extras, canonical JSON versus duplicate keys/floats, and non-persistence versus a write spy. No screenshots or pixels are written to disk.

## Source-neutral boundaries and blocked limits

A source-neutral consumer supplies observations and immutable `uint8` frames, result digests, optional external T2 `{tick,seq,cmd,args}` requests, broker outcomes, and lane-local reset notifications. Trusted authority must remain outside these untrusted T2 fields. Holdings command spelling in COMMANDS.md/CONTRACTS.md (such as `pause` with empty args, `new_game` with `country_id`, `difficulty`, `opening_mode`, `seed`) must be validated by the owner broker, not by a corpus hashing function. `source.kind=cdp` is reserved for actual CDP-origin DOM/AX observation; a Godot tree must not be relabeled CDP. This builder does not have the real Electron H2/H3 publisher, earlier-wave owner receipts, verified host admission binding, the local operator reference `$HB_DOCS/HYPERBOOKS_WEB_MGMT_v1.md` sections 10 and 14, or broker/T2 owner implementations. Those are **AUSENTE** and cannot be asserted accepted. Admission is not economic acceptance; a rejected attempt may increment *trusted* bookkeeping but may not mutate simulation state. No claims about host capacity, timing or runtime adapter compatibility follow from the in-memory tests. Genuine fake-CDP-derived DOM/AX evidence and Godot broker integration require separate owner validation.

This module deliberately remains manifest-only, and does not edit the sealed RNG, primitive detectors, runtime adapters, or ledger. One collection PR is not host acceptance.
