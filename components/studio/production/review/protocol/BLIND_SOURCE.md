# Blind viewing

View the chronological full-frame PNGs in filename order and play the accompanying video at normal speed if supported. Describe what moves, the visible action in order, and any visible consequence. Identify the frames that support your account and say what can be seen in each. If the action or consequence is unclear, describe what the pixels show.

Return only the JSON specified in `blind.schema.json`. Use `frame_index.json` to look up the PNG SHA-256 for each cited frame. Submit this response before receiving the scoring rubric or any description of the intended action.
