# Security policy

wender-agent drives real browsers and desktop programs. Reports about privilege escalation from page
content, credential or screen-data leaks into model context, unsafe actions taken without a lock, or
escapes from the redaction layer (`wender/perceive/redact.py`) are in scope.

Report privately through GitHub Security Advisories on the repository ("Report a vulnerability").
Do not open public issues for vulnerabilities. Only the latest release is supported.
