Google DeepMind × Berkeley hackathon · 14 Nov 2026

AI agents that use real software, by looking at the screen.

ViewPoint gives each AI agent its own capsule: a real program window with its own identity, on a private display, while the person keeps the desktop keyboard. The agent looks at the screen, proposes an action tied to what it saw, and gets back a verified receipt or a typed refusal, never a silent success. This site explains how it works, with the Gemini runs that show it.

  • 4 Gemini agents on one wall

Architecture

Architecture

Typed verdicts you will see in the logs

  • NAV_VERIFIED the page reached is the page asked for
  • BROWSER_BOUNDED_ACTIONS_VERIFIED a bounded browser task checked step by step
  • STALE_FRAME the screen changed since the agent looked
  • INPUT_UNCERTAIN input sent, effect not proven
  • VERIFICATION_FAILED the result is not what was asked
  • URL_QUERY_UNOBSERVABLE a ?query cannot be verified; refused with zero input
  • URL_FRAGMENT_UNOBSERVABLE a #fragment cannot be proven; refused with zero input
  • MW_PROGRAM_NO_VISIBLE_EFFECT nothing visible happened; not counted as success
  • AGENT_BUSY the shared lane is taken; the agent waits, nothing is sent
  • CAPSULE_LIMIT_REACHED admission ceiling of 16 capsules, not a capacity claim
