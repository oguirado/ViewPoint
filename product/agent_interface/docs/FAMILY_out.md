# `vp out`: bounded reading of files and command output

Reads files in pages, searches them, runs a command with its output spooled, and counts tokens. Wraps newton-py (`read`, `find`, `sh`, `tok.count`). Every other command that produces long output puts it in a spool file and names the `vp out read` command in `next`.

Generated by `docs/build_pages.py` from `design/MCP_TOOLS.json` (vpops/1.4), `docs/family_notes.json` and `router/seeds.jsonl`. For exact file:line citations with freshness marks run `vp docs ask "<question>"`.

## Commands

| Command | Class | What it does | Wraps |
|---|---|---|---|
| `vp out read` | R (read-only) | Page a spooled output or any large file. | `$VP_NPY read PATH [A:B]` |
| `vp out find` | R (read-only) | Find terms in a file or directory, ranked by coverage; reports AUSENTE terms after a complete scan. | `$VP_NPY find 'TERMS' PATH --k N` |
| `vp out sh` | W (write-own) | Run a command with bounded output: rc, counts, sha256, last N lines, spool path. Subject to every safety rule of this page. | `$VP_NPY sh --tail N -c 'CMD'` |
| `vp out tokens` | R (read-only) | Exact o200k token count of a file. | `$VP_NPY tok.count --path PATH` |

## Arguments, confirm ids and codes

- `vp out read <path> <range>` MCP tool `vp_out_read` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `NOT_FOUND` rc 5, `SECRET_PATH` rc 3.
  - `<path>` (string, required): file path
  - `<range>` (string): line range A:B
- `vp out find <query> <path> [--k]` MCP tool `vp_out_find` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `AUSENTE` rc 5, `SECRET_PATH` rc 3.
  - `<query>` (string, required): question or search terms
  - `<path>` (string, required): file path
  - `--k` (integer): number of results
- `vp out sh --cmd [--tail] [--head]` MCP tool `vp_out_sh` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `REFUSED` rc 3, `UPSTREAM` rc 9, `TIMEOUT` rc 124.
  - `--cmd` (string, required): shell command
  - `--tail` (integer): last N lines, default 5
  - `--head` (integer): first N lines instead
- `vp out tokens <path>` MCP tool `vp_out_tokens` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `NOT_FOUND` rc 5.
  - `<path>` (string, required): file path

Every command also accepts `--dry-run` (code `DRY_RUN`, nothing starts) and `--timeout-s S` (code `TIMEOUT`, rc 124).

## Typical sequence

```sh
vp out read /path/to/spool.txt 1:60
vp out find "STALE_FRAME drops" $RT/events.jsonl --k 3
vp out sh --cmd "git log --oneline" --tail 5
vp out tokens brief.md
```

## Rules and traps

- Never `cat` a spool, a log or `events.jsonl` into your context: page it.
- The newton-py executable is `~/.local/share/newton-py/venv/bin/newton`; bare `newton` on PATH is a different program.
- Paths of credential, token, key or auth files are refused (`SECRET_PATH`, rc 3).
