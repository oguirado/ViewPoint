# `vp projection`: project queue events to rooms and TaskLight

Follows the broker's `events.jsonl` and posts what happens to an OpenSwitchboard room and to TaskLight cards, so humans and other AIs see each agent's plan and result. `reconcile` checks that every agent got a plan and a close.

Generated by `docs/build_pages.py` from `design/MCP_TOOLS.json` (vpops/1.4), `docs/family_notes.json` and `router/seeds.jsonl`. For exact file:line citations with freshness marks run `vp docs ask "<question>"`.

## Commands

| Command | Class | What it does | Wraps |
|---|---|---|---|
| `vp projection run` | X (starts a process) | Project broker events to an OpenSwitchboard room and TaskLight cards (follow mode or once). | `ref: python3 -I $VP_REF/ref_projection/project.py --rt RT --osb-room R --tasklight-room T [--once / --idle-exit S]; swarm: python3 -m swarm.projection.projector` |
| `vp projection reconcile` | R (read-only) | Check that every event has its projection call and nothing extra was posted. | `python3 -I $VP_REF/ref_projection/reconcile.py --events E --ledger L [--room R]` |

## Arguments, confirm ids and codes

- `vp projection run --rt [--osb-room] [--tasklight-room] [--once] [--idle-exit] [--impl]` MCP tool `vp_projection_run` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `NOT_FOUND` rc 5.
  - `--rt` (string, required): runtime root of the multi-agent capsule (VP_SWARM_RT); never under /dev/shm/vqa-cu/hybrid/ without allow_hybrid
  - `--osb-room` (string): OpenSwitchboard room slug
  - `--tasklight-room` (string): TaskLight room, e.g. viewpoint or demo
  - `--once` (boolean): read to EOF, finalise, exit
  - `--idle-exit` (number): follow mode: finalise after S idle seconds
  - `--impl` (string): which implementation to wrap: ref = Claude Track P product/ref_*, swarm = Gemini Track H swarm/ (default ref)
- `vp projection reconcile --rt [--room]` MCP tool `vp_projection_reconcile` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `AUDIT_VIOLATIONS` rc 1, `NOT_FOUND` rc 5.
  - `--rt` (string, required): runtime root of the multi-agent capsule (VP_SWARM_RT); never under /dev/shm/vqa-cu/hybrid/ without allow_hybrid
  - `--room` (string): room slug

Every command also accepts `--dry-run` (code `DRY_RUN`, nothing starts) and `--timeout-s S` (code `TIMEOUT`, rc 124).

## Typical sequence

```sh
vp projection run --rt $RT --osb-room viewpoint-capsule --tasklight-room viewpoint --once
vp projection reconcile --rt $RT
```

## Rules and traps

- Pass `--osb-room` and `--tasklight-room` explicitly: the wrapped tool defaults to test rooms.
- Delivery is at-least-once: after a crash one batch of posts can repeat.
- A truncated or replaced `events.jsonl` is refused: use a fresh output directory.

## Facts from the wrapped tools

Each fact is pinned to a source line; `vp docs ask` returns the line and whether it is still FRESH.

- (command) F3 projects broker events once with `python3 product/ref_projection/project.py --once --osb-room viewpoint-capsule --tasklight-room viewpoint` (omit `--once` to follow; SIGTERM/SIGINT or `--idle-exit S` finalizes). Source: `product/ref_projection/README.md`.
- (command) `reconcile.py --events $RT/events.jsonl --ledger $RT/projection/ledger.jsonl` flags `MISSING_CLOSE_TASK` or `NO_PLAN` agents: rc 0 clean, 1 flagged, 2 bad input. Source: `product/ref_projection/README.md`.
- (trap) project.py room defaults are the test rooms (`viewpoint-capsule-test`, `demo`), so pass `--osb-room`/`--tasklight-room` for the real rooms; it writes only `RT/projection/state.json` and `RT/projection/ledger.jsonl`. Source: `product/ref_projection/README.md`.
- (failure) A truncated or replaced `events.jsonl` (first-line sha256 kept in the state) is refused by the projector with exit 3: use a fresh `--out`. Source: `product/ref_projection/README.md`.
- (contract) Gemini contract: a refusal or park `close` projects as osb `refute` that must carry `--ref <event_id>` (osb rejects `refute` without `--ref` or `--evidence`, rc 2); `enqueue` maps to `claim`, a granted `turn` to `ack`. Source: `hackathon/swarm/CONTRACT.md`.
- (invariant) Gemini reconciler: `INPUT_UNCERTAIN`/`OUTCOME_UNCERTAIN` events are cleared only by an explicit `control op="reconcile"`; `control op="resume"` does not clear them and unreconciled ones are flagged `UNRECONCILED_UNCERTAIN_EVENT`. Source: `hackathon/swarm/projection/README.md`.
