# `vp record`: record a display, stop by PID, compose overlays

Records a private display to mp4 with ffmpeg, stops the recorder cleanly, composes agent cursors and turn overlays onto the video from the queue's event log, and opens a view-only window for the operator.

Generated by `docs/build_pages.py` from `design/MCP_TOOLS.json` (vpops/1.4), `docs/family_notes.json` and `router/seeds.jsonl`. For exact file:line citations with freshness marks run `vp docs ask "<question>"`.

## Commands

| Command | Class | What it does | Wraps |
|---|---|---|---|
| `vp record start` | X (starts a process) | Record one display to an mp4 (ffmpeg x11grab) with a start-time sidecar. Display :1 is refused. | `ref: $VP_REF/ref_overlay/record.sh <display> <name> <outdir>; swarm: $VP_HK/swarm/tools/record.sh <display> <name>; hybrid playbook (needs allow_display :1): blender_hybrid/rec_start.sh NAME` |
| `vp record stop` | D (destructive, needs `--confirm`) | Stop a recorder by PID with SIGINT so the mp4 is finalised. Only PIDs from this session's ledger. | `kill -INT <pid> after the pid + start-time check` |
| `vp record compose` | W (write-own) | Composite agent cursors and labels onto the recording, off-display (the capsule screen is never painted). | `ref: python3 -I $VP_REF/ref_overlay/compose.py --video V --out O --rt RT --start-file F [--offset-ms N]; swarm: $VP_HK/swarm/tools/compose.sh IN EVENTS OUT` |
| `vp record viewer` | H (human-facing) | Mirror a capsule display to the operator desktop (ffplay). Reads the display, never sends input. | `$VP_HOME/hackathon/playbooks/blender_hybrid/viewer1080.sh (display substituted)` |

## Arguments, confirm ids and codes

- `vp record start --display --name --outdir [--impl] [--allow-display]` MCP tool `vp_record_start` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `FORBIDDEN_DISPLAY` rc 3, `FAIL` rc 1.
  - `--display` (string, required): X display like :99; :1 and the operator display are refused without allow_display
  - `--name` (string, required): [A-Za-z0-9_.-]+
  - `--outdir` (string, required): directory of the recording; existing files are never overwritten
  - `--impl` (string): which implementation to wrap: ref = Claude Track P product/ref_*, swarm = Gemini Track H swarm/ (default ref)
  - `--allow-display` (string): explicit permission for one otherwise forbidden display, e.g. :1
- `vp record stop --pid [--signal]` `--confirm <id>`: required unless dry_run: must equal the pid. MCP tool `vp_record_stop` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `CONFIRM_REQUIRED` rc 4, `NOT_FOUND` rc 5, `FOREIGN_JOB` rc 3.
  - `--pid` (integer, required): process id from an earlier receipt; vp checks pid + start time before signalling
  - `--signal` (string): INT (default, finalises the mp4) or TERM
- `vp record compose --video --out [--rt] [--start-file] [--start-ms] [--offset-ms] [--ring] [--impl]` MCP tool `vp_record_compose` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `NOT_FOUND` rc 5, `FAIL` rc 1.
  - `--video` (string, required): recording mp4
  - `--out` (string, required): output file; must not exist
  - `--rt` (string): runtime root of the multi-agent capsule (VP_SWARM_RT); never under /dev/shm/vqa-cu/hybrid/ without allow_hybrid
  - `--start-file` (string): the .start_ms sidecar from record start
  - `--start-ms` (number): epoch ms of the first frame
  - `--offset-ms` (number): added to the start epoch
  - `--ring` (string): comma list of agents in ring order
  - `--impl` (string): which implementation to wrap: ref = Claude Track P product/ref_*, swarm = Gemini Track H swarm/ (default ref)
- `vp record viewer --display [--allow-display]` MCP tool `vp_record_viewer` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `FORBIDDEN_DISPLAY` rc 3.
  - `--display` (string, required): X display like :99; :1 and the operator display are refused without allow_display
  - `--allow-display` (string): explicit permission for one otherwise forbidden display, e.g. :1

Every command also accepts `--dry-run` (code `DRY_RUN`, nothing starts) and `--timeout-s S` (code `TIMEOUT`, rc 124).

## Typical sequence

```sh
vp record start --display :99 --name vpops-take1 --outdir $VP_VIDEO_DIR
vp record stop --pid <pid> --confirm <pid>   # pid from the start receipt
vp record compose --video take1.mp4 --out take1_overlay.mp4 --rt $RT --start-file take1.start_ms
```

## Rules and traps

- Display `:1` is refused (`FORBIDDEN_DISPLAY`) unless `--allow-display :1` is passed on the operator's instruction.
- Stop with `vp record stop` only: it sends SIGINT to the recorded PID so ffmpeg closes the mp4. SIGKILL leaves the file unplayable.
- Do not record with OBS from a saved scene: a stale scene captured a window that no longer existed and the take was black. Record the private display with `vp record start`.
- `compose` never overwrites an existing output file.
