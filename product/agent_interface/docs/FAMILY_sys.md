# `vp sys`: health, paths and the job ledger

Start here in every session. `vp sys doctor` says which wrapped tools are present; `vp sys jobs` lists the jobs this session owns, which are the only jobs later commands may touch; `vp sys help <noun> <verb>` prints one command's arguments.

Generated by `docs/build_pages.py` from `design/MCP_TOOLS.json` (vpops/1.4), `docs/family_notes.json` and `router/seeds.jsonl`. For exact file:line citations with freshness marks run `vp docs ask "<question>"`.

## Commands

| Command | Class | What it does | Wraps |
|---|---|---|---|
| `vp sys doctor` | R (read-only) | Check every dependency and entry point; one row per capability with PASS/FAIL and the path. | `stat of each PATHS entry + `$VP_VISION doctor` + `$VP_NPY read <pyvenv.cfg> 1:1` + `$VP_OSB doctor`` |
| `vp sys paths` | R (read-only) | Print the resolved path variables and the state dir. | `none (config of the CLI)` |
| `vp sys jobs` | R (read-only) | List the jobs, recorders and runners this session started (ownership ledger). | `VP_OPS_STATE/jobs.json` |
| `vp sys help` | R (read-only) | Print one command's args, receipt fields, codes and safety class from COMMANDS.md. | `design/MCP_TOOLS.json` |

## Arguments, confirm ids and codes

- `vp sys doctor` MCP tool `vp_sys_doctor` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `DEPENDENCY` rc 8.
- `vp sys paths` MCP tool `vp_sys_paths` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2.
- `vp sys jobs` MCP tool `vp_sys_jobs` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2.
- `vp sys help <noun> <verb>` MCP tool `vp_sys_help` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2.
  - `<noun>` (string): command family
  - `<verb>` (string): verb inside the family

Every command also accepts `--dry-run` (code `DRY_RUN`, nothing starts) and `--timeout-s S` (code `TIMEOUT`, rc 124).

## Typical sequence

```sh
vp sys doctor
vp sys jobs
vp sys help capsule start
```

## Rules and traps

- A job that is not in `vp sys jobs` belongs to another session: commands refuse it with `FOREIGN_JOB` (rc 3) unless you pass `--foreign-ok <job>` because the operator told you to.
- New jobs must be named with the prefix `vpops`.
- `DEPENDENCY` (rc 8) from any command means a wrapped program or worktree is missing; `vp sys doctor` names it in `data.missing`.
