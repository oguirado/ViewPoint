# `vp spec`: capsule specs: validate, render, compare

Checks a multi-agent capsule specification (containers, mounts, limits) against the reference rules, prints the launch plan of a valid spec, and compares a spec with what was inspected. Nothing is started.

Generated by `docs/build_pages.py` from `design/MCP_TOOLS.json` (vpops/1.4), `docs/family_notes.json` and `router/seeds.jsonl`. For exact file:line citations with freshness marks run `vp docs ask "<question>"`.

## Commands

| Command | Class | What it does | Wraps |
|---|---|---|---|
| `vp spec validate` | R (read-only) | Validate a capsule spec. | `python3 -I $VP_REF/ref_capsule/validate.py SPEC --json [--skip GATE]` |
| `vp spec render` | R (read-only) | Render a capsule spec to its launch plan (nothing is started). | `python3 -I $VP_REF/ref_capsule/render.py SPEC` |
| `vp spec observe` | R (read-only) | Compare a spec with an inspected running capsule. | `python3 -I $VP_REF/ref_capsule/observe.py SPEC INSPECTED` |

## Arguments, confirm ids and codes

- `vp spec validate <spec> [--skip]` MCP tool `vp_spec_validate` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `AUDIT_VIOLATIONS` rc 1.
  - `<spec>` (string, required): capsule spec JSON
  - `--skip` (string): gate to skip
- `vp spec render <spec>` MCP tool `vp_spec_render` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2.
  - `<spec>` (string, required): capsule spec JSON
- `vp spec observe <spec> <inspected>` MCP tool `vp_spec_observe` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `AUDIT_VIOLATIONS` rc 1.
  - `<spec>` (string, required): capsule spec JSON
  - `<inspected>` (string, required): inspection JSON

Every command also accepts `--dry-run` (code `DRY_RUN`, nothing starts) and `--timeout-s S` (code `TIMEOUT`, rc 124).

## Typical sequence

```sh
vp spec validate specs/blender_4agents.json
vp spec render specs/blender_4agents.json
```

## Rules and traps

- `render` prints a plan; it cannot execute it.
- A memory scope around `docker run` limits the docker client, not the container: the per-container flags are the real limits.
