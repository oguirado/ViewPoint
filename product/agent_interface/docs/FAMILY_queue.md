# `vp queue`: the turn queue (broker) of a multi-agent capsule

Several agents share one program. Each agent writes intents into its own directory; the broker is the only process that executes them, one turn at a time, and the only writer of `events.jsonl`. `vp queue` runs the broker, enqueues and observes intents, and controls the queue. `--impl ref` uses the Claude reference broker, `--impl swarm` the Gemini Track H broker.

Generated by `docs/build_pages.py` from `design/MCP_TOOLS.json` (vpops/1.4), `docs/family_notes.json` and `router/seeds.jsonl`. For exact file:line citations with freshness marks run `vp docs ask "<question>"`.

## Commands

| Command | Class | What it does | Wraps |
|---|---|---|---|
| `vp queue run` | X (starts a process) | Run the turn broker for N turns over the job's Blender: THINK / ENQUEUE / TURN / RETURN, one agent acts per turn. | `ref: VP_SWARM_NONCE=<nonce> python3 -I $VP_REF/ref_broker/broker.py run --job J --rt RT --turns N [--job-cap-s S]; swarm: python3 -m swarm.broker.broker --job J ...` |
| `vp queue control` | W (write-own) | Operator control of a broker: stop (freeze), resume or reconcile. `stop` is the first step of a handback. | `python3 -I $VP_REF/ref_broker/broker.py control --rt RT --op stop/resume/reconcile --by WHO [--reason R]` |
| `vp queue enqueue` | W (write-own) | Validate and enqueue one intent for an agent (script or GUI). Written atomically inside the agent's own intents dir. | `swarm: python3 -m swarm.agents.intent_cli enqueue-script/enqueue-gui --agent A --event-id E --write-set W --expect X --script-file F; ref: write RT/intents/<agent>/<event_id>.json then python3 -I $VP_REF/ref_agents/contract.py --rt RT --agent A --json` |
| `vp queue observe` | R (read-only) | What an agent needs before planning: latest frame, its lease, its last closes. | `swarm: python3 -m swarm.agents.intent_cli observe --agent A [--wait-s S] [--last-n N]; ref: fold of RT/events.jsonl + RT/frames/latest.json` |
| `vp queue validate` | R (read-only) | Validate every intent file under RT against the shared contract. | `python3 -I $VP_REF/ref_agents/contract.py --rt RT [--agent A] --json` |
| `vp queue status` | R (read-only) | Fold of events.jsonl: mode, turn, tick, per-agent queue and last verdicts. No Blender contact. | `python3 -I $VP_REF/ref_rewind_demo/rewindctl.py status --rt RT (or --events F)` |
| `vp queue events` | R (read-only) | Page the authoritative events log (bounded). | `$VP_NPY read RT/events.jsonl A:B` |
| `vp queue simulate` | R (read-only) | Offline A/B of round-robin against the auction scheduler on a synthetic trace. | `python3 -I $VP_REF/ref_auction/sim.py` |

## Typical sequence

```sh
vp queue run --job vpops-blender --rt $RT --turns 12 --detach
vp queue observe --rt $RT --agent modeler-agent
vp queue enqueue --rt $RT --agent modeler-agent --event-id m-001 --kind script --script-file add_nucleus.py --write-set Nucleus
vp queue status --rt $RT
vp queue events --rt $RT --range 1:40
vp queue control --rt $RT --op stop --by director-agent --reason "handback"
```

## Rules and traps

- `STALE_FRAME` (rc 7) on a GUI intent: it cited an old frame. Run `vp queue observe`, then enqueue the same `--event-id` again citing the new frame. Three drops park the intent.
- `INPUT_UNCERTAIN` puts the queue in `RECONCILE`: nothing is dispatched and nothing is repeated. Look at the program, then `vp queue control --op reconcile`, then `--op resume`.
- `FROZEN` (rc 7): the broker was stopped by control or by the watchdog. Use `vp queue control --op resume`, or `vp rewind restore` when the scene is wrong.
- Upstream rc 3 from the broker means `RECONCILE` or `FROZEN`, not an error to retry. Read the receipt `code`.
- `QUEUE_FULL` (rc 6): the agent already has 8 pending intents.
- The broker nonce is passed in the environment only and is never printed. Do not write it into the runtime root.
- An agent writes only inside `RT/intents/<agent_id>/`. Never write `events.jsonl`, `claims.json` or another agent's directory.

## Facts from the wrapped tools

Each fact is pinned to a source line; `vp docs ask` returns the line and whether it is still FRESH.

- (command) F1 ref_broker runs turns with `VP_SWARM_NONCE=$N python3 broker.py run --job vpref1 --rt $RT --turns 12` (rc 0 idle, 3 RECONCILE/FROZEN, 2 error); leave RECONCILE with `python3 broker.py control --rt $RT --op resume --by director-agent --reason "..."`. Source: `product/ref_broker/README.md`.
- (contract) F1 claims live in `RT/claims.json` and agents write `RT/intents/<agent_id>/<event_id>.json` (tmp + rename); the broker is the only writer of `RT/events.jsonl`, `RT/cursor.jsonl`, `RT/frames/` and the only caller of `vision look/act`. Source: `product/ref_broker/README.md`.
- (invariant) The broker reads the nonce from env `VP_SWARM_NONCE` only (never from RT, which agents can read), and `run` rebuilds state from `events.jsonl` so it can be called repeatedly. Source: `product/ref_broker/README.md`.
- (contract) `STALE_FRAME`: a gui `based_on_frame` older than the head frame with differing pixels in between goes to the tail with `drops+1`; the agent may resubmit the same `event_id` citing a newer frame (`rebased:true`); 3 drops park it. Source: `product/ref_broker/README.md`.
- (contract) `INPUT_UNCERTAIN` (hover/key returned an rc other than 0/3, e.g. 8 or 9) and `OUTCOME_UNCERTAIN` close the event and put the queue in RECONCILE, with no dispatch and no repeat until `control resume`. Source: `product/ref_broker/README.md`.
- (invariant) Outbox line 1 is `OK`/`ERROR` and `META` carries `mac` = HMAC-SHA256(nonce, event_id, status, script sha); the broker requires the mac, so an agent cannot answer for the bridge. Source: `product/ref_broker/README.md`.
- (command) The Gemini H1 broker runs live with `python3 -m swarm.broker.broker --job vpswarm --vision-mode live`, or offline with `--vision-mode mock --drain-and-exit` and `/tmp/swarm_dryrun` paths. Source: `hackathon/swarm/broker/README.md`.
- (contract) Gemini contract: the broker writes jobs `<nonce>__<seq>__<event_id>.py` atomically into `SWARM_INBOX`, the bridge answers `<nonce>__<seq>__<event_id>.json` receipts with status `OK`|`ERROR`, and other inbox files are moved to `SWARM_REJECTED` unexecuted. Source: `hackathon/swarm/CONTRACT.md`.
- (contract) Gemini lease rule: for `lane: "script"` `write_set` must be non-empty and every element must start with one of the claim's `write_prefixes`, otherwise `CLAIM_REFUSED`; stale `lease_epoch` or late arrival is `LEASE_EXPIRED`, a missing lease `NO_LEASE`. Source: `hackathon/swarm/CONTRACT.md`.
- (contract) The auction scheduler only proposes: `pick = scheduler.pick(view)` then `recs = scheduler.settle(pick, close)`; the broker's `admit()` remains the only authority. Source: `product/ref_auction/README.md`.
- (contract) Bids are sidecars `RT/bids/<agent_id>/<event_id>.json` `{v,rec:"bid",agent_id,event_id,bid}`; missing or malformed = 0, and `bid_eff = min(bid, balance, bid_cap)`. Source: `product/ref_auction/README.md`.
- (trap) ref_auction is NOT wired into the live broker: the frozen H1 round-robin rule stays until a rehearsal A/B says otherwise; `broker_hook.patch` is not applied by the unit. Source: `product/ref_auction/README.md`.
