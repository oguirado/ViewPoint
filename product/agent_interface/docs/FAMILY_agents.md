# `vp agents`: run the agent team, a solo agent, or a worker wave

Starts and stops the agents that feed the queue: `run` launches the role agents (or stub agents without a model), `solo` runs one Gemini Hydrogen agent from a brief, `wave` drives the swarm skill (pack, plan, run, wait, metrics).

Generated by `docs/build_pages.py` from `design/MCP_TOOLS.json` (vpops/1.4), `docs/family_notes.json` and `router/seeds.jsonl`. For exact file:line citations with freshness marks run `vp docs ask "<question>"`.

## Commands

| Command | Class | What it does | Wraps |
|---|---|---|---|
| `vp agents run` | X (starts a process) | Start the model agents of the 4-agent capsule (or scripted stubs with stub=true, no model). | `ref: python3 -I $VP_REF/ref_agents/runner.py run --rt RT --evidence E [--agents a,b] [--stub] [--model M] [--max-seconds S] [--max-intents N] [--init-rt]; swarm: python3 -m swarm.agents.runner --model M --proof-dir E` |
| `vp agents status` | R (read-only) | Status of the runner started with that evidence dir. | `python3 -I $VP_REF/ref_agents/runner.py status --evidence E` |
| `vp agents stop` | D (destructive, needs `--confirm`) | Stop the runner's agents by their recorded PIDs. | `python3 -I $VP_REF/ref_agents/runner.py stop --evidence E` |
| `vp agents solo` | X (starts a process) | Single-agent hybrid lane: run one headless Antigravity model with a brief; every log goes to the evidence dir. | `$VP_HOME/hackathon/playbooks/blender_hybrid/run_hydrogen.sh BRIEF.md EVIDENCE [MODEL]` |
| `vp agents transcript` | R (read-only) | Render the agent stream as a readable transcript. | `python3 -I $VP_HOME/hackathon/playbooks/blender_hybrid/agy_transcript.py STREAM OUT` |
| `vp agents briefs` | R (read-only) | Print the per-agent briefs of the reference capsule. | `python3 -I $VP_REF/ref_agents/briefs.py` |
| `vp agents wave` | X (starts a process) | Launch a worker wave through the swarm skill (pack, plan, run, wait, metrics). | `$VP_SWARM_SKILL pack/plan/run/wait/metrics --wave-dir DIR ...` |

## Arguments, confirm ids and codes

- `vp agents run --rt --evidence [--agents] [--stub] [--model] [--max-seconds] [--max-intents] [--init-rt] [--impl]` MCP tool `vp_agents_run` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `NOT_FOUND` rc 5, `TIMEOUT` rc 124.
  - `--rt` (string, required): runtime root of the multi-agent capsule (VP_SWARM_RT); never under /dev/shm/vqa-cu/hybrid/ without allow_hybrid
  - `--evidence` (string, required): evidence directory; created if absent, never overwritten
  - `--agents` (string): comma list of contract agent ids (default all four)
  - `--stub` (boolean): scripted fake agents, no model
  - `--model` (string): model id for the agent CLI
  - `--max-seconds` (number): wall clock cap
  - `--max-intents` (integer): intents per agent
  - `--init-rt` (boolean): create RT/intents, RT/frames, claims.json
  - `--impl` (string): which implementation to wrap: ref = Claude Track P product/ref_*, swarm = Gemini Track H swarm/ (default ref)
- `vp agents status --evidence` MCP tool `vp_agents_status` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `NOT_FOUND` rc 5.
  - `--evidence` (string, required): evidence directory; created if absent, never overwritten
- `vp agents stop --evidence` `--confirm <id>`: required unless dry_run: must equal the basename of the evidence dir. MCP tool `vp_agents_stop` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `CONFIRM_REQUIRED` rc 4.
  - `--evidence` (string, required): evidence directory; created if absent, never overwritten
- `vp agents solo --brief --evidence [--model] [--allow-hybrid]` MCP tool `vp_agents_solo` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `FORBIDDEN_PATH` rc 3, `NOT_FOUND` rc 5.
  - `--brief` (string, required): brief markdown file
  - `--evidence` (string, required): evidence directory; created if absent, never overwritten
  - `--model` (string): default gemini-4-hydrogen-xhigh
  - `--allow-hybrid` (boolean): explicit permission to use /dev/shm/vqa-cu/hybrid/
- `vp agents transcript --evidence` MCP tool `vp_agents_transcript` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `NOT_FOUND` rc 5.
  - `--evidence` (string, required): evidence directory; created if absent, never overwritten
- `vp agents briefs [--agent]` MCP tool `vp_agents_briefs` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2.
  - `--agent` (string): agent id; the 4-agent capsule uses modeler-agent, props-agent, look-agent, camera-agent
- `vp agents wave --step --wave-dir [--seat] [--pack] [--tasks] [--sources]` MCP tool `vp_agents_wave` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `TIMEOUT` rc 124, `REFUSED` rc 3.
  - `--step` (string, required): pack, plan, run, wait or metrics
  - `--wave-dir` (string, required): wave directory
  - `--seat` (string): seat name from the seat policy
  - `--pack` (string): context pack file
  - `--tasks` (string): comma list of task files
  - `--sources` (string): context sources for pack

Every command also accepts `--dry-run` (code `DRY_RUN`, nothing starts) and `--timeout-s S` (code `TIMEOUT`, rc 124).

## Typical sequence

```sh
vp agents briefs
vp agents run --rt $RT --evidence evidence/vpops-run1 --stub --init-rt
vp agents status --evidence evidence/vpops-run1
vp agents stop --evidence evidence/vpops-run1 --confirm vpops-run1
vp agents transcript --evidence evidence/vpops-solo1
```

## Rules and traps

- Agents are stopped by the PID recorded at start, never by name: `pkill -f <pattern>` has killed the caller's own shell twice.
- `agy` needs `-p "<prompt>"` as the last argument; with another order it takes `--model` as the prompt and exits 2. The wrapped scripts already do this.
- `claude -p` with `--output-format stream-json` needs `--verbose`.
- A context pack must be byte-stable: no PIDs, clock values or timestamps in pack sources or questions. A refusal names `pack_volatile_or_marker`.
- A worker's exit code 0 does not prove success: read the receipt (`is_error`, empty result, denied actions).
- Run one solo Hydrogen job at a time per live Blender.
