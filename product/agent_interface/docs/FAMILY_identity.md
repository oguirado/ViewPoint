# `vp identity`: browser identities (profiles) of the take

Lists, creates, relabels and deletes the identities that capsules open. An identity is a persistent browser profile with an allow-list of domains. Login is always done by the operator, by hand.

Generated by `docs/build_pages.py` from `design/MCP_TOOLS.json` (vpops/1.4), `docs/family_notes.json` and `router/seeds.jsonl`. For exact file:line citations with freshness marks run `vp docs ask "<question>"`.

## Commands

| Command | Class | What it does | Wraps |
|---|---|---|---|
| `vp identity list` | R (read-only) | List browser identities (public metadata only). | `python3 -I $VP_HOME/hackathon/vp_mcp/vp_mcp.py (VP_MCP_SESSION=<abs session.json>) tools/call vp_identity_list` |
| `vp identity create` | W (write-own) | Create an identity with a label and its allowed registrable domains. Login stays manual. | `python3 -I $VP_HOME/hackathon/vp_mcp/vp_mcp.py (VP_MCP_SESSION=<abs session.json>) tools/call vp_identity_create` |
| `vp identity label` | W (write-own) | Change only the label of an identity. | `python3 -I $VP_HOME/hackathon/vp_mcp/vp_mcp.py (VP_MCP_SESSION=<abs session.json>) tools/call vp_identity_set_label` |
| `vp identity delete` | D (destructive, needs `--confirm`) | Delete an identity and its browser profile. Refused while a capsule holds its lease. | `python3 -I $VP_HOME/hackathon/vp_mcp/vp_mcp.py (VP_MCP_SESSION=<abs session.json>) tools/call vp_identity_delete (confirm == id)` |

## Arguments, confirm ids and codes

- `vp identity list [--session]` MCP tool `vp_identity_list` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2.
  - `--session` (string): absolute path of the vp_mcp session file (VP_MCP_SESSION); default: newest take's session
- `vp identity create --id --label --domains [--session]` MCP tool `vp_identity_create` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2.
  - `--id` (string, required): identity id
  - `--label` (string, required): human label
  - `--domains` (string, required): comma separated registrable domains, sorted
  - `--session` (string): absolute path of the vp_mcp session file (VP_MCP_SESSION); default: newest take's session
- `vp identity label --id --label [--session]` MCP tool `vp_identity_label` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2.
  - `--id` (string, required): identity id
  - `--label` (string, required): new label
  - `--session` (string): absolute path of the vp_mcp session file (VP_MCP_SESSION); default: newest take's session
- `vp identity delete --id [--session]` `--confirm <id>`: required unless dry_run: must equal the identity id. MCP tool `vp_identity_delete` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `CONFIRM_REQUIRED` rc 4, `BUSY` rc 6.
  - `--id` (string, required): identity id
  - `--session` (string): absolute path of the vp_mcp session file (VP_MCP_SESSION); default: newest take's session

Every command also accepts `--dry-run` (code `DRY_RUN`, nothing starts) and `--timeout-s S` (code `TIMEOUT`, rc 124).

## Typical sequence

```sh
vp identity list
vp identity create --id docs-demo --label "Docs demo" --domains example.org
vp identity label --id docs-demo --label "Docs"
vp identity delete --id docs-demo --dry-run
vp identity delete --id docs-demo --confirm docs-demo
```

## Rules and traps

- `vp identity delete` is irreversible: it removes the identity and its browser profile. `--confirm` must equal the id.
- Ids are 2 to 40 characters of lowercase letters, digits and `-`.
- Never type or read passwords: ask the operator to log in through `vp capsule view`.

## Facts from the wrapped tools

Each fact is pinned to a source line; `vp docs ask` returns the line and whether it is still FRESH.

- (contract) vp_list_capsules takes no arguments. It pages through `mvctl list --limit 256` (up to 16 pages) and maps each configured identity to its active browser surface (surface_id/kind/state). It returns no title or URL. Source: `hackathon/mcp/vp_mcp/README.md`.
- (failure) Every tool refuses an identity that is not in the session capsules list before starting any subprocess. Source: `$VP_OPS_ROOT/ViewPoint/hackathon/vp_mcp/vp_mcp.py`.
- (contract) vp_navigate(identity, url) accepts only https:// URLs of at most 2048 chars. It refuses literal private, loopback and link-local hosts but does no DNS lookup, so names that resolve to private addresses are not refused. Source: `$VP_OPS_ROOT/ViewPoint/hackathon/vp_mcp/vp_mcp.py`.
- (command) vp_browser_task(identity, goal, text?, key?=Enter) runs `python3 -B -m metaviewer_agents.mw_run --identity I --surface-kind browser --goal G [--text T] [--key Enter] --steps 6 --timeout-ms 30000 --planner rules` with a 70 s subprocess timeout. Source: `$VP_OPS_ROOT/ViewPoint/hackathon/vp_mcp/vp_mcp.py`.
- (contract) vp_read_page(identity, max_chars 1..6000) runs the read-only `srf ax --container C --window w1 --state-dir S`. It returns the title plus heading, link, paragraph and static-text names, marked as untrusted page content. Source: `$VP_OPS_ROOT/ViewPoint/hackathon/vp_mcp/vp_mcp.py`.
- (contract) The identity tools (vp_identity_list, vp_identity_create(id,label,domains), vp_identity_set_label(id,label), vp_identity_delete(id,confirm)) run `python3 -B <repo>/tools/mv_identity.py <verb>` through env_launcher with a 600 s timeout. Login is always manual. Source: `$VP_OPS_ROOT/ViewPoint/hackathon/vp_mcp/vp_mcp.py`.
- (failure) On IDENTITY_TIMEOUT nothing is retried. The operator should check the identity's status in the host menu before any retry. Source: `$VP_OPS_ROOT/ViewPoint/hackathon/vp_mcp/vp_mcp.py`.
- (trap) vp_identity_delete is irreversible: it deletes the identity and its browser profile. It is refused while the identity holds an active lease, and for mv- ids, the live profile and foreign ids. Source: `$VP_OPS_ROOT/ViewPoint/hackathon/vp_mcp/vp_mcp.py`.
- (failure) vp_identity_delete runs nothing unless confirm equals id exactly. Otherwise it returns "CONFIRM_MISMATCH: confirm must equal the id; nothing was deleted". Source: `$VP_OPS_ROOT/ViewPoint/hackathon/vp_mcp/vp_mcp.py`.
- (contract) Identity ids must be 2-40 chars of [a-z0-9-] starting with a letter or digit (else INVALID_ID). Labels must be 1-128 chars with no surrounding spaces or control characters (else INVALID_LABEL). Source: `$VP_OPS_ROOT/ViewPoint/hackathon/vp_mcp/vp_mcp.py`.
