# `vp docs`: the documentation and command router

Answers "which command, which file, which line" offline. Every answer cites file:line and marks the citation FRESH, SHIFT or STALE by hashing the cited bytes again. A question the corpus does not cover returns `AUSENTE` (rc 5) instead of a guess. Ranking, citation states and packs come from newton-py's route engine.

Generated by `docs/build_pages.py` from `design/MCP_TOOLS.json` (vpops/1.4), `docs/family_notes.json` and `router/seeds.jsonl`. For exact file:line citations with freshness marks run `vp docs ask "<question>"`.

## Commands

| Command | Class | What it does | Wraps |
|---|---|---|---|
| `vp docs card` | R (read-only) | One-page card of ViewPoint for an AI reader: what exists, safety rules, first commands. | `python3 -I product/agent_interface/router/vp_docs.py card` |
| `vp docs ask` | R (read-only) | Answer a question with cited file:line rows, each marked FRESH, SHIFT or STALE. Abstains with AUSENTE. | `python3 -I product/agent_interface/router/vp_docs.py ask QUERY [--k N]` |
| `vp docs pack` | R (read-only) | Compile a context pack for a task under a token budget. | `python3 -I product/agent_interface/router/vp_docs.py pack QUERY [--budget N]` |
| `vp docs locate` | R (read-only) | Locate a symbol, file or command. | `python3 -I product/agent_interface/router/vp_docs.py locate QUERY` |
| `vp docs show` | R (read-only) | Show one finding with its cited lines. | `python3 -I product/agent_interface/router/vp_docs.py show ID` |
| `vp docs route` | R (read-only) | Route an intent to the `vp` command (and team skill) that does it. Abstains instead of guessing. | `python3 -I product/agent_interface/router/vp_docs.py ask QUERY (commands[] rows) + $VP_NPY route QUERY` |
| `vp docs file` | R (read-only) | What the router knows about one file: symbols and findings. | `python3 -I product/agent_interface/router/vp_docs.py file QUERY [--k N]` |
| `vp docs find` | R (read-only) | Find symbols by name in the router index. | `python3 -I product/agent_interface/router/vp_docs.py find QUERY [--k N]` |
| `vp docs stats` | R (read-only) | Size of the router corpus: files, symbols, findings. | `python3 -I product/agent_interface/router/vp_docs.py stats` |
| `vp docs check` | R (read-only) | Re-verify every citation of the router against disk. | `python3 -I product/agent_interface/router/vp_docs.py check` |
| `vp docs build` | W (write-own) | Rebuild the router index. | `python3 -I product/agent_interface/router/vp_docs.py build` |

## Arguments, confirm ids and codes

- `vp docs card` MCP tool `vp_docs_card` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2.
- `vp docs ask <query> [--k]` MCP tool `vp_docs_ask` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `AUSENTE` rc 5.
  - `<query>` (string, required): question or search terms
  - `--k` (integer): number of results
- `vp docs pack <query> [--budget]` MCP tool `vp_docs_pack` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2.
  - `<query>` (string, required): question or search terms
  - `--budget` (integer): token budget, default 6000
- `vp docs locate <query> [--k]` MCP tool `vp_docs_locate` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `AUSENTE` rc 5.
  - `<query>` (string, required): question or search terms
  - `--k` (integer): number of results
- `vp docs show <id>` MCP tool `vp_docs_show` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `NOT_FOUND` rc 5.
  - `<id>` (string, required): finding id
- `vp docs route <query>` MCP tool `vp_docs_route` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `AUSENTE` rc 5.
  - `<query>` (string, required): question or search terms
- `vp docs file <query> [--k]` MCP tool `vp_docs_file` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `AUSENTE` rc 5.
  - `<query>` (string, required): question or search terms
  - `--k` (integer): number of results
- `vp docs find <query> [--k]` MCP tool `vp_docs_find` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `AUSENTE` rc 5.
  - `<query>` (string, required): question or search terms
  - `--k` (integer): number of results
- `vp docs stats` MCP tool `vp_docs_stats` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2.
- `vp docs check` MCP tool `vp_docs_check` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `AUDIT_VIOLATIONS` rc 1.
- `vp docs build` MCP tool `vp_docs_build` (tier extended). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2.

Every command also accepts `--dry-run` (code `DRY_RUN`, nothing starts) and `--timeout-s S` (code `TIMEOUT`, rc 124).

## Typical sequence

```sh
vp docs card
vp docs route "record the blender display"
vp docs ask "what do I do after INPUT_UNCERTAIN" --k 3
vp docs show product/agent_interface/docs/TROUBLESHOOTING.md#L1-20
vp docs pack "rewind after a wrong edit" --budget 3000
vp docs check
```

## Rules and traps

- `AUSENTE` means absent from the corpus: do not invent an answer. Try the words the commands use, `vp docs locate`, or ask the operator.
- STALE means the cited bytes changed: read the file again and run `vp docs build`.
- Ranking is lexical. Use command words (`capsule`, `enqueue`, `checkpoint`) and code words (`STALE_FRAME`).
- A pack has no timestamps or PIDs: the same tree gives the same bytes, so it can sit in a cached prompt prefix.
