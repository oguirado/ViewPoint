# `vp human`: hand control to the operator and take it back

`handback` stops the queue, posts a `handoff` act in the room and opens the view for the operator. `resume` checks that the handoff was acknowledged, reconciles and resumes the queue.

Generated by `docs/build_pages.py` from `design/MCP_TOOLS.json` (vpops/1.4), `docs/family_notes.json` and `router/seeds.jsonl`. For exact file:line citations with freshness marks run `vp docs ask "<question>"`.

## Commands

| Command | Class | What it does | Wraps |
|---|---|---|---|
| `vp human handback` | H (human-facing) | Hand the capsule back to the human: freeze the broker (control stop), post a handoff act in the room, open the viewer. Agents stay frozen until `human resume`. | `vp queue control --op stop  ->  vp room post --act handoff  ->  vp capsule view / vp record viewer` |
| `vp human resume` | W (write-own) | Take the capsule back after the human acked: checks the handoff has an ack in the room, reconciles, resumes the broker. | `vp room status (ack of handoff_id)  ->  vp queue control --op reconcile  ->  vp queue control --op resume` |

## Arguments, confirm ids and codes

- `vp human handback --rt --room --by --reason [--display] [--allow-display]` MCP tool `vp_human_handback` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `NOT_FOUND` rc 5, `FORBIDDEN_DISPLAY` rc 3.
  - `--rt` (string, required): runtime root of the multi-agent capsule (VP_SWARM_RT); never under /dev/shm/vqa-cu/hybrid/ without allow_hybrid
  - `--room` (string, required): room slug
  - `--by` (string, required): agent handing back
  - `--reason` (string, required): what the human must decide or do
  - `--display` (string): X display like :99; :1 and the operator display are refused without allow_display
  - `--allow-display` (string): explicit permission for one otherwise forbidden display, e.g. :1
- `vp human resume --rt --room --by --handoff-id` MCP tool `vp_human_resume` (tier core). Codes: `OK` rc 0, `DRY_RUN` rc 0, `USAGE` rc 2, `STATE` rc 7, `NOT_FOUND` rc 5.
  - `--rt` (string, required): runtime root of the multi-agent capsule (VP_SWARM_RT); never under /dev/shm/vqa-cu/hybrid/ without allow_hybrid
  - `--room` (string, required): room slug
  - `--by` (string, required): agent resuming
  - `--handoff-id` (string, required): id returned by human handback

Every command also accepts `--dry-run` (code `DRY_RUN`, nothing starts) and `--timeout-s S` (code `TIMEOUT`, rc 124).

## Typical sequence

```sh
vp human handback --rt $RT --room viewpoint-capsule --by director-agent --reason "operator wants to adjust the camera"
vp room wait --room viewpoint-capsule --act ack --timeout-s 900
vp human resume --rt $RT --room viewpoint-capsule --by director-agent --handoff-id <handoff-id>   # data of the handback receipt
```

## Rules and traps

- While the operator has control, no agent enqueues and nobody acts on the display.
- After the operator returns control, wait at least 70 s before the first browser action in a ViewPoint take; every agent observes again before it enqueues.
- `resume` checks the room for the ack of the handoff id before it reconciles and resumes the queue.
