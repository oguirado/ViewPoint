# ViewPoint v0.3.1-hackathon

This release does not change the hackathon submission. [v0.3.0-hackathon](https://github.com/oguirado/ViewPoint/releases/tag/v0.3.0-hackathon) (commit `79a69b5`) stays the hackathon submission. Under `hackathon/`, the code is byte-identical to that release, apart from the assembly edits listed in [PROVENANCE.md](../../PROVENANCE.md).

What v0.3.1 adds is everything around that code: one repository you can clone, build and test, with green CI, documentation and a project site.

## What is in it

- **The whole monorepo on `main`.** The repository holds the pre-existing MetaViewer core (Rust core, daemon adapter, contracts, agents, UI). Its perception and action engines are vendored under `components/` at the pins in `deps.lock`. The hackathon layer is under `hackathon/`:
  - the Gemini swarm;
  - the replay viewer;
  - the Cloud Run gateway;
  - the `viewpoint-agent` MCP server.
- **One licence: `AGPL-3.0-only`** for the whole tree. See [LICENSE](../../LICENSE) and [NOTICE-EVALUATION.md](../../NOTICE-EVALUATION.md).
- **Who wrote what is declared.** [PROVENANCE.md](../../PROVENANCE.md) separates:
  - the pre-existing core;
  - Gemini's work (Track H);
  - Claude's work (Track P, the assembly and the hardening).

  Nothing written by Claude is labelled as Gemini's. Claude's reference stack moved to the `claude-reference` branch.
- **CI on GitHub is green and needs no repository secrets.** Five workflows run on `ubuntu-24.04` (x86_64) and `ubuntu-24.04-arm` (arm64):
  - CI;
  - Quickstart, which runs the README Quickstart word for word;
  - Secrets (gitleaks);
  - Linux package verification;
  - assembly.
- **Install guides for DGX Spark class machines (arm64) and x86_64 Linux.** See [INSTALL.md](../../INSTALL.md). On a DGX Spark class host, a clean-install audit built, tested and packaged the tree, then ran `--verify-install`, `--smoke` and a 60 s app launch.
- **The project site is in [`site/`](../../site/)**, published by the Pages workflow at [oguirado.github.io/ViewPoint](https://oguirado.github.io/ViewPoint/). It covers the architecture and the queues, and shows the Blender pieces the Gemini agents built, with a 3D viewer and the log behind every number. Its own provenance is in [`site/PROVENANCE.md`](../../site/PROVENANCE.md).
- **Live demo on Cloud Run:** [viewpoint-swarm-viewer](https://viewpoint-swarm-viewer-dtrnknr6bq-ew.a.run.app), revision `00005-tab`. It replays the recorded Gemini swarm runs step by step. The public test passes and the vision engine responds live.
- **Logo, social preview and contact.** The logo and social preview are under `docs/media/`. Contact details are in [CONTACT.md](../../CONTACT.md).
