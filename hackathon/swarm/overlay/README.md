# ViewPoint Swarm Off-Display Overlay Compositor & Recording Tools (`H3`)

Post-processing HUD compositor and X11 capsule recorder conforming to `swarm/CONTRACT.md` (`v: 1`).

## Zero-Contamination Invariant

- **0 live-display pixel mutations**: `swarm.overlay.compositor` clears `DISPLAY` / `WAYLAND_DISPLAY` on startup and renders exclusively in memory onto decoded MP4 frames via `PIL` + `numpy` + `ffmpeg` (`libx264`, `yuv420p`, `+faststart`).
- **Display `:1` hard refusal**: `swarm/tools/record.sh` normalizes leading zeros in base-10 (`10#${DISP_NUM}`) and unconditionally exits `2` on `:1` / `:01` / `:001` / `:1.0` (even if `--allow-display0` is passed), and refuses `:0` / `:00` / `:000` unless `--allow-display0` is explicitly supplied.

## Components

| File | Role |
|---|---|
| `swarm/tools/record.sh` | Background `ffmpeg` `x11grab` (`1920x1080`, `15 fps`, `+faststart`) recorder with `:1`/`:0` safety gates and `.meta.json` wall-clock sidecar |
| `swarm/tools/compose.sh` | Headless CLI wrapper running `python3 -m swarm.overlay.compositor` and validating output stream via `ffprobe` |
| `swarm/overlay/compositor.py` | Off-display Turn-Queue Strip, `C^1` smoothstep cursor interpolator (`250 ms`), and standing caption renderer |
| `swarm/overlay/test_overlay.py` | Unit + end-to-end `ffmpeg` synthesis, pixel-region verification, and negative-control test suite |

## HUD Layout & Per-Agent Palette (`1920x1080` Canonical Coordinates)

1. **Top Turn-Queue Strip (`y = 0..56`)**:
   - **Active Head Badge**: `TURN #<N> | TICK #<T> | HEAD: <agent_id> [SCRIPT|GUI]`
   - **Waiting Ring Pills**: Deterministic round-robin queue (`props-agent -> look-agent -> camera-agent`) with per-agent pending FIFO counts and `[PARK]` indicators
   - **Last Verdict Pill**: `STATE_VERIFIED` (green), `VERIFIED` / `VERIFIED_WITH_SPILL` (cyan), `STALE_FRAME` / `TURN_TIMEOUT` (amber with drop/rebase tags), `CLAIM_REFUSED` / `JOB_ERROR` (red)
2. **Per-Agent Coloured Cursors** (`250 ms` cubic smoothstep `lerp`):

| `agent_id` | Hex Color | Default Anchor `[x, y]` | Default Lane |
|---|---|---|---|
| `modeler-agent` | `#ff6b6b` | `[480, 420]` | `SCRIPT` |
| `props-agent` | `#4ecdc4` | `[1080, 620]` | `SCRIPT` |
| `look-agent` | `#ffe66d` | `[780, 300]` | `SCRIPT` |
| `camera-agent` | `#38bdf8` | `[800, 500]` | `GUI` |

   - `phase: "intent"`: 8-segment dashed ghost ring + `[intent]` tag
   - `phase: "act"`: solid outlined pointer + animated concentric pulse ring + `[ACTING]` tag
   - `phase: "result"`: solid pointer + verdict badge (`✓` / `!` / `✗`) + outcome tag
3. **Standing Attribution Caption** (bottom-right):
   - `"Code generated by Gemini 4 via Antigravity CLI | Per-agent overlays under a turn queue"`

## Usage

### 1. Record Capsule Display (`:99`, never `:1`)

```bash
PID=$(swarm/tools/record.sh :99 rehearsal1)
# ... run swarm broker & agents ...
kill -INT "$PID"
RAW_MP4=$(cat "/tmp/swarm_record_${PID}.mp4.path")
```

Tracking artifacts written by `record.sh`:
- Video: `~/Vídeos/ViewPoint_hackathon/swarm_<name>_<HHMMSS>.mp4`
- Sidecar: `~/Vídeos/ViewPoint_hackathon/swarm_<name>_<HHMMSS>.mp4.meta.json`
- Pointers: `/tmp/swarm_record_<name>.pid`, `/tmp/swarm_record_<name>.outpath`, `/tmp/swarm_record_<PID>.mp4.path` (mirrored to `$SWARM_RUN_DIR` when set)

### 2. Compose Off-Display Overlays

```bash
swarm/tools/compose.sh \
  "$RAW_MP4" \
  swarm/run/events.jsonl \
  ~/Vídeos/ViewPoint_hackathon/swarm_rehearsal1_composed.mp4
```

Timeline alignment priority (`--timeline-mode auto`):
1. Explicit `--start-ts-ms <epoch_ms>` (and optional `--end-ts-ms <epoch_ms>`)
2. Recording sidecar (`<input.mp4>.meta.json` or `--sidecar <path>`) unconditionally when present
3. File `mtime - duration` when overlapping `events.jsonl`
4. Automatic `[min(events.ts_ms), max(events.ts_ms)]` span mapping when no sidecar exists (or `--timeline-mode span`)
