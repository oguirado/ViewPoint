What you're looking at

ViewPoint lets AI agents operate a shared app—here one Blender 4.0.2 instance—where no action counts until the core admits and verifies it against a fresh frame; this page is a recorded, SHA-256 verified replay, not live.

Try this: switch Recorded Bundle to take3-w2-guards to watch the guards refuse bad actions.

  1. Pick a take in Recorded Bundle (starts on empty frame 0).
  2. Press Play or Next to step through recorded turns.
  3. Left: the Blender viewport after each turn with agent HUD.
  4. Right: which agent acted, what it promised, its write set, and core verdict.
Verdict pill legend
  • STATE_VERIFIED Verified within claimed write set.
  • VERIFIED_WITH_SPILL Touched outside claim; logged, not counted clean.
  • JOB_ERROR Agent script failed.
  • PASS Empty turn; nothing to do.
  • CLAIM_REFUSED / STALE_FRAME Guard refused bad claim or stale frame (take3).
